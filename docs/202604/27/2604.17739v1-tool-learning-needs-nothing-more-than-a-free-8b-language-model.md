## 摘要
强化学习（RL）已成为训练工具调用智能体的主流范式，这通常需要在线交互环境。现有方法要么依赖于带有真值标注的训练数据，要么需要先进的商业语言模型（LM）来合成一旦创建就保持不变的固定环境。在这项工作中，我们提出了 TRUSTEE，这是一种无数据方法，通过完全由免费开源 LM（小至 8B）模拟的动态环境来训练工具调用智能体，包括任务生成、用户模拟、工具模拟和轨迹评估，并配合一种在训练过程中动态控制任务难度各方面的自适应课程学习机制。我们的实证结果表明，TRUSTEE 在各个领域都带来了持续的改进，并优于所有需要额外外部资源进行训练的基准模型。这些结果证实，通过足够精巧的设计，即使是以本地 8B LM 为骨干的模拟环境也能为工具学习建立强大的基准，而无需昂贵的标注数据、真实的人机交互、可执行工具，或来自人类专家或商业 LM 的昂贵可验证环境。我们希望所提出的范式能够启发未来在有限资源下进行环境扩展的研究。

## Abstract
Reinforcement learning (RL) has become a prevalent paradigm for training tool calling agents, which typically requires online interactive environments. Existing approaches either rely on training data with ground truth annotations or require advanced commercial language models (LMs) to synthesize environments that keep fixed once created. In this work, we propose TRUSTEE, a data-free method training tool calling agents with dynamic environments fully simulated by free open-source LMs that can be as small as 8B, including task generation, user simulation, tool simulation and trajectory evaluation, paired with an adaptive curriculum learning mechanism that controls various aspects of the task difficulty dynamically during training. Our empirical results show that TRUSTEE brings consistent improvements across various domains and outperforms all the baselines which require extra external resources for training. These confirm that, with a sufficiently sophisticated design, even simulated environments with a local 8B LM as the backbone could set a strong baseline for tool learning, without expensive annotated data, realistic human interactions, executable tools or costly verifiable environments from human experts or commercial LMs. We hope our proposed paradigm could inspire future research on environment scaling with limited resources.

### 1. 核心问题与整体含义
*   **研究动机**：训练工具调用智能体通常依赖强化学习（RL），但 RL 需要在线交互环境。现有的环境构建方法存在三大痛点：1) 依赖昂贵的人工标注数据；2) 依赖不稳定的真实 API；3) 依赖昂贵的商业模型（如 GPT-4）来合成静态环境。
*   **核心目标**：探索是否能仅依靠一个**免费、本地、8B 规模**的开源模型，在完全“无数据”的情况下，通过自我模拟环境来完成高质量的工具学习。

### 2. 方法论
TRUSTEE 框架包含三个阶段和一套自适应机制：
*   **核心思想**：将环境中的所有组件（任务生成器、用户模拟器、工具模拟器、奖励评估器）全部由同一个 8B 开源模型承担，实现“自给自足”的训练闭环。
*   **关键技术流程**：
    1.  **任务生成**：根据当前难度，从工具库中采样工具，生成用户角色、意图、初始查询和预期调用的工具列表。
    2.  **环境模拟**：
        *   **用户模拟器**：根据对话历史和意图，以人类口吻回复智能体或提出澄清。
        *   **工具模拟器**：模拟 API 的执行结果（无需真实执行代码），并提供初步反馈。
    3.  **策略优化**：使用 **GRPO（Group Relative Policy Optimization）** 算法。它通过组内相对优势来计算奖励，无需额外的 Critic 模型，节省了显存。
*   **自适应课程学习 (ACL)**：这是本文的核心创新。系统会根据智能体在前一步的平均奖励动态调整难度（Dn）。调整维度包括：可用工具数量、预期调用次数、交互轮数、系统提示词的详细程度、用户角色的专业度、查询的歧义性以及评估标准的严苛程度。

### 3. 实验设计
*   **数据集/场景**：工具库来源于 **ToolBench**（包含约 49 个类别的 REST API 描述）。
*   **Benchmark（评测基准）**：
    *   **BFCL V4** (Berkeley Function Calling Leaderboard)：涵盖单轮（简单、并行、多重）和多轮场景。
    *   **$\tau^2$-bench**：评估在航空、零售、电信三个真实领域中的多轮交互能力。
*   **对比方法**：
    *   **ToolRL / Tool-N1**：基于真值标注数据的单轮 RLVR 方法。
    *   **Simia-RL**：使用商业模型模拟工具响应的方法。
    *   **EnvScaler / AWM**：使用商业模型进行程序化环境合成的方法。

### 4. 资源与算力
*   **硬件环境**：使用了 1 个节点，配备 **8 张 NVIDIA H20 GPU**。
*   **算力分配**：4 张 GPU 用于智能体策略训练，另外 4 张 GPU 用于部署 vLLM 服务器以运行模拟环境（任务生成、用户/工具模拟等）。
*   **训练细节**：总计训练 200 个 Step，每个 Step 包含 16 个任务，每个任务采样 8 条轨迹（Group Size = 8）。

### 5. 实验数量与充分性
*   **实验规模**：论文在 BFCL 的多个子集（Non-Live, Live, Multi-Turn）和 $\tau^2$-bench 的三个领域进行了详尽测试。
*   **充分性与公平性**：对比了当前最先进的（SOTA）基于数据驱动和基于合成环境的方法。为了公平，作者还重新运行了部分基准代码以对齐序列长度等参数。实验覆盖了从单轮到复杂多轮交互的完整频谱，验证了方法的泛化性。

### 6. 主要结论与发现
*   **性能卓越**：仅使用 8B 模型模拟环境训练出的 Qwen3-8B，在 BFCL 和 $\tau^2$-bench 上的表现优于所有依赖人工标注或商业模型（如 GPT-4）的基准方法。
*   **环境扩展性**：证明了“环境缩放”（Environment Scaling）并不一定需要昂贵的资源，精巧设计的模拟逻辑比单纯增加模型规模更重要。
*   **课程学习的必要性**：动态调整难度能确保智能体始终在“舒适区”边缘学习，避免了训练初期的崩溃。

### 7. 优点
*   **极低成本**：完全摆脱了对商业 API 费用和人工标注的依赖，实现了“数据自由”。
*   **动态性强**：相比于 EnvScaler 等生成的静态环境，TRUSTEE 的环境是根据智能体表现实时调整的，更符合强化学习的本质。
*   **全流程闭环**：不仅模拟工具，还模拟了用户行为和复杂的评估逻辑，是一个完整的智能体训练范式。

### 8. 不足与局限
*   **模拟上限**：8B 模型的认知能力有限，在处理极度复杂（如超多工具、超长轮次）的任务时，模拟的准确性和奖励的公正性可能会下降。
*   **超参数敏感**：自适应课程学习（ACL）涉及大量阈值和步长参数，寻找最优配置可能具有挑战性。
*   **稳定性风险**：由于 8B 模型偶尔会产生格式错误的输出，可能导致部分训练轨迹因解析失败而作废，影响训练效率。
