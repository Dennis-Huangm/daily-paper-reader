## 摘要
小型视觉语言模型（SVLMs）是高效的任务控制器，但通常面临视觉脆弱性和工具编排能力差的问题。它们通常需要昂贵的监督轨迹微调来缓解这些缺陷。在这项工作中，我们提出了通过级联工具展开对齐实现的自监督感知（SPECTRA），这是一个无监督框架，通过冷启动强化学习来引导 SVLMs 的智能体能力。SPECTRA 强制执行软结构化多轮展开，这是一种拓扑约束，引导智能体在综合信息之前显式地对工具获取的证据进行排序，从而有效地将推理锚定在视觉观察中。我们采用多目标奖励信号，同时最大化任务正确性、展开结构和工具效用，使智能体能够在没有人类偏好标签的情况下自我发现鲁棒行为。我们进一步引入了工具工具性效用（TIU），这是一种在缺乏地面真值的情况下量化工具效能的新型指标。在综合和分布外（MMMU-Pro）基准测试上的广泛评估表明，SPECTRA 增强了智能体轨迹，将任务准确率提高了多达 5%，工具效率提高了 9%，从而实现了仅通过环境交互即可有效学习的更高效多模态智能体。

## Abstract
Small Vision-Language Models (SVLMs) are efficient task controllers but often suffer from visual brittleness and poor tool orchestration. They typically require expensive supervised trajectory tuning to mitigate these deficits. In this work, we propose Self-supervised Perception Enabled by Cascaded Tool Rollout Alignment (SPECTRA), a supervision-free framework that bootstraps agentic capabilities via Coldstart Reinforcement Learning for SVLMs. SPECTRA enforces Soft Structured Multi-turn Rollouts, a topological constraint that directs agents to explicitly sequence tool derived evidence before synthesis, effectively grounding reasoning in visual observations. We employ a multi-objective reward signal that simultaneously maximizes task correctness, rollout structure, and tool utility, enabling agent to self-discover robust behaviors without human preference labels. We further introduce Tool Instrumental Utility (TIU), a novel metric to quantify tool efficacy in the absence of ground truth. Extensive evaluations across composite and out-of-distribution (MMMU-Pro) benchmarks demonstrate that SPECTRA boosts agentic trajectories, improving task accuracy by up to 5% and tool efficiency by 9%, enabling more efficient multimodal agents that learn effectively from environmental interaction alone.

*   **研究背景**：小型视觉语言模型（SVLMs，如 Qwen2.5-VL）虽然部署成本低、延迟小，但在处理复杂多步任务时表现出“视觉脆弱性”（感知不精细）和工具编排能力差的问题。
*   **核心问题**：现有的智能体轨迹优化方法高度依赖昂贵的监督数据（人类标注或大模型蒸馏的轨迹）。如何在**无监督、无人类偏好标签**的情况下，提升 SVLM 的视觉感知接地能力和工具调用效率？
*   **整体含义**：论文提出了 **SPECTRA** 框架，旨在通过环境反馈的冷启动强化学习，让模型自主发现稳健的推理轨迹。

### 2. 方法论
*   **核心思想**：利用强化学习（RL）结合结构化拓扑约束，强制模型在生成答案前必须经历“推理-工具调用-观察-感知合成”的循环。
*   **关键技术细节**：
    *   **软结构化多轮展开（Soft Structured Multi-turn Rollouts）**：定义了一种拓扑序列约束，强制模型显式地对工具获取的证据进行排序和综合，防止模型“盲目”直接给出答案。
    *   **冷启动强化学习（Cold-Start RL）**：采用 **GRPO（组相对策略优化）** 算法。它通过采样一组（Group）不同的推理轨迹，利用组内相对表现来计算优势函数，无需额外的奖励模型（Reward Model）。
    *   **多目标奖励信号**：
        1.  **任务正确性（$R_{corr}$）**：最终答案是否正确。
        2.  **结构完整性（$R_{struct}$）**：轨迹是否符合预设的拓扑结构。
        3.  **工具效用（$R_{tool}$）**：包括语法正确性、执行成功率及工具多样性奖励。
        4.  **终端界定（$R_{term}$）**：是否正确生成结束符，防止无限循环。
    *   **TIU 指标**：提出“工具工具性效用”（Tool Instrumental Utility），通过可靠性、任务对齐度和选择性三个维度量化工具使用的有效性。

### 6. 主要结论与发现

*   **行为转变**：通过强化学习，模型学会了抑制无效的循环调用，并能从工具执行错误中恢复，形成了更线性的“推理-感知-回答”路径。
*   **自发进化**：即使没有人类轨迹引导，模型也能通过环境信号自发学会何时该调用 OCR 或视觉感知工具来辅助决策。

### 7. 优点
*   **无需监督数据**：极大地降低了构建高性能多模态智能体的门槛。
*   **结构化约束有效**：通过拓扑约束解决了 SVLM 常见的“视觉盲区”问题，强制模型“先看后说”。

### 8. 不足与局限
*   **工具库局限**：目前仅集成了视觉类工具（OCR、检测等），缺乏代码解释器或搜索引擎，限制了其处理非视觉类复杂问题的能力。

*   **确认偏差风险**：如果工具返回的信息不够精细，模型可能会利用模糊的工具输出进一步强化其初始的错误判断（见论文中的解剖图案例）。
