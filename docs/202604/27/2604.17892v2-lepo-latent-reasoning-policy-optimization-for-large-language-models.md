## 摘要
最近，隐空间推理（latent reasoning）被引入大语言模型（LLMs），以利用连续空间内的丰富信息。然而，如果没有随机采样，这些方法不可避免地会坍缩为确定性推理，从而无法发现多样化的推理路径。为了弥补这一差距，我们通过 Gumbel-Softmax 向隐空间推理中注入了可控的随机性，恢复了 LLMs 的探索能力，并增强了其与强化学习（RL）的兼容性。在此基础上，我们提出了 LEPO，这是一个直接将强化学习应用于连续隐表征的新型框架。具体而言，在展开（rollout）阶段，LEPO 保持随机性以实现多样化的轨迹采样；而在优化阶段，LEPO 为隐表征和离散标记（tokens）构建了统一的梯度估计。广泛的实验表明，LEPO 在离散和隐空间推理方面显著优于现有的强化学习方法。

## Abstract
Recently, latent reasoning has been introduced into large language models (LLMs) to leverage rich information within a continuous space. However, without stochastic sampling, these methods inevitably collapse to deterministic inference, failing to discover diverse reasoning paths. To bridge the gap, we inject controllable stochasticity into latent reasoning via Gumbel-Softmax, restoring LLMs' exploratory capacity and enhancing their compatibility with Reinforcement Learning (RL). Building on this, we propose \textbf{\underline{L}}atent R\textbf{\underline{e}}asoning \textbf{\underline{P}}olicy \textbf{\underline{O}}ptimization~(\textbf{LEPO}), a novel framework that applies RL directly to continuous latent representations. Specifically, in rollout stage, LEPO maintains stochasticity to enable diverse trajectory sampling, while in optimization stage, LEPO constructs a unified gradient estimation for both latent representations and discrete tokens. Extensive experiments show that LEPO significantly outperforms existing RL methods for discrete and latent reasoning.

### 1. 核心问题与整体含义（研究动机和背景）
传统的思维链（CoT）推理受限于离散 Token 的选择，容易丢失模型内部状态的分布信息。近期研究转向**隐空间推理（Latent Reasoning）**，利用连续向量（如词表概率分布）进行推理以保留更丰富的信息。
然而，现有的隐空间推理方法大多是**确定性**的，缺乏随机采样机制。这导致模型在推理时无法探索多样化的路径（即缺乏“轨迹级探索”），限制了其在强化学习（RL）框架下的优化潜力。本研究旨在通过引入随机性，恢复隐空间推理的探索能力，并提出一套直接优化连续表征的 RL 框架。

### 2. 方法论：核心思想与关键技术
LEPO 框架主要包含两个阶段：
*   **随机轨迹采样（Rollout Stage）：**
    *   **Gumbel-Softmax 注入：** 为了在保持连续性的同时引入随机性，LEPO 使用 Gumbel-Softmax 对模型输出的词表分布进行扰动。这使得模型能够采样出不同的“隐式推理轨迹”。
    *   **混合生成：** 模型先生成 $L_g$ 个随机隐式 Token（连续向量），随后基于这些隐式表征生成离散的答案 Token，从而兼顾推理的深度与结果的可读性。
*   **统一策略优化（Optimization Stage）：**
    *   **统一梯度估计：** LEPO 构建了一个联合目标函数。对于离散 Token，采用标准的策略梯度（如 REINFORCE）；对于隐式 Token，将其视为“软标签（Soft Label）”，通过最大化当前策略与采样向量之间的对齐度来进行优化。
    *   **优势函数：** 使用基于结果的奖励（正确为 1，错误为 0）并进行归一化处理，计算每条轨迹的优势值（Advantage）。

### 3. 实验设计
*   **基础模型：** Qwen2.5 (7B, 3B) 和 Llama3.2-3B-Instruct。
*   **数据集：** 
    *   **数学推理：** GSM8K, MATH500, MinervaMath, AIME2024, AIME2025, AMC23。
    *   **泛化性测试（OOD）：** GPQA-Diamond, ARC-C, MMLU-STEM。
*   **对比方法：** 
    *   离散推理：CoT, GRPO（离散 RL 标杆）。
    *   隐空间推理：Soft Tokens, HRPO, 以及 SFT 类的 Coconut 和 CODI。

### 4. 资源与算力
*   **硬件：** 使用了 **8 台 Nvidia H20 GPU**。
*   **训练时长：** 
    *   Qwen2.5-7B 训练约 **28 小时**。
    *   Qwen2.5-3B 和 Llama3.2-3B 训练约 **20 小时**。
*   **参数设置：** 学习率 $1 \times 10^{-6}$，训练 1 个 Epoch，Global Batch Size 为 32。

### 5. 实验数量与充分性
实验设计非常充分且具有说服力：
*   **多维度评估：** 涵盖了从基础数学到竞赛级难题（AIME）的多个难度梯度。
*   **消融实验：** 详细探讨了隐式 Token 长度（$L_g$）、Gumbel 温度（$\tau_g$）以及不同噪声类型（高斯、狄利克雷）对性能的影响。
*   **动态分析：** 监控了训练过程中的熵（Entropy）变化和 Token 消耗效率。
*   **客观性：** 通过 Pass@1 和 Pass@32 两个指标评估了策略质量和解空间覆盖率，对比了多种最新的 SOTA 方法。

### 6. 主要结论与发现
*   **性能领先：** LEPO 在所有基准测试中均显著优于离散 RL（GRPO）和现有的隐空间 RL 方法。在 Qwen2.5-7B 上，平均 Pass@1 提升了 1.76%，Pass@32 提升了 1.95%。
*   **探索优势：** 随机隐空间推理能将“不可解”的极难问题转化为“可解”的中等难度问题，为 RL 提供了更丰富的奖励信号。
*   **效率提升：** 相比离散推理，LEPO 在达到同等或更高精度时，消耗的 Token 数量更少，推理更高效。
*   **鲁棒性：** 在 OOD 任务上表现出更强的泛化能力。

### 7. 优点
*   **创新性：** 首次将 Gumbel-Softmax 引入隐空间推理，解决了隐空间方法难以进行轨迹探索的痛点。
*   **统一性：** 提出的统一优化目标成功弥合了连续表征与离散 Token 之间的梯度估计鸿沟。
*   **实用性：** 显著降低了推理成本（Token 效率），同时提升了模型在复杂逻辑任务上的表现。

### 8. 不足与局限
*   **可解释性：** 隐式推理步骤在连续空间内运行，人类无法直接阅读其“思考过程”，只能通过解码 Top-1 Token 进行近似观察。
*   **生成范式限制：** 目前采用“先隐式、后离散”的顺序结构，尚不支持隐式思考与离散写作的动态交替（Interleaving）。
*   **任务范围：** 实验主要集中在数学和逻辑推理，对于长文本创作或多模态任务的适用性有待进一步验证。
