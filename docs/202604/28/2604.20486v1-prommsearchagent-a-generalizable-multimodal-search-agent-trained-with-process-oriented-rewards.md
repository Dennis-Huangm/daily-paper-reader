## 摘要
通过强化学习训练用于知识密集型视觉推理的多模态智能体，从根本上受到基于结果的监督极其稀疏以及实时网络环境不可预测性的阻碍。为了解决这些算法和环境瓶颈，我们推出了 ProMMSearchAgent，为多模态搜索建立了一种新颖的“模拟到现实”（Sim-to-Real）训练范式。我们将策略学习解耦到一个确定性的本地静态沙箱中。关键在于，为了在这个受限环境中进行有效学习，我们提出了一种内省式过程导向奖励。通过探测智能体自身的参数化知识边界，我们生成了密集的行为元数据，这些数据明确奖励正确的认知决策，即仅在视觉或事实不确定时才启动多模态或文本搜索。大量实验表明，我们本地训练的策略可以零样本迁移到实时的 Google Search API。ProMMSearchAgent 实现了新的 SOTA 性能，在 FVQA-test 上超过 MMSearch-R1 5.1%，在 InfoSeek 上超过 6.3%，在 MMSearch 上超过 11.3%。

## Abstract
Training multimodal agents via reinforcement learning for knowledge-intensive visual reasoning is fundamentally hindered by the extreme sparsity of outcome-based supervision and the unpredictability of live web environments. To resolve these algorithmic and environmental bottlenecks, we introduce ProMMSearchAgent, establishing a novel Sim-to-Real training paradigm for multimodal search.   We decouple policy learning into a deterministic, local static sandbox. Crucially, to learn effectively within this constrained environment, we propose an introspective process-oriented reward. By probing the agent's own parametric knowledge boundaries, we generate dense behavioral metadata that explicitly rewards the correct cognitive decision, initiating a multimodal or text search only when visually or factually uncertain. Extensive experiments demonstrate that our locally-trained policy transfers zero-shot to the live Google Search API. ProMMSearchAgent achieves new SOTA performance, outperforming MMSearch-R1 by +5.1% on FVQA-test, +6.3% on InfoSeek, and +11.3% on MMSearch.

*   **研究动机**：现有的多模态搜索智能体在强化学习（RL）训练中存在两个核心问题：
    1.  **监督信号稀疏**：仅依赖最终结果（Outcome-based）的奖励会导致模型盲目调用搜索工具。
    2.  **奖励-行为失配**：为了防止过度依赖工具，现有方法常引入“工具惩罚”，但这会导致模型在确实需要搜索的难题面前因害怕惩罚而放弃搜索（即“工具羞怯”）。
    3.  **环境不稳定**：直接在实时网页 API 上训练成本高、延迟大且不可复现。

### 2. 方法论：核心思想与关键技术
论文提出了 **ProMMSearchAgent**，其核心思想是建立一种 **Sim-to-Real（模拟到现实）** 的训练范式：
*   **行为元数据引擎（Behavioral Metadata Engine）**：在训练前，通过多次无工具推理探测模型的“知识边界”。如果模型在多次尝试中均无法直接回答，则标记该样本为“需要搜索”，否则为“无需搜索”。
*   **过程导向奖励（Process-Oriented Reward）**：
    *   将奖励分解为：**结果奖励**（答案正确性）和**过程奖励**（行为对齐 + 格式规范）。
    *   **行为对齐奖励**：如果模型在标记为“需要搜索”的样本上发起了搜索，或在“无需搜索”的样本上直接回答，则给予正向奖励。这解决了奖励-行为失配问题，引导模型识别自身知识盲区。
*   **解耦的工具沙箱（Tool Sandbox）**：构建一个包含 2025 年 Wikipedia 离线 dump 和预计算图像缓存的本地环境。模型在本地沙箱中学习搜索逻辑，而非直接在实时网络上训练。
*   **优化算法**：使用 **GRPO**（群组相对策略优化）算法，在 `veRL` 框架下进行异步强化学习训练。
