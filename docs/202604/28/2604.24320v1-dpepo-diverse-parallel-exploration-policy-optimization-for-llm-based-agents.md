## 摘要
遵循顺序“推理-行动”（reason-then-act）范式的大语言模型（LLM）智能体在许多复杂任务中取得了卓越的性能。然而，由于这些方法每步仅与单个环境交互，因此面临探索受限和环境理解不完整的问题。在本文中，我们首先引入了一种新颖的范式，使智能体能够同时与多个环境交互并共享跨轨迹经验。基于这一范式，我们进一步提出了 DPEPO，这是一种强化学习（RL）算法，旨在鼓励智能体进行多样化的并行探索。DPEPO 包含两个阶段：初始的有监督微调（SFT）赋予智能体基础的并行推理和动作生成能力，随后是采用分层奖励方案的强化学习阶段。我们设计了一个并行轨迹级成功奖励和两个步骤级奖励：多样化动作奖励（Diverse Action Reward）和多样化状态转移奖励（Diverse State Transition Reward），这些奖励主动惩罚行为冗余并促进广泛探索。在 ALFWorld 和 ScienceWorld 上的广泛实验表明，DPEPO 达到了最先进的（SOTA）成功率，同时保持了与强顺序基线模型相当的效率。（代码可在 https://github.com/LePanda026/Code-for-DPEPO 获取）

## Abstract
Large language model (LLM) agents that follow the sequential "reason-then-act" paradigm have achieved superior performance in many complex tasks.However, these methods suffer from limited exploration and incomplete environmental understanding, as they interact with only a single environment per step. In this paper, we first introduce a novel paradigm that enables an agent to interact with multiple environments simultaneously and share cross-trajectory experiences. Building upon this paradigm, we further propose DPEPO, a reinforcement learning (RL) algorithm that encourages the agent to perform diverse parallel exploration. There are two stages in DPEPO: initial supervised fine-tuning (SFT) imparts basic parallel reasoning and action generation, followed by reinforcement learning stage with a hierarchical reward scheme. We design a parallel trajectory-level success reward and two step-level rewards: Diverse Action Reward and Diverse State Transition Reward, which actively penalize behavioral redundancy and promote broad exploration. Extensive experiments on ALFWorld and ScienceWorld show that DPEPO achieves state-of-the-art (SOTA) success rates, while maintaining comparable efficiency to strong sequential baselines. ### 1. 核心问题与整体含义
*   **研究动机**：现有的 LLM 智能体大多遵循 ReAct（推理-行动）的顺序范式，每步仅执行一个动作并观察一个反馈。这种“线性视角”限制了智能体对环境的探索广度，容易导致对环境认知不全，在复杂长程任务中表现不佳。
*   **核心挑战**：简单的多样本采样（Multi-sampling）存在两个缺陷：一是缺乏多样性（动作容易趋同）；二是效率低下且轨迹间经验孤立，导致 Token 消耗和运行时间激增。
*   **整体含义**：本文提出了一种**并行探索范式**，允许智能体同时与多个环境交互并共享跨轨迹经验，通过强化学习优化策略，使其具备构建全面环境认知的水平。

### 2. 方法论
DPEPO 框架分为两个阶段，核心在于通过层次化奖励引导多样化并行探索：
*   **核心思想**：将单线交互扩展为多环境并行交互，利用 LLM 的并行生成能力同时输出多个环境的动作，并设计专门的奖励函数惩罚冗余行为。
*   **关键技术细节**：
    1.  **冷启动阶段（SFT）**：通过少量人工标注和模型合成的并行探索轨迹进行微调，使模型学会 `<parallel>` 标签下的结构化输出格式。
    2.  **强化学习阶段（RL）**：采用类似 GRPO 的无 Critic 架构，通过组内相对优势估计进行策略优化。
    3.  **层次化奖励方案**：
        *   **并行轨迹级成功奖励 ($R_{traj}$)**：只要并行环境中的任一轨迹完成任务，即给予奖励。
        *   **多样化动作奖励 ($R_{action}$)**：包含“深度”（单环境内动作重复）和“宽度”（跨环境间动作重复）两个维度的惩罚。
        *   **多样化状态转移奖励 ($R_{transition}$)**：惩罚重复的“状态-动作”对，强制智能体探索未知的状态空间。
*   **算法流程**：模型在每一步推理出多个动作 -> 在 $K$ 个并行环境中执行 -> 收集反馈 -> 计算层次化奖励 -> 更新策略。

### 3. 实验设计
*   **数据集/场景**：
    *   **ALFWorld**：文本交互式家居任务（如“把铅笔放桌上”），包含 Seen 和 Unseen 任务。
    *   **ScienceWorld**：复杂的科学实验模拟（如电路、生命周期），分为 L0（已知）、L1（未知变体）、L2（完全未知）三个难度等级。
*   **对比方法（Baselines）**：

*   **评估指标**：成功率（Success Rate）、平均步数、Token 消耗、推理时间。

*   **超参数**：训练样本 500 个，并行环境数 $K=4$，最大步数 25。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了从 0.5B 到 8B 不同参数规模的模型（Qwen2.5 和 Qwen3 系列），验证了算法的**可扩展性（Scaling）**。
*   **消融实验**：详细对比了有无 SFT、有无动作奖励（DAR）、有无状态转移奖励（DSTR）的效果，证明了各组件的必要性。
*   **多样性分析**：通过可视化动作重复率、状态转移重复率和轨迹长度，客观展示了 DPEPO 如何减少冗余。
*   **公平性**：在相同的 Token 预算和推理限制下对比了并行与顺序采样的效率，实验设计较为客观。

### 6. 主要结论与发现
*   **性能领先**：DPEPO 在 ALFWorld 达到 98.2% 的成功率，在 ScienceWorld 达到 61.4%，显著超过 DeepSeek-R1 和其他 RL 智能体方法。
*   **效率优势**：尽管是并行探索，但由于 DPEPO 能更快找到正确路径，其**平均轨迹长度更短**，推理时间甚至优于某些顺序执行的强基线（如 GiGPO）。
*   **Token 经济性**：随着并行环境数 $K$ 的增加，DPEPO 的 Token 增长速度远低于传统的独立多样本采样。
*   **探索策略演变**：智能体表现出“先广泛并行探索，后集中单点突破”的智能行为模式。

### 7. 优点
*   **范式创新**：打破了 ReAct 的线性限制，提出了更符合 LLM 并行处理特性的并行探索范式。
*   **奖励设计精巧**：通过“深度+宽度”的双重维度定义多样性，有效解决了 RL 中的探索退化问题。
*   **高训练效率**：相比传统方法，仅需极少的 RL 训练样本（500个）即可获得显著提升。

### 8. 不足与局限
*   **环境依赖性**：该方法假设环境可以被轻易地“克隆”或并行实例化，这在某些现实世界的具身智能场景（如单一实体机器人）中难以实现。
*   **偏见风险**：并行探索可能使智能体接触到更多环境偏见，论文提到需注意安全性和伦理评估。
*   **上下文压力**：虽然设计了 Prompt 压缩方案，但并行环境的反馈仍会快速消耗上下文窗口，对长文本处理能力有一定要求。
