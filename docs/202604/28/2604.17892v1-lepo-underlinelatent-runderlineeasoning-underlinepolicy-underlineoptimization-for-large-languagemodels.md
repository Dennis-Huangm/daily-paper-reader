## 摘要
最近，隐空间推理（latent reasoning）被引入大语言模型（LLMs），以利用连续空间内的丰富信息。然而，如果没有随机采样，这些方法不可避免地会坍缩为确定性推理，从而无法发现多样化的推理路径。为了弥补这一差距，我们通过 Gumbel-Softmax 向隐空间推理中注入了可控的随机性，恢复了 LLMs 的探索能力，并增强了其与强化学习（RL）的兼容性。在此基础上，我们提出了隐空间推理策略优化（LEPO），这是一个直接将强化学习应用于连续隐表征的新型框架。具体而言，在展开（rollout）阶段，LEPO 保持随机性以实现多样化的轨迹采样；而在优化阶段，LEPO 为隐表征和离散标记（tokens）构建了统一的梯度估计。广泛的实验表明，LEPO 在离散推理和隐空间推理方面均显著优于现有的强化学习方法。

## Abstract
Recently, latent reasoning has been introduced into large language models (LLMs) to leverage rich information within a continuous space. However, without stochastic sampling, these methods inevitably collapse to deterministic inference, failing to discover diverse reasoning paths. To bridge the gap, we inject controllable stochasticity into latent reasoning via Gumbel-Softmax, restoring LLMs' exploratory capacity and enhancing their compatibility with Reinforcement Learning (RL). Building on this, we propose \textbf{\underline{L}}atent R\textbf{\underline{e}}asoning \textbf{\underline{P}}olicy \textbf{\underline{O}}ptimization~(\textbf{LEPO}), a novel framework that applies RL directly to continuous latent representations. Specifically, in rollout stage, LEPO maintains stochasticity to enable diverse trajectory sampling, while in optimization stage, LEPO constructs a unified gradient estimation for both latent representations and discrete tokens. Extensive experiments show that LEPO significantly outperforms existing RL methods for discrete and latent reasoning.

以下是对该论文的结构化总结：

### 1. 核心问题与研究动机
*   **核心问题**：传统的离散思维链（CoT）在每一步只选择一个 Token，会丢失模型内部状态的丰富分布信息。虽然现有的“隐空间推理”方法利用了连续向量，但它们大多是**确定性**的（缺乏随机采样），导致模型无法探索多样化的推理路径，且难以与强化学习有效结合。
*   **研究动机**：作者认为探索能力分为“步骤级”和“轨迹级”。现有隐空间方法具备步骤级搜索能力，但牺牲了轨迹级探索。通过引入随机性，可以恢复模型的探索潜力，使模型能够发现更多正确的推理路径，并利用强化学习进行优化。

### 2. 方法论
LEPO 的核心思想是将隐空间推理建模为一个可学习的策略，并直接在连续表征上应用强化学习。
*   **随机隐空间采样（Gumbel-Softmax）**：
    *   在推理阶段，不再直接取概率分布的期望，而是通过 **Gumbel-Softmax** 注入随机噪声。
    *   这种方式满足了三个标准：有效性（保持分布特性）、隐匿性（不坍缩为 One-hot 向量）和忠实性（保留原始分布的核心信息）。
*   **混合展开（Rollout）流程**：
    *   模型首先生成 $L_g$ 个带有随机噪声的**隐 Token**（连续向量）。
    *   随后基于这些隐 Token 生成可读的**离散 Token**（最终答案）。
*   **统一优化目标**：
    *   **离散部分**：使用标准的 REINFORCE 算法，根据奖励（正确性）最大化所选 Token 的对数似然。
    *   **隐空间部分**：提出一种“软代理目标”（Soft Surrogate Objective），将采样的随机向量视为“软标签”，通过优势函数（Advantage）加权，使当前策略向高奖励的隐表征对齐。
    *   最终将两部分梯度结合，实现对内部推理过程和最终输出的统一监督。

### 3. 实验设计
*   **数据集/场景**：
    *   **数学推理**：GSM8K, MATH500, MinervaMath, AIME2024, AIME2025, AMC23。
    *   **泛化性/OOD（出域）测试**：GPQA-Diamond, ARC-C, MMLU-STEM。
*   **基准模型**：Qwen2.5 (7B, 3B) 和 Llama3.2-3B-Instruct。
*   **对比方法**：
    *   **离散 RL**：GRPO（DeepSeek 提出的一种高效 RL 算法）。
    *   **隐空间 RL**：Soft Tokens, HRPO。
    *   **推理方法**：标准 CoT, 确定性隐空间推理。

### 4. 资源与算力
*   **硬件**：使用了 **8 台 Nvidia H20 GPU**。
*   **训练时长**：
    *   Qwen2.5-7B：约 28 小时。
    *   Qwen2.5-3B 和 Llama-3.2-3B：约 20 小时。
*   **超参数**：Batch Size 为 32，Group Size 为 8，学习率 $1 \times 10^{-6}$。

### 5. 实验数量与充分性
*   **实验规模**：在 3 个不同规模和架构的基础模型上进行了验证，涵盖了 9 个主流基准测试集。
*   **消融实验**：非常充分。作者研究了隐空间长度（$L_g$）、Gumbel 温度（$\tau_g$）、噪声类型（对比了高斯噪声和狄利克雷噪声）对性能的影响。
*   **客观性**：通过 Pass@1 和 Pass@32 两个指标衡量性能，既评估了策略质量，也评估了搜索空间的覆盖率。同时对比了 SFT 基础的隐空间方法（如 Coconut, CODI），证明了 RL 优化的优越性。

### 6. 主要结论与发现
*   **性能领先**：LEPO 在所有基准测试中均优于离散 RL（GRPO）和现有的隐空间 RL 方法。在 Qwen2.5-7B 上，Pass@1 平均提升了 1.76%，Pass@32 提升了 1.95%。
*   **探索机制的价值**：随机性将“不可解”的难题转化为了“中等难度”的可解题目，为 RL 提供了更密集的奖励信号。
*   **Token 效率**：LEPO 在训练过程中表现出更高的 Token 利用效率，相比 GRPO，它能用更短的序列长度达到更高的准确率。
*   **熵的维持**：LEPO 在训练过程中能保持更高的策略熵，避免了过早陷入局部最优。

### 7. 优点
*   **理论完备性**：通过 Gumbel-Softmax 解决了隐空间推理不可导或难以采样的痛点。
*   **统一框架**：成功将连续表征和离散 Token 纳入同一个梯度估计框架，实现了端到端的优化。
*   **效率与性能并重**：不仅提升了准确率，还通过隐空间压缩减少了推理所需的 Token 数量。

### 8. 不足与局限
*   **可解释性挑战**：隐空间推理步骤对人类来说是不可读的（虽然可以解码 Top-1 Token 来近似查看，但本质上是连续向量）。
*   **生成范式限制**：目前采用“先隐空间思考、后离散输出”的固定顺序，不支持隐空间和离散 Token 的动态交替（即边写边想）。
*   **任务范围**：实验主要集中在数学和科学推理上，在更广泛的创意写作或多轮对话任务中的表现尚待验证。
