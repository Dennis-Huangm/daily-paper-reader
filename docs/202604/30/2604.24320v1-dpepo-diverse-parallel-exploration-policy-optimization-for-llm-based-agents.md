## 摘要
遵循顺序“推理-行动”范式的大语言模型（LLM）智能体在许多复杂任务中取得了卓越的性能。然而，由于这些方法每步仅与单个环境交互，因此面临探索受限和环境理解不完整的问题。在本文中，我们首先引入了一种新颖的范式，使智能体能够同时与多个环境交互并共享跨轨迹经验。基于这一范式，我们进一步提出了 DPEPO，这是一种鼓励智能体进行多样化并行探索的强化学习（RL）算法。DPEPO 包含两个阶段：初始的有监督微调（SFT）赋予基础的并行推理和动作生成能力，随后是采用分层奖励方案的强化学习阶段。我们设计了一个并行轨迹级成功奖励和两个步骤级奖励：多样化动作奖励（Diverse Action Reward）和多样化状态转移奖励（Diverse State Transition Reward），旨在主动惩罚行为冗余并促进广泛探索。在 ALFWorld 和 ScienceWorld 上的广泛实验表明，DPEPO 实现了最先进的（SOTA）成功率，同时保持了与强顺序基线相当的效率。（代码可在 https://github.com/LePanda026/Code-for-DPEPO 获取）

## Abstract
Large language model (LLM) agents that follow the sequential "reason-then-act" paradigm have achieved superior performance in many complex tasks.However, these methods suffer from limited exploration and incomplete environmental understanding, as they interact with only a single environment per step. In this paper, we first introduce a novel paradigm that enables an agent to interact with multiple environments simultaneously and share cross-trajectory experiences. Building upon this paradigm, we further propose DPEPO, a reinforcement learning (RL) algorithm that encourages the agent to perform diverse parallel exploration. There are two stages in DPEPO: initial supervised fine-tuning (SFT) imparts basic parallel reasoning and action generation, followed by reinforcement learning stage with a hierarchical reward scheme. We design a parallel trajectory-level success reward and two step-level rewards: Diverse Action Reward and Diverse State Transition Reward, which actively penalize behavioral redundancy and promote broad exploration. Extensive experiments on ALFWorld and ScienceWorld show that DPEPO achieves state-of-the-art (SOTA) success rates, while maintaining comparable efficiency to strong sequential baselines. ### 1. 核心问题与研究动机
*   **核心问题**：传统的 LLM 智能体通常遵循 **ReAct（推理-行动）** 范式，这是一种线性的、顺序的交互方式。在这种模式下，智能体每步只能执行一个动作并观察一个反馈，导致其对环境的探索极其有限，容易产生片面或错误的认知，在复杂、长程任务中表现不佳。
*   **研究动机**：虽然可以通过多次独立采样（Multi-sampling）来增加探索，但这种方式存在**缺乏多样性**（动作容易收敛到相似选择）和**效率低下**（不同轨迹间经验不共享、Token 消耗大）的问题。因此，作者提出需要一种能够让智能体“同时在多个平行宇宙中探索”并共享经验的新范式。

### 2. 方法论
DPEPO 提出了一种**并行探索策略优化**框架，核心流程分为两个阶段：
*   **核心思想**：允许智能体在每一步同时与 $K$ 个环境交互，通过多样性奖励机制强制智能体在不同环境中尝试不同的路径，从而构建对环境的全面认知。
*   **关键技术细节**：
    1.  **冷启动阶段（SFT）**：通过人工标注和模型合成（如 DeepSeek-V3）生成包含并行探索行为的数据集（约 500-1000 条），让模型学会使用 `<parallel>` 标签和并行推理格式。
    2.  **强化学习阶段（RL）**：基于 **GRPO**（组相对策略优化）算法，无需 Critic 模型，通过组内奖励排名估计优势。
    3.  **分层奖励方案（Hierarchical Reward）**：
        *   **轨迹级成功奖励 ($R_{traj}$)**：只要并行环境中的任何一个达到目标状态，即给予奖励。
        *   **步骤级多样性奖励 ($R_{step}$)**：
            *   **多样化动作奖励 (DAR)**：惩罚在单个环境内（深度）或跨环境（宽度）重复执行相同动作的行为。
            *   **多样化状态转移奖励 (DSTR)**：惩罚重复的“状态-动作”转换对，鼓励智能体探索未知的状态空间。
    4.  **优势计算**：结合轨迹级优势和步骤级奖励，为每个并行步骤分配信用（Credit Assignment）。

### 3. 实验设计
*   **数据集/场景**：
    *   **ALFWorld**：文本交互式家庭任务环境（如“把铅笔放回桌子”），考察常识推理。
    *   **ScienceWorld**：复杂的科学实验模拟环境（涵盖电力、化学反应等 10 个领域），任务具有多级子目标。
*   **Benchmark 与对比方法**：
    *   **闭源模型**：GPT-4o, DeepSeek-V3, DeepSeek-R1。
    *   **强化学习基线**：GRPO, GiGPO（锚点状态组）, RLVMR（元推理奖励）, SPEAR（自模仿学习）。
    *   **模型底座**：Qwen2.5 (1.5B, 7B) 和 Qwen3 (0.5B 到 8B)。

### 4. 资源与算力
*   **算力配置**：
    *   **Qwen2.5-1.5B**：使用 4 张 **NVIDIA L40** GPU。
    *   **Qwen2.5-7B**：使用 4 张 **NVIDIA H20** GPU。
*   **训练时长**：
    *   DPEPO 在 500 个样本上训练 1 个 epoch（约 125 个迭代步），总训练时间约为 **24 小时**（含 SFT 阶段）。
    *   相比之下，基线方法 GiGPO 达到峰值性能需要约 96 小时。

### 5. 实验数量与充分性
*   **实验规模**：论文涵盖了主实验（两个基准测试的所有任务划分）、模型缩放实验（Scaling Law）、环境数量 $K$ 的敏感性分析、消融实验、效率分析（Token 和推理时间）以及案例研究。
*   **充分性评价**：实验设计非常充分且客观。作者不仅对比了成功率，还深入分析了**探索动力学**（如动作重复率、轨迹长度），并公平地对比了在相同 Token 预算下的性能表现。

### 6. 主要结论与发现
*   **性能领先**：DPEPO 在 ALFWorld 达到 **98.2%** 的成功率，在 ScienceWorld 达到 **61.4%**，显著超过了 DeepSeek-R1 和其他 RL 智能体方法。
*   **高效性**：尽管使用了并行探索，但由于智能体能更快找到正确路径，其**平均轨迹步数更短**，推理时间甚至比一些顺序探索的强基线（如 GiGPO）更短。
*   **缩放效应**：随着模型参数量增加（从 0.5B 到 8B），DPEPO 的性能稳步提升，显示出良好的泛化能力。
*   **多样性价值**：消融实验证明，DAR 和 DSTR 奖励能有效降低行为冗余，提高探索效率。

### 7. 优点
*   **范式创新**：打破了 ReAct 的线性限制，提出了并行环境交互的新范式。
*   **奖励设计精巧**：通过“深度+宽度”的双维度多样性奖励，解决了 LLM 容易陷入重复行为的顽疾。
*   **训练效率高**：相比传统的 PPO 或其他复杂的 RL 方案，DPEPO 样本利用率极高，训练成本相对较低。
*   **推理优化**：通过精心设计的 Prompt 策略管理长上下文，平衡了信息保留与计算开销。

### 8. 不足与局限
*   **环境构建限制**：该方法依赖于能够被“并行实例化”的环境。在现实世界的具身智能体（如实体机器人）场景中，构建多个完全一致的并行物理环境非常困难且昂贵。
*   **上下文窗口压力**：虽然有 Prompt 压缩策略，但并行探索产生的观察结果仍会快速消耗上下文窗口，限制了极长任务的处理。
*   **偏见风险**：并行探索可能让智能体在包含偏见的环境中收集到更多负面经验，需注意安全评估。
