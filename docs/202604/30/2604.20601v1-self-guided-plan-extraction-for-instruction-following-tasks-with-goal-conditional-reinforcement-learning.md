## 摘要
我们介绍了 SuperIgor，一个用于指令遵循任务的框架。与以往依赖预定义子任务的方法不同，SuperIgor 使语言模型能够通过自学习机制生成并优化高层计划，从而减少了对手动数据集标注的需求。我们的方法涉及迭代协同训练：训练强化学习（RL）智能体以遵循生成的计划，同时语言模型根据 RL 的反馈和偏好调整并修改这些计划。这创建了一个反馈循环，使智能体和规划器能够共同提升。我们在具有丰富动力学特性和随机性的环境中验证了我们的框架。结果表明，SuperIgor 智能体比基准方法更严格地遵循指令，同时也展现出对先前未见指令的强大泛化能力。

## Abstract
We introduce SuperIgor, a framework for instruction-following tasks. Unlike prior methods that rely on predefined subtasks, SuperIgor enables a language model to generate and refine high-level plans through a self-learning mechanism, reducing the need for manual dataset annotation. Our approach involves iterative co-training: an RL agent is trained to follow the generated plans, while the language model adapts and modifies these plans based on RL feedback and preferences. This creates a feedback loop where both the agent and the planner improve jointly. We validate our framework in environments with rich dynamics and stochasticity. Results show that SuperIgor agents adhere to instructions more strictly than baseline methods, while also demonstrating strong generalization to previously unseen instructions.

### 2. 方法论
SuperIgor 采用迭代协同训练循环，包含以下核心步骤：
*   **自引导计划提取（LLM端）**：
    *   **子任务库构建**：从指令集中提取并规范化可能的子任务。
    *   **本体构建（Ontology Construction）**：LLM 识别子任务间的先验依赖关系（例如：挖铁矿前必须先有石镐），生成本体图。
    *   **计划扩展**：根据本体图将高级指令展开为线性化的子任务序列。
*   **策略学习（RL端）**：
    *   **技能课程学习（Skill Curriculum Learning）**：智能体从单步任务开始，只有在掌握（成功率 > $\tau$）当前子任务后，才在课程中加入包含该子任务的更复杂长程计划。
    *   **动作空间增强**：引入 `DONE` 动作，让智能体自主决定何时完成当前子任务并切换到计划的下一步。
*   **闭环优化（DPO）**：
    *   利用 RL 代理在环境中的实际执行成功率作为偏好信号，通过**直接偏好优化（DPO）**对 LLM 进行微调。这使得 LLM 能够学习并优先生成那些“智能体更容易学会且更符合环境逻辑”的计划。

*   **性能卓越**：SuperIgor 在原子任务和组合任务上的成功率远超仅依赖指令的基准方法（成功率提升约 2-4 倍）。

*   **解耦设计**：将高层规划（LLM）与底层执行（RL）解耦，降低了长程任务的学习难度。

*   **计算开销**：虽然比手动标注便宜，但迭代训练 LLM 和大规模 RL 采样仍需要可观的算力支持。
