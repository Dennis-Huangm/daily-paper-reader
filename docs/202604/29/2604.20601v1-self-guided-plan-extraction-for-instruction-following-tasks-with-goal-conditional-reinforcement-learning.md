## 摘要
我们介绍了 SuperIgor，这是一个用于指令遵循任务的框架。与以往依赖预定义子任务的方法不同，SuperIgor 使语言模型能够通过自学习机制生成并优化高层计划，从而减少了对手动数据集标注的需求。我们的方法涉及迭代协同训练：训练强化学习（RL）智能体以遵循生成的计划，同时语言模型根据 RL 的反馈和偏好调整并修改这些计划。这形成了一个反馈循环，使得智能体和规划器能够共同提升。我们在具有丰富动力学特性和随机性的环境中验证了该框架。结果表明，SuperIgor 智能体比基准方法更严格地遵循指令，同时也展现出对先前未见指令的强大泛化能力。

## Abstract
We introduce SuperIgor, a framework for instruction-following tasks. Unlike prior methods that rely on predefined subtasks, SuperIgor enables a language model to generate and refine high-level plans through a self-learning mechanism, reducing the need for manual dataset annotation. Our approach involves iterative co-training: an RL agent is trained to follow the generated plans, while the language model adapts and modifies these plans based on RL feedback and preferences. This creates a feedback loop where both the agent and the planner improve jointly. We validate our framework in environments with rich dynamics and stochasticity. Results show that SuperIgor agents adhere to instructions more strictly than baseline methods, while also demonstrating strong generalization to previously unseen instructions.

*   **研究动机**：利用大语言模型（LLM）的世界知识进行高层规划，并通过强化学习（RL）的反馈不断优化这些计划，构建一个无需人工干预的自引导学习闭环。

#### 2. 方法论
SuperIgor 采用 **LLM 规划器与 RL 执行器迭代协同训练** 的架构，核心流程包含四个阶段：
*   **计划生成（Plan Generation）**：
    *   **本体构建（Ontology Construction）**：LLM 提取指令中的子任务并识别前置依赖关系，形成一个任务本体图。
    *   **计划展开**：根据本体图将高层指令分解为结构化的子任务序列（Plan）。
*   **策略学习（Policy Learning）**：
    *   使用 **PPO 算法** 训练底层策略。
    *   **技能课程学习（Skill Curriculum Learning）**：从简单的单步任务开始，只有当智能体掌握（成功率达标）当前子任务后，才引入包含该任务的更复杂组合任务，解决稀疏奖励下的信用分配问题。
*   **计划验证（Plan Validation）**：在随机环境中多次运行智能体，评估生成计划的实际成功率。
*   **LLM 微调（LLM Fine-Tuning）**：
    *   利用 **直接偏好优化（DPO）**，将执行成功率高的计划作为正样本，失败的作为负样本，微调 LLM 使其生成的计划更符合环境动力学和智能体的执行能力。

*   **场景与数据集**：在 **CrafText** 基准测试（一个动态、部分可观测、类似《我的世界》的开放世界环境）中进行。使用了专门构建的 **FOCUS 数据集**，包含 900 多条指令。

*   **性能领先**：SuperIgor 在组合任务上的成功率远超 PPO-T 等基准方法（0.21 vs 0.08）。
*   **泛化性强**：在处理“新对象组合”时，SuperIgor 的表现比 Oracle 模型更稳健，说明 LLM 生成的多样化计划有助于智能体学习更具通用性的技能。

#### 7. 优点
*   **全自动闭环**：实现了从原始指令到任务分解再到策略执行的全流程自动化，无需人工标注子任务。
*   **课程学习机制**：巧妙地解决了开放世界中长程任务奖励极度稀疏的难题。
*   **自适应进化**：通过 DPO 让规划器“理解”执行器的极限，实现了规划与执行的深度对齐。

#### 8. 不足与局限
*   **对初始 LLM 的依赖**：如果底层 LLM 无法生成逻辑自洽的初始本体（如出现循环依赖），整个框架的效能会大幅下降。

*   **诊断困难**：当训练停滞时，难以直观判断是 RL 探索不足还是 LLM 计划分解存在逻辑缺陷。
