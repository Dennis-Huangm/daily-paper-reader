## 摘要
遵循顺序“推理-行动”（reason-then-act）范式的大语言模型（LLM）智能体在许多复杂任务中取得了卓越的性能。然而，由于这些方法每步仅与单个环境交互，因此面临探索受限和环境理解不完整的问题。在本文中，我们首先引入了一种新颖的范式，使智能体能够同时与多个环境交互并共享跨轨迹经验。基于这一范式，我们进一步提出了 DPEPO，这是一种鼓励智能体进行多样化并行探索的强化学习（RL）算法。DPEPO 包含两个阶段：初始的有监督微调（SFT）赋予智能体基础的并行推理和动作生成能力，随后是采用分层奖励方案的强化学习阶段。我们设计了一个并行轨迹级成功奖励和两个步骤级奖励：多样化动作奖励和多样化状态转移奖励，旨在主动惩罚行为冗余并促进广泛探索。在 ALFWorld 和 ScienceWorld 上的广泛实验表明，DPEPO 达到了最先进（SOTA）的成功率，同时保持了与强顺序基线模型相当的效率。（代码可在 https://github.com/LePanda026/Code-for-DPEPO 获取）

## Abstract
Large language model (LLM) agents that follow the sequential "reason-then-act" paradigm have achieved superior performance in many complex tasks.However, these methods suffer from limited exploration and incomplete environmental understanding, as they interact with only a single environment per step. In this paper, we first introduce a novel paradigm that enables an agent to interact with multiple environments simultaneously and share cross-trajectory experiences. Building upon this paradigm, we further propose DPEPO, a reinforcement learning (RL) algorithm that encourages the agent to perform diverse parallel exploration. There are two stages in DPEPO: initial supervised fine-tuning (SFT) imparts basic parallel reasoning and action generation, followed by reinforcement learning stage with a hierarchical reward scheme. We design a parallel trajectory-level success reward and two step-level rewards: Diverse Action Reward and Diverse State Transition Reward, which actively penalize behavioral redundancy and promote broad exploration. Extensive experiments on ALFWorld and ScienceWorld show that DPEPO achieves state-of-the-art (SOTA) success rates, while maintaining comparable efficiency to strong sequential baselines. ### 1. 核心问题与整体含义（研究动机和背景）
目前基于大语言模型（LLM）的智能体主要遵循 **ReAct**（推理-行动）范式，即在每一步中选择单个动作并观察反馈。这种线性、顺序的交互方式存在两个核心缺陷：
*   **探索受限**：智能体只能从狭窄的线性视角构建对环境的认知，容易陷入局部最优或因理解不全导致任务失败。
*   **效率低下**：虽然可以通过多次独立采样来增加探索，但不同轨迹间缺乏经验共享，且动作往往趋同（缺乏多样性），导致计算资源浪费。

本文提出了 **DPEPO** 框架，旨在通过**并行探索**范式，让智能体同时与多个环境交互并共享经验，从而构建更全面的环境认知。

### 2. 方法论
DPEPO 包含两个主要阶段，并引入了创新的分层奖励机制：

*   **核心思想**：将传统的单线交互扩展为并行交互，允许智能体在单步内对多个环境副本执行不同动作，并利用强化学习优化其探索的多样性。
*   **阶段一：有监督微调（SFT）冷启动**：
    *   通过人工标注和模型合成（如 DeepSeek-V3）生成包含并行探索行为的数据集。
    *   训练模型掌握特定的输出格式（如使用 `<parallel>` 和 `<env_i>` 标签）以及基础的并行推理能力。
*   **阶段二：强化学习优化（基于 GRPO）**：
    *   **并行轨迹级成功奖励 ($R_{traj}$)**：只要并行环境中的任何一个达到目标状态，即判定为成功。
    *   **并行步级多样性奖励 ($R_{step}$)**：
        1.  **多样化动作奖励 (DAR)**：惩罚在单个环境内（深度）或跨环境（宽度）重复执行相同动作的行为。
        2.  **多样化状态转移奖励 (DSTR)**：惩罚重复的“状态-动作”转移对，强制智能体尝试未探索过的路径。
    *   **策略优化**：采用 **GRPO**（组相对策略优化）算法，通过组内样本的相对奖励估计优势函数（Advantage），无需额外的 Critic 模型，降低了训练开销。

### 5. 实验数量与充分性
实验设计非常详尽且具有说服力：
*   **多维度对比**：涵盖了不同模型规模（1.5B 到 7B）和不同基准测试。
*   **消融实验**：分别验证了冷启动（SFT）、多样化动作奖励（DAR）和状态转移奖励（DSTR）的必要性。
*   **效率分析**：对比了推理时的 Token 消耗和实际耗时，证明了并行化虽然增加了单步 Token，但缩短了总步数和推理时间。

### 6. 主要结论与发现
*   **性能领先**：DPEPO 在 ALFWorld（98.2%）和 ScienceWorld（61.4%）上均刷新了 SOTA 记录。
*   **泛化能力强**：在 Unseen 任务和更高难度的 ScienceWorld L2 任务中表现出显著的优势。
*   **高效探索**：通过并行化，智能体能更快找到解决方案。虽然单步 Token 增加，但由于总步数减少，整体推理时间反而比一些强基线（如 DeepSeek-R1）更短。
*   **多样性奖励的关键性**：消融实验证明，如果没有多样性奖励，智能体容易产生行为冗余，导致性能大幅下降。

### 7. 优点
*   **范式创新**：打破了 ReAct 的线性限制，提出了更符合 LLM 批处理特性的并行探索范式。
*   **奖励设计精巧**：DAR 和 DSTR 有效解决了强化学习中常见的“探索-利用”平衡问题，减少了无效的重复尝试。
*   **训练高效**：基于 GRPO 的无 Critic 架构结合高质量的并行样本，显著缩短了训练周期。

### 8. 不足与局限
*   **环境依赖性**：该方法依赖于能够被“并行化”或“实例化多个副本”的环境。在某些无法轻易复制状态的现实物理场景（如单体机器人硬件）中，应用难度较大。

*   **安全与偏差风险**：论文提到，更广泛的探索可能导致智能体在包含偏见的环境中学习到不安全或不公正的行为，需加强安全对齐。
