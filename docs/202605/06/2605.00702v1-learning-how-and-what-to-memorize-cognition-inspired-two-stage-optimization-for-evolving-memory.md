## 摘要
大语言模型（LLM）智能体需要长期用户记忆来实现一致的个性化，但有限的上下文窗口阻碍了在长期交互中追踪演化的偏好。现有的记忆系统主要依赖于静态的手工更新规则；虽然基于强化学习（RL）的智能体可以学习记忆更新，但稀疏的结果奖励提供了较弱的监督，导致长时程优化不稳定。借鉴记忆图式理论以及前额叶区域与海马体区域之间的功能划分，我们提出了 MemCoE，这是一个受认知启发的两阶段优化框架，用于学习记忆应如何组织以及更新哪些信息。在第一阶段，我们提出了记忆指南归纳（Memory Guideline Induction），通过解释为文本梯度的对比反馈来优化全局指南；在第二阶段，指南对齐的记忆策略优化（Guideline-Aligned Memory Policy Optimization）利用归纳出的指南来定义结构化的过程奖励，并进行多轮强化学习，以学习遵循指南的记忆演化策略。我们在三个个性化记忆基准上进行了评估，涵盖了显式/隐式偏好以及不同的规模和噪声，并观察到相比强基准线有持续的改进，且具有良好的鲁棒性、可迁移性和效率。

## Abstract
Large language model (LLM) agents require long-term user memory for consistent personalization, but limited context windows hinder tracking evolving preferences over long interactions. Existing memory systems mainly rely on static, hand-crafted update rules; although reinforcement learning (RL)-based agents learn memory updates, sparse outcome rewards provide weak supervision, resulting in unstable long-horizon optimization. Drawing on memory schema theory and the functional division between prefrontal regions and hippocampus regions, we introduce MemCoE, a cognition-inspired two-stage optimization framework that learns how memory should be organized and what information to update. In the first stage, we propose Memory Guideline Induction to optimize a global guideline via contrastive feedback interpreted as textual gradients; in the second stage, Guideline-Aligned Memory Policy Optimization uses the induced guideline to define structured process rewards and performs multi-turn RL to learn a guideline-following memory evolution policy. We evaluate on three personalization memory benchmarks, covering explicit/implicit preference and different sizes and noise, and observe consistent improvements over strong baselines with favorable robustness, transferability, and efficiency.

### 论文总结：Learning How and What to Memorize (MemCoE)

#### 1. 核心问题与整体含义（研究动机和背景）
大语言模型（LLM）智能体在提供个性化服务时，受限于有限的上下文窗口，难以在长期的用户交互中持续追踪演化的偏好。现有的记忆系统主要面临两大挑战：
*   **静态规则的局限性：** 许多系统依赖手工设计的提取和更新规则，缺乏灵活性，难以适应不同用户行为。
*   **强化学习（RL）的不稳定性：** 现有的基于 RL 的记忆更新方法通常依赖稀疏的“结果奖励”（如最终回答是否正确），导致在长程优化中探索空间过大、训练不稳定。

**研究动机：** 受认知心理学中“记忆图式理论（Memory Schema Theory）”启发，论文模拟大脑中**前额叶（负责组织模式/图式）**与**海马体（负责填充具体情节细节）**的功能分工，提出了 **MemCoE** 框架，旨在解耦“如何组织记忆”与“记忆什么内容”。

#### 2. 方法论：核心思想与关键技术
MemCoE 采用两阶段优化框架：

*   **第一阶段：记忆指南归纳 (Memory Guideline Induction, MGI)**
    *   **核心思想：** 学习“如何记忆”。将记忆更新指令（Prompt）视为全局自然语言参数进行优化。
    *   **关键技术：** 
        1.  **对比反馈作为文本梯度：** 比较正确和错误的记忆演化轨迹，利用 LLM 生成自然语言形式的“文本梯度”，指出当前指南的不足。
        2.  **批次梯度聚合：** 在 mini-batch 层面汇总多个实例的反馈，通过总结和抽象形成稳定的全局更新信号，避免过拟合于单一对话。
*   **第二阶段：指南对齐的记忆策略优化 (Guideline-Aligned Memory Policy Optimization, GMPO)**
    *   **核心思想：** 学习“记忆什么”。在固定第一阶段诱导出的指南基础上，优化具体的记忆更新策略。
    *   **关键技术：**
        1.  **指南对齐奖励 (Guideline-aligned rewards)：** 除了最终的回答正确性奖励外，引入“过程奖励”，即评估记忆更新是否严格遵循了第一阶段定义的结构和规则。
        2.  **多轮强化学习：** 使用 **GRPO (Group Relative Policy Optimization)** 算法，在多轮对话轨迹上进行策略梯度更新，使模型学会选择性地保留对下游任务最有用的信息。

#### 6. 主要结论与发现
*   **性能领先：** MemCoE 在所有基准测试中均显著优于强基线模型，尤其在处理 128K 超长上下文和高噪声环境时优势明显。
*   **稳定性：** 通过引入“指南对齐奖励”，解决了传统 RL 记忆更新中由于奖励稀疏导致的训练不稳定问题。
*   **效率：** 相比于频繁调用 LLM 进行提取和合并的方案，MemCoE 将更新逻辑内化到模型策略中，具有更好的推理效率。
*   **记忆保留：** 案例分析显示，MemCoE 能在多轮演化中更好地保留初始注入的用户偏好，而基线模型容易随轮数增加而产生“记忆漂移”。

#### 7. 优点（亮点）
*   **认知启发：** 巧妙地将认知心理学理论转化为工程上的两阶段优化架构（组织 vs. 内容）。

*   **过程监督：** 通过“指南”为 RL 提供结构化的过程奖励，降低了长程记忆优化的难度。
*   **强迁移性：** 诱导出的自然语言指南具有模型无关性，展现了极高的实用价值。

#### 8. 不足与局限
*   **评分器依赖：** 第二阶段的奖励计算依赖于 LLM 作为评分器，评分器的可靠性可能影响训练效果。

*   **隐私风险：** 尽管指南中包含隐私保护规则，但长期记忆系统本质上仍存在过度收集用户敏感信息的潜在风险。
