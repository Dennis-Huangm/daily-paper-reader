## 摘要
智能体强化学习利用多轮轨迹训练大语言模型，这些轨迹交织了长推理链与短环境交互动作。常见的策略梯度方法（如 PPO 和 GRPO）对轨迹中的每个 token 一视同仁，导致了均匀的信用分配。本文批判性地证明，这种均匀的信用分配在很大程度上错配了 token 级的训练信号。从基于能量建模的视角出发，我们展示了 token 级的训练信号（通过其与从给定提示词采样出的不同 rollout 奖励方差的相关性来量化）急剧集中在动作 token 而非推理 token 上，尽管动作 token 仅占轨迹的一小部分。我们将这一现象称为“动作瓶颈”。受此启发，我们提出了一种极其简单的 token 重加权方法 ActFocus，它降低了推理 token 的梯度权重，并结合一种额外的基于能量的再分配机制，进一步增加了具有更高不确定性的动作 token 的权重。在四种环境和不同模型规模下，ActFocus 的表现始终优于 PPO 和 GRPO，在不增加任何额外运行时间或内存成本的情况下，最终步的增益分别高达 65.2 和 63.7 个百分点。

## Abstract
Agentic reinforcement learning trains large language models using multi-turn trajectories that interleave long reasoning traces with short environment-facing actions. Common policy-gradient methods, such as PPO and GRPO, treat each token in a trajectory equally, leading to uniform credit assignment. In this paper, we critically demonstrate that such uniform credit assignment largely misallocates token-level training signals. From an energy-based modeling perspective, we show that token-level training signals, quantified by their correlations with reward variance of different rollouts sampled from a given prompt, concentrate sharply on action tokens rather than reasoning tokens, even though action tokens account for only a small fraction of the trajectory. We refer to this phenomenon as the Action Bottleneck. Motivated by this observation, we propose an embarrassingly simple token reweighting approach, ActFocus, that downweights gradients on reasoning tokens, along with an additional energy-based redistribution mechanism that further increases the weights on action tokens with higher uncertainty. Across four environments and different model sizes, ActFocus consistently outperforms PPO and GRPO, yielding final-step gains of up to 65.2 and 63.7 percentage points, respectively, without any additional runtime or memory cost.

在智能体强化学习（Agentic RL）中，大语言模型（LLM）生成的轨迹通常包含长篇累牍的推理过程（Reasoning）和极短的关键动作（Action）。现有的主流算法（如 PPO 和 GRPO）通常采用**均匀信用分配（Uniform Credit Assignment）**，即对轨迹中的每一个 token 分配相同的梯度权重。

论文指出，这种做法会导致训练信号的严重错配。通过能量建模分析，作者发现：
*   **动作瓶颈（Action Bottleneck）**：尽管动作 token 仅占轨迹的极小比例（如在 Sokoban 任务中仅占 4%），但它们与奖励的变动性（Reward Variance）高度相关。
*   **信号稀疏性**：推理 token 虽然数量庞大，但其 token 级能量与最终奖励的相关性几乎为零。
*   **研究目标**：通过重新分配 token 级的信用权重，将优化重点从冗长的推理转向关键的动作决策。

#### 2. 方法论：ActFocus
作者提出了一种名为 **ActFocus** 的 token 重加权机制，其核心思想是“抑制推理，聚焦动作”。

*   **核心思想**：利用结构化标签（如 `<think>` 和 `<answer>`）区分推理与动作，并引入基于冻结参考模型（Frozen Reference Model）的能量值来衡量动作的不确定性。
*   **关键技术细节**：
    1.  **推理 token 降权**：为推理部分的 token 分配一个较小的权重因子 $\alpha$（通常 $\alpha < 1$）。
    2.  **动作 token 能量加权**：利用参考模型的 Free Energy $E_t = -\log \sum_{v \in V} \exp(f^{ref}_{t,v})$ 来量化 token 级不确定性。
    3.  **权重公式**：
        *   若 $t \in \text{推理区}$，$w_t = \alpha$。
        *   若 $t \in \text{动作区}$，$w_t = 1 + \beta \cdot \text{sigmoid}(\frac{E_t - \mu_E}{\sigma_E})$，其中 $\beta$ 控制能量调制的强度。
    4.  **损失函数集成**：将 $w_t$ 引入 PPO 或 GRPO 的代理损失函数中，通过加权求和代替简单的 token 平均。

*   **任务范围**：实验主要集中在具有明确动作空间的智能体任务上，对于纯开放式长文本生成任务的适用性尚未验证。
