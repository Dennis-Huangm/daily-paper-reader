## 摘要
强化学习（RL）已成为大语言模型（LLM）智能体训练后的核心范式，但其轨迹级奖励信号仅为长程交互提供粗粒度的监督。同策略自蒸馏（OPSD）通过引入来自增强了特权上下文的教师分支的密集 Token 级引导，对 RL 进行了补充。然而，将 OPSD 迁移到多轮智能体中存在挑战：复合的多轮不稳定性会使监督失效，而基于技能条件的特权引导需要非对称处理，因为教师的负面拒绝可能源于不完善的技能检索或利用。我们提出了 SDAR（自蒸馏智能体强化学习），它将 OPSD 视为门控辅助目标，同时保持 RL 作为主要的优化骨干。SDAR 将分离的 Token 级信号映射到 Sigmoid 门控中，加强了对教师认可的正差距（positive-gap）Token 的蒸馏，并软性地削弱了教师的负面拒绝。在 ALFWorld、WebShop 和 Search-QA 任务上，基于 Qwen2.5 和 Qwen3 系列模型，SDAR 相比 GRPO 取得了显著提升（ALFWorld 提升 9.4%，Search-QA 提升 7.0%，WebShop-Acc 提升 10.2%），避免了原生 GRPO+OPSD 的不稳定性，并在不同模型规模下始终优于混合 RL-OPSD 基准。

## Abstract
Reinforcement learning (RL) has emerged as a central paradigm for post-training LLM agents, yet its trajectory-level reward signal provides only coarse supervision for long-horizon interaction. On-Policy Self-Distillation (OPSD) complements RL by introducing dense token-level guidance from a teacher branch augmented with privileged context. However, transferring OPSD to multi-turn agents proves problematic: compounding multi-turn instability destabilizes supervision, while skill-conditioned privileged guidance requires asymmetric treatment for negative teacher rejections may arise from imperfect skills retrieval or utilization. We introduce SDAR (Self-Distilled Agentic Reinforcement Learning), which treats OPSD as a gated auxiliary objective while keeping RL as the primary optimization backbone. SDAR maps detached token-level signals into a sigmoid gate, strengthening distillation on teacher-endorsed positive-gap tokens and softly attenuating negative teacher rejections. Across the Qwen2.5 and Qwen3 families on ALFWorld, WebShop, and Search-QA, SDAR substantially improves over GRPO (+9.4% on ALFWorld, +7.0% on Search-QA, +10.2% on WebShop-Acc), avoids the instability of naive GRPO+OPSD, and consistently outperforms hybrid RL--OPSD baselines across model scales.

### 1. 核心问题与整体含义
*   **研究背景**：强化学习（RL）是提升大语言模型（LLM）智能体能力的核心手段，但传统的 RL 依赖轨迹级的奖励信号，对于长路径的多轮交互来说，监督信号过于稀疏且粗糙。
*   **核心问题**：现有的“在线策略自蒸馏”（OPSD）虽然能提供密集的 Token 级引导，但在多轮智能体场景下存在两大痛点：
    1.  **多轮不稳定性**：学生模型一旦偏离教师轨迹，误差会迅速累积，导致训练崩溃。
    2.  **特权引导的非对称性**：教师分支通过“特权上下文”（如检索到的技能）进行增强，但如果检索到的技能质量差或教师利用不当，其给出的负向反馈（拒绝信号）可能是错误的。
*   **研究意义**：本文旨在通过一种稳健的机制，将 RL 的任务级优化与 OPSD 的密集 Token 级引导结合，使智能体能稳定地内化特权知识。

### 2. 方法论
*   **核心思想**：将 RL（具体为 GRPO）作为主要的优化骨干，而将 OPSD 视为一个受控的辅助目标。引入**令牌级门控机制（Token-Level Gating）**，让每个 Token 自主决定其受监督的强度。
*   **关键技术细节**：
    *   **教师分支**：使用与学生相同的模型，但在输入中加入“特权上下文”（从 SkillBank 检索到的相关技能）。
    *   **差距计算（Gap）**：计算教师与学生在当前 Token 上的对数概率差值：$\Delta_t = \log \pi_T(y_t | s^+_t) - \log \pi_\theta(y_t | s_t)$。
    *   **Sigmoid 门控**：定义门控 $g_t = \sigma(\beta \Delta_t)$。
        *   **正向增强**：当教师对该 Token 的信心高于学生（$\Delta_t > 0$）时，门控开启，强化蒸馏。
        *   **负向衰减**：当教师信心较低时，门控软性关闭，减少不可靠信号的干扰。
    *   **优化目标**：总损失 $L = L_{GRPO} + \lambda \cdot L_{SDAR}$。其中 $L_{SDAR}$ 采用反向 KL 散度，并对门控部分进行梯度截断（stop-gradient），确保稳定性。

    3.  **Search-QA**：搜索增强的问答任务（包含 NQ, HotpotQA 等多个子集）。
*   **对比方法**：
    *   **基础 RL**：GRPO。
    *   **自蒸馏基准**：OPSD。
    *   **混合方法**：Skill-SD（基于 K3 散度）、RLSD（重加权 RL 优势函数）、GRPO+OPSD（直接相加）。
    *   **技能增强基准**：Skill-GRPO（训练时带技能，推理时不带或带技能）。

*   **实验规模**：涵盖了 3 个不同领域的 Benchmark，使用了 3 种不同规模和家族的模型。
*   **消融实验**：非常充分。分别对门控策略（熵门控 vs 差距门控）、Sigmoid 锐度 $\beta$、蒸馏系数 $\lambda$、以及蒸馏损失类型（Forward KL, Reverse KL, JSD）进行了详细对比。
*   **鲁棒性测试**：针对技能检索质量做了专门实验，对比了 UCB 检索、关键词匹配、全量检索和随机检索。

### 6. 主要结论与发现
*   **性能飞跃**：SDAR 在所有任务上均显著优于 GRPO，例如在 ALFWorld 上提升了 9.4%，在 WebShop 准确率上提升了 10.2%。
*   **稳定性**：成功解决了原生 GRPO+OPSD 在多轮交互中容易出现的训练崩溃问题，尤其是在 Qwen3-1.7B 模型上表现极其稳健。
*   **知识内化**：SDAR 训练的模型在推理时**不需要**检索外部技能，其表现甚至优于那些在推理时挂载了技能的基准模型（Skill-GRPO*）。
*   **非对称信任**：实验证实，教师的负向信号（Negative Gap）往往带有噪声，通过门控对其进行衰减是保持训练稳定的关键。

### 7. 优点
*   **设计精巧**：Sigmoid 门控机制简单且数学性质优良（有界、单调、平滑），有效平衡了 RL 和蒸馏。
*   **实用性强**：实现了“训练时用特权，推理时去特权”，降低了智能体在部署时的复杂度和延迟。
*   **鲁棒性高**：即使检索到的技能是随机噪声，SDAR 依然能通过门控过滤噪声，保持优于基准线的性能。

### 8. 不足与局限
*   **模型规模上限**：实验最高仅覆盖到 7B 模型，尚未在 70B 或更大规模的参数量下验证门控机制的必要性。
*   **任务局限**：实验主要集中在有明确环境反馈（Reward）的任务，对于缺乏明确成功定义的开放式任务（如创意写作智能体）的适用性尚待研究。
*   **超参数敏感性**：虽然给出了推荐值，但 $\lambda$ 和 $\beta$ 的选择对最终性能仍有一定影响，可能需要针对新环境进行微调。
