## 摘要
我们引入了递归智能体优化（Recursive Agent Optimization, RAO），这是一种用于训练递归智能体的强化学习方法：递归智能体能够生成自身的新实例，并递归地将子任务委托给这些实例。递归智能体实现了一种推理时扩展算法，使其能够自然地扩展到更长的上下文，并通过分治法泛化到更难的问题。RAO 提供了一种训练模型以充分利用此类递归推理的方法，教会智能体何时以及如何进行委托和通信。我们发现，以这种方式训练的递归智能体具有更好的训练效率，能够扩展到超出模型上下文窗口的任务，泛化到比训练任务困难得多的任务，并且与单智能体系统相比，可以缩短实际运行时间。

## Abstract
We introduce Recursive Agent Optimization (RAO), a reinforcement learning approach for training recursive agents: agents that can spawn and delegate sub-tasks to new instantiations of themselves recursively. Recursive agents implement an inference-time scaling algorithm that naturally allows agents to scale to longer contexts and generalize to more difficult problems via divide-and-conquer. RAO provides a method to train models to best take advantage of such recursive inference, teaching agents when and how to delegate and communicate. We find that recursive agents trained in this way enjoy better training efficiency, can scale to tasks that go beyond the model's context window, generalize to tasks much harder than the ones the agent was trained on, and can enjoy reduced wall-clock time compared to single-agent systems.

以下是对该论文的结构化总结：

### 1. 核心问题与整体含义（研究动机和背景）
随着 LLM 智能体被部署在软件工程、深度研究等复杂任务中，它们面临着**超长执行步长、有限的上下文窗口以及复杂的探索需求**。虽然“分治法（Divide-and-Conquer）”是解决复杂问题的自然策略，且已有系统尝试在推理阶段使用递归（如生成子智能体），但这些系统大多将递归视为外部脚手架，模型本身并未经过专门训练。
**核心问题：** 如何训练一个模型，使其学会自主决定何时委派任务、如何制定子任务、如何跨层级通信以及如何整合结果，从而实现真正的推理时扩展（Inference-time Scaling）？

### 2. 方法论：核心思想与关键技术
RAO 的核心思想是**将递归执行过程建模为一个动态生成的树状结构**，并对树中的所有节点（即智能体实例）进行端到端的联合强化学习训练。

*   **递归动作空间：** 在标准的 Python REPL 智能体基础上，增加了一个异步函数 `launch_subagent(goal, ...)`。智能体可以通过编写代码调用此函数，生成一个新的自身实例来处理子任务。
*   **局部节点奖励（Local Node Reward）：** 为了解决信用分配（Credit Assignment）难题，RAO 为每个节点定义了奖励函数：
    $$R(X, \tau_X) = \tilde{s}(X, \tau_X) + \lambda \cdot \text{mean}(\tilde{s}(\text{children}))$$
    即：当前节点的奖励 = 自身任务成功分 + 委派奖金（子节点成功率的加权）。这鼓励智能体不仅要解决自己的任务，还要学会高效地委派。
*   **策略优化：**
    *   **留一法基准（Leave-one-out Baseline）：** 使用同一根任务下的多个并行采样结果作为基准，减少方差且不引入偏差。
    *   **深度频率加权（Depth-level Inverse-frequency Weighting）：** 递归树深层节点往往远多于根节点，RAO 通过逆频率加权平衡不同深度的梯度贡献，防止训练被深层节点主导。
*   **自诱导课程学习：** 递归结构自然地将复杂任务分解为简单子任务，为模型提供了一个从易到难的隐式训练课程。

### 3. 实验设计
研究在三个具有挑战性的基准测试中评估了 RAO：
*   **TextCraft-Synth：** 一个受 Minecraft 启发的合成合成任务，可精确控制任务难度和递归深度（2-10层）。
*   **Oolong-Real：** 长文本推理基准，处理超过 5.5 万甚至 22 万 token 的龙与地下城（D&D）游戏日志。
*   **DeepDive：** 深度搜索任务，需要多步、串行的网页搜索和信息整合。
*   **对比方法：** 主要对比了**单智能体（Flat Single-agent）**基准，并在不同上下文窗口限制（8K vs 40K/256K）下进行测试。

### 4. 资源与算力
*   **训练后端：** 使用了 AReaL 异步强化学习系统和 Tinker 训练服务。
*   **模型：** 主要使用 Qwen-3-4B-Instruct 和 Qwen-3-VL-30B。
*   **硬件：** 评估阶段使用了 **8xH200 GPU 节点**。
*   **训练细节：** 学习率在 3e-6 到 3e-5 之间，Batch Size 为 16，每个任务组采样 8 个 Rollout。具体训练时长未明确给出总小时数，但提到了 staleness（延迟）控制在 3 个 batch 内。

### 5. 实验数量与充分性
*   **实验组数：** 涵盖了三个完全不同的领域（合成任务、长文本、Web 搜索），并针对 TextCraft-Synth 进行了不同难度（Easy/Medium/Hard）的泛化测试。
*   **消融实验：** 专门验证了“局部奖励设计”和“深度加权”的必要性，证明了两者对训练效率的提升。
*   **公平性：** 在对比单智能体时，给予了单智能体更多的执行步数预算，以确保对比是在性能极限而非简单的计算量差异上进行的。实验设计较为客观、充分。

### 6. 主要结论与发现
*   **突破上下文限制：** 即使训练时只有 8K 上下文，递归智能体也能通过分治法处理需要极长上下文的任务，表现远超单智能体。
*   **超强的泛化能力：** 在中等难度任务上训练的模型，能够通过增加递归深度（最高达 10 层）成功解决比训练任务难得多的 Hard 任务。
*   **训练效率更高：** 递归结构提供的密集奖励信号使模型比单智能体更快收敛。
*   **缩短运行时间：** 在可并行任务中，递归智能体通过并发执行子任务，实际运行时间（Wall-clock time）比单智能体缩短了高达 2.5 倍。

### 7. 优点（亮点）
*   **端到端训练：** 首次实现了递归深度大于 1 的端到端强化学习训练，解决了以往递归系统难以训练的难题。
*   **动态性：** 智能体自主决定递归树的形状，而非使用预设的固定层级。
*   **推理时扩展：** 提供了一种通过增加计算量（深度和宽度）来换取更高成功率的有效路径。

### 8. 不足与局限
*   **领域局限性：** 目前的实验是在特定领域内分别训练的，尚未实现一个通用的、跨领域的“通用递归智能体”。
*   **串行任务开销：** 对于无法并行的任务（如 DeepDive），递归会引入额外的推理延迟和 Token 消耗（因为需要多次启动新实例）。
*   **训练成本：** 完整的递归 Rollout 采样成本较高，未来需要研究更高效的代理采样（Surrogate Sampling）程序。
