## 摘要
通用机器人策略日益受益于大规模预训练，但仅靠离线数据不足以实现稳健的现实世界部署。部署后的机器人会遇到分布偏移、长尾失败、任务变化以及人类纠错机会，而固定的演示数据集无法完全捕捉这些情况。我们提出了“边部署边学习”（Learning While Deploying, LWD），这是一个车队级的离线到在线强化学习框架，用于通用视觉-语言-动作（VLA）策略的持续后训练。LWD 从预训练的 VLA 策略开始，通过利用在机器人车队中收集的自主运行和人类干预，闭合了部署、共享物理经验、策略改进和重新部署之间的循环。为了稳定从异构、稀疏奖励的车队数据中学习的过程，LWD 将用于稳健价值估计的分布隐式价值学习（DIVL）与通过伴随匹配进行 Q 学习（QAM）相结合，用于流式 VLA 动作生成器中的策略提取。我们在由 16 台双臂机器人组成的车队上验证了 LWD，涵盖了八个现实世界的操纵任务，包括语义杂货补货和 3-5 分钟的长程任务。随着车队经验的积累，单一通用策略不断改进，平均成功率达到 95%，其中在长程任务上的提升最为显著。

## Abstract
Generalist robot policies increasingly benefit from large-scale pretraining, but offline data alone is insufficient for robust real-world deployment. Deployed robots encounter distribution shifts, long-tail failures, task variations, and human correction opportunities that fixed demonstration datasets cannot fully capture. We present Learning While Deploying (LWD), a fleet-scale offline-to-online reinforcement learning framework for continual post-training of generalist Vision-Language-Action (VLA) policies. Starting from a pretrained VLA policy, LWD closes the loop between deployment, shared physical experience, policy improvement, and redeployment by using autonomous rollouts and human interventions collected across a robot fleet. To stabilize learning from heterogeneous, sparse-reward fleet data, LWD combines Distributional Implicit Value Learning (DIVL) for robust value estimation with Q-learning via Adjoint Matching (QAM) for policy extraction in flow-based VLA action generators. We validate LWD on a fleet of 16 dual-arm robots across eight real-world manipulation tasks, including semantic grocery restocking and 3--5 minute long-horizon tasks. A single generalist policy improves as fleet experience accumulates, reaching an average success rate of 95%, with the largest gains on long-horizon tasks.

### 论文总结：边部署边学习（Learning While Deploying, LWD）

#### 1. 核心问题与研究动机
*   **核心问题**：离线预训练的视觉-语言-动作（VLA）策略在实际部署中面临分布偏移、长尾失败和任务变体等挑战，仅靠静态数据集无法实现稳健的现实世界应用。
*   **研究动机**：将“部署”从训练的终点转变为持续改进的起点。通过机器人车队（Fleet）在实际运行中产生的自主尝试、失败恢复和人类干预数据，构建一个闭环的“数据飞轮”，使通用策略能够随使用规模的扩大而持续进化。

#### 2. 方法论
LWD 框架包含两个关键阶段（离线预训练与在线微调）和两项核心技术：
*   **核心思想**：利用分布式机器人集群收集异构数据，通过离线到在线的强化学习（RL）持续优化 VLA 策略。
*   **关键技术 1：分布隐式价值学习（DIVL）**
    *   改进了隐式 Q 学习（IQL），将标量价值回归替换为**分布价值模型**（Categorical Distribution）。
    *   针对车队数据中存在的稀疏奖励和多模态结果（成功、失败、干预），DIVL 能够保留高回报的模式，并通过自适应分位数（$\tau$）策略在不确定性高时保持保守，在置信度高时保持乐观。
*   **关键技术 2：伴随匹配 Q 学习（QAM）**
    *   解决了流匹配（Flow Matching）策略在强化学习中更新不稳定的问题。
    *   QAM 将价值函数（Critic）提供的动作梯度转化为流模型每一步的局部回归目标，避免了直接通过复杂的 ODE 求解器进行反向传播，确保了大型 VLA 策略提取的稳定性。
*   **算法流程**：
    1.  在包含演示、历史运行和人类引导数据的离线缓冲区上进行预训练。
    2.  将策略部署到机器人集群，异步收集在线交互数据。
    3.  在混合缓冲区（离线+在线数据 1:1）上持续更新价值函数和策略，并定期向集群同步新模型。

#### 3. 实验设计
*   **实验场景**：使用 16 台 **Agibot G1** 双臂机器人，涵盖 8 项真实世界任务：
    *   **语义杂货补货（4 项）**：平铺补货、错位纠正、冰箱补货、冷柜处理。
    *   **长程操纵任务（4 项）**：功夫茶冲泡、果汁制作、鸡尾酒调制、鞋盒打包（单次任务时长达 3-5 分钟）。
*   **Benchmark 与对比方法**：
    *   **SFT**：仅使用人类演示的监督微调。
    *   **RECAP**：基于优势加权的离线后训练基准。
    *   **HG-DAgger**：交互式模仿学习基准，利用人类干预数据。
    *   **LWD (Offline)**：仅使用离线 RL 阶段的消融版本。

#### 4. 资源与算力
*   **模型架构**：
    *   **策略网络**：基于 PaliGemma（Gemma-2B 语言模型 + SigLIP 视觉编码器）及 300M 参数的动作专家模型。
    *   **价值/评论网络**：基于 Gemma-3-270M-IT 和 SigLIP-So400M。
*   **训练时长**：在线微调阶段，每个方法分配了 **4 小时** 的墙钟时间预算，对应集群总计约 **60 小时** 的在线交互数据。
*   **系统实现**：采用分布式 Actor-Learner 架构，基于 JAX 开发，支持多主机 SPMD 并行训练。

#### 5. 实验数量与充分性
*   **实验规模**：在 16 台机器人上进行了大规模实测，这在机器人 RL 论文中属于较高规格。
*   **消融实验**：针对“分布价值设计”和“自适应 $\tau$ 策略”进行了专门的消融研究，验证了 DIVL 相比标量回归的优越性。
*   **公平性**：所有对比方法在相同的在线时长和数据缓冲区下运行，评估标准包括任务成功率（长程任务采用步骤评分制）和循环时间（Cycle Time）。实验设计较为客观、严谨。

#### 6. 主要结论与发现
*   **性能卓越**：LWD 在所有任务上的平均成功率达到 **95%**，显著优于 SFT (76%)、RECAP (85%) 和 HG-DAgger (85%)。
*   **长程任务优势明显**：在 3-5 分钟的长程任务中，LWD 的提升幅度最大，证明了 RL 在处理稀疏奖励和错误累积方面的能力。
*   **效率提升**：相比 SFT，LWD 训练出的策略动作更果断，平均循环时间缩短了约 23.75 秒。
*   **价值函数有效性**：可视化证明了学习到的价值函数能够准确追踪任务进度，即使在只有末端稀疏奖励的情况下。

#### 7. 优点
*   **系统性创新**：成功闭环了“部署-学习-再部署”的流程，展示了车队级数据飞轮的巨大潜力。
*   **算法适配性强**：DIVL 和 QAM 的结合解决了 VLA 模型在强化学习中的稳定性和异构数据处理难题。
*   **实战导向**：实验全部在真实机器人和复杂长程任务中完成，具有极高的应用参考价值。

#### 8. 不足与局限
*   **更新策略简单**：目前的在线学习采用固定的实时调度，对于更大规模（如成千上万台）的部署，可能需要更复杂的持续学习策略。
*   **安全建模缺失**：框架尚未显式引入执行安全约束，在更敏感的环境中部署可能存在风险。
*   **推理依赖**：长程任务仍依赖简单的语言指令，对于需要复杂逻辑推理或多轮对话的任务，当前的视觉-语言理解能力可能仍有局限。
