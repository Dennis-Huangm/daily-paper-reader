## 摘要
大语言模型（LLM）智能体需要长期用户记忆来实现一致的个性化，但有限的上下文窗口阻碍了在长时交互中追踪演化的偏好。现有的记忆系统主要依赖于静态的手工更新规则；虽然基于强化学习（RL）的智能体可以学习记忆更新，但稀疏的结果奖励提供了微弱的监督，导致长程优化不稳定。借鉴记忆图式理论以及前额叶区域与海马体区域之间的功能划分，我们提出了 MemCoE，这是一个受认知启发的两阶段优化框架，用于学习记忆应如何组织以及更新哪些信息。在第一阶段，我们提出了记忆指南归纳（Memory Guideline Induction），通过解释为文本梯度的对比反馈来优化全局指南；在第二阶段，指南对齐的记忆策略优化（Guideline-Aligned Memory Policy Optimization）利用归纳出的指南来定义结构化的过程奖励，并进行多轮强化学习，以学习遵循指南的记忆演化策略。我们在三个个性化记忆基准上进行了评估，涵盖了显式/隐式偏好以及不同的规模和噪声，并观察到相比强基准线有持续的改进，且具有良好的鲁棒性、可迁移性和效率。

## Abstract
Large language model (LLM) agents require long-term user memory for consistent personalization, but limited context windows hinder tracking evolving preferences over long interactions. Existing memory systems mainly rely on static, hand-crafted update rules; although reinforcement learning (RL)-based agents learn memory updates, sparse outcome rewards provide weak supervision, resulting in unstable long-horizon optimization. Drawing on memory schema theory and the functional division between prefrontal regions and hippocampus regions, we introduce MemCoE, a cognition-inspired two-stage optimization framework that learns how memory should be organized and what information to update. In the first stage, we propose Memory Guideline Induction to optimize a global guideline via contrastive feedback interpreted as textual gradients; in the second stage, Guideline-Aligned Memory Policy Optimization uses the induced guideline to define structured process rewards and performs multi-turn RL to learn a guideline-following memory evolution policy. We evaluate on three personalization memory benchmarks, covering explicit/implicit preference and different sizes and noise, and observe consistent improvements over strong baselines with favorable robustness, transferability, and efficiency.

*   **核心问题**：大语言模型（LLM）智能体在处理长期个性化交互时，受限于有限的上下文窗口。现有的记忆系统要么依赖**静态的手工规则**（难以适应复杂变化），要么依赖**基于强化学习（RL）的更新**（由于奖励稀疏且动作空间巨大，导致长程优化极不稳定）。
*   **研究动机**：受认知心理学中“记忆图式理论”启发，人类大脑在前额叶区域（负责组织模式/图式）与海马体区域（负责填充具体情节细节）之间存在功能分工。论文旨在构建一个类似的系统，将“如何组织记忆”与“记忆什么内容”解耦。

#### 2. 方法论：MemCoE 框架
论文提出了 **MemCoE**（Memory Cognition-inspired Evolution），分为两个优化阶段：
*   **第一阶段：记忆准则诱导 (MGI - Memory Guideline Induction)**
    *   **核心思想**：学习“如何”记忆。将记忆更新指令视为一个全局的自然语言参数进行优化。
    *   **关键技术**：
        1.  **对比反馈作为文本梯度**：通过比较正确和错误的记忆更新轨迹，生成自然语言形式的“文本梯度”。
        2.  **批次级梯度聚合**：在 mini-batch 上汇总这些反馈，消除随机噪声，诱导出通用的、领域无关的记忆组织准则（Guideline）。
*   **第二阶段：准则对齐的记忆策略优化 (GMPO - Guideline-Aligned Memory Policy Optimization)**
    *   **核心思想**：学习“什么”该记。在固定第一阶段准则的前提下，优化具体的记忆更新策略。
    *   **关键技术**：
        1.  **准则对齐奖励**：利用诱导出的准则定义“过程奖励”（Process Reward），评估记忆更新是否符合格式和逻辑要求。
        2.  **多轮强化学习 (GRPO)**：采用组相对策略优化（Group Relative Policy Optimization），结合过程奖励和最终的答案正确性奖励，端到端训练记忆演化策略。

#### 6. 主要结论与发现
*   **性能领先**：MemCoE 在所有基准测试中均优于强基准线，尤其在处理隐式偏好和长程演化方面优势明显。

*   **迁移性强**：诱导出的自然语言准则具有通用性，能够提升不同规模和厂商模型的记忆管理能力。
*   **效率优势**：相比于频繁调用 LLM 进行提取和合并的系统，MemCoE 通过策略内化减少了推理开销。

#### 7. 优点与亮点
*   **认知启发**：将脑科学中的前额叶-海马体分工引入 AI 记忆系统，具有坚实的理论支撑。
*   **文本梯度优化**：利用 LLM 自身的反馈来迭代优化指令，避免了繁琐的人工调优。
*   **过程奖励设计**：通过准则对齐解决了 RL 在记忆任务中奖励稀疏的痛点。

#### 8. 不足与局限
*   **评分器依赖**：第二阶段的奖励依赖于另一个 LLM 作为评分器，评分器的可靠性会直接影响训练效果。

*   **超参数敏感**：每轮演化的 Token 预算和轮数需要仔细调整，过大或过小都会导致性能下降。
*   **多目标平衡**：目前尚未显式解决记忆稳定性（保留旧信息）与塑料性（吸收新信息）之间的精细平衡冲突。
