## 摘要
遵循顺序“推理-行动”范式的大语言模型（LLM）智能体在许多复杂任务中取得了卓越的性能。然而，由于这些方法每步仅与单个环境交互，因此面临探索受限和环境理解不完整的问题。在本文中，我们首先引入了一种新颖的范式，使智能体能够同时与多个环境交互并共享跨轨迹经验。基于这一范式，我们进一步提出了 DPEPO，这是一种鼓励智能体进行多样化并行探索的强化学习（RL）算法。DPEPO 包含两个阶段：初始的有监督微调（SFT）赋予基础的并行推理和动作生成能力，随后是采用分层奖励方案的强化学习阶段。我们设计了一个并行轨迹级成功奖励和两个步骤级奖励：多样化动作奖励和多样化状态转移奖励，旨在主动惩罚行为冗余并促进广泛探索。在 ALFWorld 和 ScienceWorld 上的广泛实验表明，DPEPO 实现了最先进的（SOTA）成功率，同时保持了与强顺序基线相当的效率。（代码可在 https://github.com/LePanda026/Code-for-DPEPO 获取）

## Abstract
Large language model (LLM) agents that follow the sequential "reason-then-act" paradigm have achieved superior performance in many complex tasks.However, these methods suffer from limited exploration and incomplete environmental understanding, as they interact with only a single environment per step. In this paper, we first introduce a novel paradigm that enables an agent to interact with multiple environments simultaneously and share cross-trajectory experiences. Building upon this paradigm, we further propose DPEPO, a reinforcement learning (RL) algorithm that encourages the agent to perform diverse parallel exploration. There are two stages in DPEPO: initial supervised fine-tuning (SFT) imparts basic parallel reasoning and action generation, followed by reinforcement learning stage with a hierarchical reward scheme. We design a parallel trajectory-level success reward and two step-level rewards: Diverse Action Reward and Diverse State Transition Reward, which actively penalize behavioral redundancy and promote broad exploration. Extensive experiments on ALFWorld and ScienceWorld show that DPEPO achieves state-of-the-art (SOTA) success rates, while maintaining comparable efficiency to strong sequential baselines. ### 论文总结：DPEPO - 面向大语言模型智能体的多样化并行探索策略优化

#### 1. 核心问题与整体含义
论文针对当前大语言模型（LLM）智能体主流的 **ReAct（推理-行动）** 范式存在的局限性进行了研究。传统的 ReAct 范式是线性的、顺序的，智能体每一步只能执行一个动作并观察一个反馈。这种“窄视野”导致智能体在复杂、长程任务中探索效率低下，容易陷入局部最优或因环境理解不全而失败。

**DPEPO** 的核心意义在于提出了一种**并行探索（Parallel Exploration）**新范式，允许智能体在同一步骤内同时与多个环境副本交互，共享跨轨迹经验，从而构建更全面的环境认知。

#### 2. 方法论
DPEPO 结合了监督微调（SFT）和强化学习（RL），核心流程如下：

*   **并行探索范式**：智能体在每一步 $t$ 可以选择一个环境子集，生成一组并行动作 $A_t = \{(E_i, a_t)\}$ 并同时执行，观察多个状态反馈。
*   **SFT 冷启动**：通过人工标注和模型合成（如 DeepSeek-V3）生成包含并行探索行为的数据，训练模型掌握并行推理和特定的输出格式（如 `<parallel>` 标签）。
*   **分层奖励强化学习**：
    *   **轨迹级成功奖励 ($R_{traj}$)**：如果并行环境中的任何一个达到目标状态，则给予奖励。
    *   **步级多样性奖励 ($R_{step}$)**：
        *   **多样化动作奖励 (DAR)**：惩罚在单一环境内（深度）或跨环境间（宽度）重复执行相同动作的行为。
        *   **多样化状态转移奖励 (DSTR)**：惩罚重复的“状态-动作”转移对，强制智能体探索未知的状态空间。
*   **策略优化**：基于 **GRPO**（组相对策略优化）框架，取消了 Critic 模型，通过组内样本的相对得分估计优势函数（Advantage），并结合步级奖励进行细粒度的信用分配。

#### 6. 主要结论与发现
*   **性能领先**：DPEPO 在 ALFWorld（98.2%）和 ScienceWorld（61.4%）上均刷新了 SOTA 记录。
*   **高效探索**：并行探索不仅提高了成功率，还缩短了完成任务所需的平均步数。
*   **推理效率**：虽然并行探索增加了单步的 Token 消耗，但由于动作是并行执行的，其**总推理时间**往往低于需要多次尝试的顺序基线模型。
*   **多样性奖励的作用**：实验证明，单纯增加采样数量（Multi-sampling）效果有限，必须通过多样性奖励主动惩罚冗余行为，才能实现真正的有效探索。

#### 7. 优点
*   **范式创新**：打破了 ReAct 的线性限制，提出了更符合 LLM 并行处理能力的智能体交互范式。
*   **奖励设计精巧**：通过“深度+宽度”两个维度的多样性奖励，解决了强化学习中常见的探索冗余问题。
*   **训练效率高**：相比传统的 PPO 或其他需要大量样本的 RL 方法，DPEPO 在极少样本（500个）下即可收敛。

#### 8. 不足与局限
*   **环境依赖性**：该方法依赖于能够提供多个并行副本（Sandbox）的环境。在某些现实世界场景（如实体机器人）中，构建多个完全同步的并行物理环境成本极高或不可行。
*   **上下文压力**：随着并行环境数量增加，Prompt 的长度会迅速增长，虽然论文设计了 Prompt 压缩策略，但在极长任务中仍可能触及 LLM 的上下文窗口上限。
*   **偏见风险**：并行探索可能让智能体更快地接触到环境中的偏见信息，需注意安全性和合规性评估。
