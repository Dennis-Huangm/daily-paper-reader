## 摘要
我们引入了递归智能体优化（Recursive Agent Optimization, RAO），这是一种用于训练递归智能体的强化学习方法：递归智能体能够生成自身的新实例，并递归地将子任务委托给这些实例。递归智能体实现了一种推理时扩展算法，该算法自然地允许智能体扩展到更长的上下文，并通过分而治之的方法泛化到更难的问题。RAO 提供了一种训练模型以充分利用此类递归推理的方法，教导智能体何时以及如何进行委托和通信。我们发现，以这种方式训练的递归智能体具有更好的训练效率，能够扩展到超出模型上下文窗口的任务，泛化到比训练任务难得多的任务，并且与单智能体系统相比，可以缩短实际运行时间。

## Abstract
We introduce Recursive Agent Optimization (RAO), a reinforcement learning approach for training recursive agents: agents that can spawn and delegate sub-tasks to new instantiations of themselves recursively. Recursive agents implement an inference-time scaling algorithm that naturally allows agents to scale to longer contexts and generalize to more difficult problems via divide-and-conquer. RAO provides a method to train models to best take advantage of such recursive inference, teaching agents when and how to delegate and communicate. We find that recursive agents trained in this way enjoy better training efficiency, can scale to tasks that go beyond the model's context window, generalize to tasks much harder than the ones the agent was trained on, and can enjoy reduced wall-clock time compared to single-agent systems.

*   **核心问题**：大型语言模型（LLM）在处理长程（Long-horizon）、超长上下文或极高复杂度的任务时，往往受限于上下文窗口大小和推理能力的瓶颈。
*   **研究动机**：虽然现有的多智能体系统通过“分而治之”的递归架构（如父智能体调用子智能体）来缓解这些问题，但大多数系统仅将递归视为一种**推理时的外挂脚手架**（Scaffold），模型本身并未经过专门训练来学习：
    *   何时应该委派任务？
    *   如何制定有效的子任务目标？
    *   如何跨层级通信并整合结果？
*   **目标**：通过强化学习（RL）端到端地训练模型，使其原生具备高效的递归委派能力。

### 2. 方法论：RAO 核心思想与技术细节
*   **核心思想**：将递归执行过程建模为一个动态生成的**执行树（Execution Tree）**。树中的每个节点都是同一个策略网络 $\pi_\theta$ 的实例。RAO 对整棵树的所有决策进行联合优化。
*   **关键技术细节**：
    *   **动作空间扩展**：在标准的 Python 代码执行环境（REPL）基础上，增加了一个异步函数 `launch_subagent(goal, ...)`。这允许智能体以异步方式启动自身副本，并等待返回结果。
    *   **局部节点奖励（Local Node Reward）**：
        $$R(X, \tau_X) = \tilde{s}(X, \tau_X) + \lambda \cdot \frac{1}{|C(X)|} \sum_{c \in C(X)} \tilde{s}(c, \tau_c)$$
        其中 $\tilde{s}$ 是任务成功信号，$\lambda$ 是委派奖励系数。该公式不仅奖励当前节点任务的成功，还奖励其委派的子任务的成功率，从而鼓励高质量的委派。
    *   **策略优化**：
        *   **留一法基准（Leave-one-out Baseline）**：为了降低方差且不引入额外的 Critic 网络，使用同一根任务下不同采样轨迹的平均奖励作为基准。
        *   **深度频率加权（Depth-level Inverse-frequency Weighting）**：由于递归树深层节点的数量远多于浅层，RAO 通过逆频率加权防止优化过程被深层节点主导，确保各层级任务均衡学习。

*   **模型基础**：主要使用 Qwen-3-4B-Instruct 和 Qwen-3-VL-30B。

### 6. 主要结论与发现
*   **突破上下文限制**：递归智能体能处理远超其训练上下文窗口的任务（如 8K 训练模型处理 256K 任务）。
*   **更强的泛化性**：在简单/中等任务上训练的模型，通过递归能有效泛化到极难（深度达 10 层）的任务，而单智能体在这些任务上几乎完全失败。
*   **训练效率更高**：递归结构提供了天然的“课程学习”信号，使得模型比单智能体更快达到高成功率。
*   **推理加速**：在可并行化的任务中，递归智能体通过异步委派，实际运行时间（Wall-clock time）比单智能体缩短了高达 2.5 倍。

### 7. 优点
*   **端到端训练**：不同于以往的硬编码规则，RAO 让模型自主学习委派策略，具有极高的灵活性。
*   **异步支持**：引入异步委派机制，充分利用了现代计算资源的并行能力。
*   **自适应深度**：实验显示模型能根据任务难度自动调整递归深度，表现出智能的计算分配。

### 8. 不足与局限
*   **推理成本**：虽然运行时间可能缩短，但递归会产生大量的 Token 消耗（因为每个子智能体都有自己的 Prompt 和上下文），论文附录显示其 Token 使用量在某些场景下远高于单智能体。
*   **任务依赖性**：对于强顺序依赖的任务（如 DeepDive），递归的并行优势无法发挥，反而会因为多次启动智能体而增加延迟。
*   **评估指标单一**：目前主要关注成功率和时间，对递归过程中的通信冗余、错误传播等细粒度问题的分析较少。
