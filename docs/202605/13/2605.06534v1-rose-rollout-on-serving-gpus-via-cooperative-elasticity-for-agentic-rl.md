## 摘要
智能体强化学习（Agentic RL）已成为提升大语言模型（LLM）多步推理和工具使用能力的关键驱动力。然而，其效率受限于具有多轮环境交互的长尾 Rollout，这使得静态 GPU 资源配置难以适配：过度配置会在落后者（stragglers）上浪费 GPU 资源，而配置不足则会增加竞争并减慢训练速度。我们观察到，生产环境中的推理服务集群通常会留有大量的 GPU 计算和显存余量。基于这一观察，我们提出了协作弹性（cooperative elasticity）：机会性地重新利用未充分利用的推理服务 GPU 来执行 Rollout。实现协作弹性并非易事，因为它必须在突发流量下维持推理服务的服务水平目标（SLO），并最小化通信开销。为了应对这些挑战，我们提出了 ROSE，这是一个协作式资源弹性后训练系统，它能安全地利用推理服务 GPU 上的空闲计算和显存资源，以加速智能体强化学习的 Rollout。ROSE 由三个组件组成：（1）一个 SLO 安全的共存服务执行器，通过高效的 GPU 显存和计算共享，在保持推理服务 SLO 的同时提高 Rollout 吞吐量；（2）一个跨集群权重传输引擎，利用权重分片和稀疏性实现跨集群的快速权重同步；（3）一个弹性 Rollout 调度器，动态配置协作容量，并在专用 Rollout GPU 和机会性推理服务 GPU 之间路由轨迹 Rollout。在多种模型大小和集群规模上的实验表明，与最先进的资源固定和弹性基准相比，ROSE 将平均端到端吞吐量提高了 1.20-3.31 倍。

## Abstract
Agentic reinforcement learning (RL) has emerged as a key driver for improving the multi-step reasoning and tool-use capabilities of LLMs. However, its efficiency is bottlenecked by long-tail rollouts with multi-turn environment interactions, making static GPU provisioning a poor fit: overprovisioning wastes GPUs on stragglers, while underprovisioning increases contention and slows training.   We observe that production serving clusters routinely leave substantial GPU compute and memory headroom. Based on this observation, we argue for cooperative elasticity: opportunistically repurposing underutilized serving GPUs to execute rollouts. Realizing cooperative elasticity is non-trivial because it must preserve serving Service Level Objectives (SLOs) under bursty traffic and minimize communication overhead. To address these challenges, we present ROSE, a cooperative, resource-elastic post-training system that safely harvests idle compute and memory on serving GPUs to accelerate agentic RL rollouts. ROSE consists of three components: (1) an SLO-safe co-serving executor that improves rollout throughput while preserving serving SLOs through efficient GPU memory and compute sharing; (2) a cross-cluster weight transfer engine that leverages weight shards and sparsity for fast weight synchronization across clusters; and (3) an elastic rollout scheduler that dynamically provisions cooperative capacity and routes trajectory rollouts across dedicated rollout GPUs and opportunistic serving GPUs. Experiments across multiple model sizes and cluster scales show that ROSE improves average end-to-end throughput by 1.20-3.31 x compared with state-of-the-art resource-fixed and elastic baselines.

### 1. 核心问题与整体含义
*   **研究背景**：智能体强化学习（Agentic RL）通过多轮环境交互提升大语言模型（LLM）的推理和工具使用能力。然而，其效率受限于“采样（Rollout）”阶段，该阶段通常占总训练时间的 70% 以上，且具有显著的长尾分布特征。
*   **核心挑战**：静态资源配置（Static Provisioning）难以应对波动的采样需求，导致资源浪费或严重拥塞。现有的弹性方案（如竞价实例或 Serverless）受限于资源可用性、高昂的初始化开销和跨集群通信瓶颈。
*   **核心思想**：提出“协作弹性（Cooperative Elasticity）”概念，即在保障生产环境推理服务（Serving）的 SLO（服务水平目标）前提下，动态“窃取”推理集群中闲置的 GPU 计算和显存资源来执行 RL 采样任务。

### 2. 方法论
ROSE 系统由三个关键组件构成：
*   **SLO 安全的共存执行器（Co-serving Executor）**：
    *   **VMM 显存共享**：利用 CUDA 虚拟内存管理（VMM）实现异构模型（推理模型与采样模型）间的显存页动态重平衡，无需重启进程。
    *   **抢占式显存策略**：保留采样前缀缓存（Prefix Caching）以提升效率，但在推理流量激增时，通过高水位线触发强制回收。
    *   **双 SLO 准入控制**：基于预分析的算力开销，实时计算 TTFT（首字延迟）和 TPOT（字间延迟）的余量，仅在不违反推理 SLO 的空隙插入采样任务。
*   **跨集群权重传输引擎**：
    *   **稀疏性感知**：发现 RL 后训练中相邻 Step 的权重增量（Delta）具有 >95% 的无损稀疏性，仅传输非零值。
    *   **分片感知与异步化**：支持训练与推理集群间不同的并行策略（TP/PP），自动映射分片，并利用中继层实现异步传输，与训练过程重叠。
*   **弹性采样调度器**：
    *   **轮次级并发路由**：在采样任务的多轮交互中，根据实时负载动态决定将哪些轮次分发至推理 GPU。
    *   **缓存亲和性放置**：优先将请求路由至持有该轨迹前缀缓存的 GPU，以减少重复计算。

### 6. 主要结论与发现
*   **吞吐量提升**：相比固定资源基准，ROSE 实现了 **1.20x 至 3.31x** 的端到端吞吐量提升。
*   **SLO 保障**：在大幅提升采样效率的同时，推理服务的 P99 延迟始终保持在预设的 SLO 范围内。

### 7. 优点
*   **工业界落地性强**：直接利用大厂现有的推理集群余量，无需额外购买 GPU，极具成本效益。
*   **技术融合创新**：巧妙结合了 CUDA VMM、权重稀疏性和前缀缓存技术，解决了异构模型共存的痛点。
*   **调度粒度细**：轮次级（Turn-wise）调度比请求级调度更能适应智能体任务的动态特性。

### 8. 不足与局限
*   **模型异构限制**：虽然支持异构模型，但如果推理模型和采样模型规模差异过大（如 1.5B 与 70B 共存），显存管理和算力分配的复杂性会显著增加。
*   **跨数据中心延迟**：尽管优化了带宽占用，但极高延迟的跨地域连接仍可能影响同步效率。
*   **依赖推理余量**：如果推理集群长期处于极高负载（如双 11 期间），ROSE 能提供的加速效果将大幅回落。
