## 摘要
针对大推理模型（Large Reasoning Models）的带可验证奖励的强化学习（RLVR）依赖于基准估计（baseline estimation）来减少方差，但现有方法代价高昂：PPO 需要一个与策略模型规模相当的 Critic，而 GRPO 则需要针对每个提示词（prompt）进行多次采样（rollouts）以保持其经验组均值的稳定。我们提出了 POISE（基于内部状态价值估计的策略优化），它通过利用策略模型在前向传播过程中已经计算出的内部信号，以微乎其微的成本获取基准。一个轻量级的探针根据提示词和生成轨迹的隐藏状态以及 Token 熵统计数据来预测预期的可验证奖励，并与策略模型同步进行在线训练。为了在利用轨迹相关特征的同时保持梯度的无偏性，我们引入了一种交叉采样（cross-rollout）结构，通过独立采样的内部状态来预测每个采样的价值。由于 POISE 仅使用单次采样即可估计提示词价值，因此在固定的训练计算预算下，它能够实现更高的提示词多样性。这降低了梯度方差，使学习更加稳定，同时也消除了用于检测零优势提示词的采样计算开销。在 Qwen3-4B 和 DeepSeek-R1-Distill-Qwen-1.5B 上的数学推理基准测试中，POISE 在计算量更少的情况下达到了与 DAPO 相当的性能。此外，其价值估计器的表现与独立的 LLM 规模价值模型相似，并能泛化到各种可验证任务。通过利用模型自身的内部表示，POISE 实现了更稳定、更高效的策略优化。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) for Large Reasoning Models hinges on baseline estimation for variance reduction, but existing approaches pay a heavy price: PPO requires a policy-model scale critic, while GRPO needs multiple rollouts per prompt to keep its empirical group mean stable. We introduce Policy Optimization with Internal State Value Estimation), which obtains a baseline at negligible cost by using the policy model's internal signals already computed during the policy forward pass. A lightweight probe predicts the expected verifiable reward from the hidden states of the prompt and generated trajectory, as well as token-entropy statistics, and is trained online alongside the policy. To preserve gradient unbiasedness despite using trajectory-conditioned features, we introduce a cross-rollout construction that predicts each rollout's value from an independent rollout's internal states. Because POISE estimates prompt value using only a single rollout, it enables higher prompt diversity for a fixed compute budget during training. This reduces gradient variance for more stable learning and also eliminates the compute overhead of sampling costs for detecting zero-advantage prompts. On Qwen3-4B and DeepSeek-R1-Distill-Qwen-1.5B across math reasoning benchmarks, POISE matches DAPO while requiring less compute. Moreover, its value estimator shows similar performance to a separate LLM-scale value model and generalizes to various verifiable tasks. By leveraging the model's own internal representations, POISE enables more stable and efficient policy optimization.

这篇论文介绍了一种名为 **POISE**（Policy Optimization with Internal State Value Estimation）的新型强化学习算法，旨在提升大语言模型（LLM）在复杂推理任务中的训练效率和稳定性。以下是对该论文的结构化总结：

### 1. 核心问题与研究动机
在针对大推理模型的可验证奖励强化学习（RLVR）中，为了减少梯度方差，必须引入“基准值（Baseline）”来计算“优势（Advantage）”。
*   **现有方法的瓶颈：**
    *   **PPO：** 需要一个与策略模型规模相当的独立 Critic 模型，这导致显存占用翻倍，计算复杂度极高。
    *   **GRPO：** 通过对同一提示词（Prompt）进行多次采样取均值来作为基准，但这牺牲了提示词的多样性（在固定计算预算下，每个 Batch 包含的独特 Prompt 变少），且在所有采样结果一致时会产生无效梯度。
*   **核心动机：** 探索是否能从策略模型自身的内部计算信号中提取有效的基准值，从而消除对大型 Critic 或大规模重复采样的依赖。

### 2. 方法论：POISE 核心思想与技术细节
POISE 的核心思想是**将策略模型视为其自身的 Critic**，利用其前向传播产生的内部状态来估计价值。

*   **内部状态特征提取：** 探针（Probe）输入包含三个层面的信号：
    1.  **提示词特征（Prompt-level）：** 提取生成开始前最后几个 Prompt Token 的隐藏状态，捕捉模型感知的题目难度。
    2.  **轨迹特征（Trajectory-level）：** 提取推理结束时的隐藏状态，捕捉推理过程的质量。
    3.  **不确定性特征：** 包含 Token 级别的熵统计量。
*   **交叉采样基准（Cross-Rollout Baseline）：** 为了防止梯度偏差（即基准值不能依赖于当前动作），POISE 对每个 Prompt 采样两次（$y^{(1)}, y^{(2)}$）。计算 $y^{(1)}$ 的优势时，使用 $y^{(2)}$ 的内部状态特征来预测基准值，反之亦然。这确保了基准值在给定 Prompt 的条件下与当前响应条件独立。
*   **轻量级在线探针：** 使用一个极其轻量级的线性回归器（或小型 MLP）作为价值估计器，在训练过程中利用滑动缓冲区（Sliding Buffer）存储的近期采样结果进行在线更新。
*   **算法流程：** 采样 -> 提取特征 -> 交叉预测基准 -> 计算优势 -> PPO 风格更新策略 -> 更新轻量级探针。

### 3. 实验设计
*   **模型：** Qwen3-4B 和 DeepSeek-R1-Distill-Qwen-1.5B。

*   **数据集：** 训练使用 DAPO-Math-17K；评估使用 AMC23/24、AIME24/25/26、HMMT25、BRUMO25。
*   **对比方法：** **DAPO**（目前 SOTA 的基于 GRPO 的强化学习系统）。
*   **泛化性测试：** 在代码生成（AceCoder）、工具调用（ToolDial）和指令遵循（IF-RLVR）等非数学领域验证价值估计器的有效性。

### 5. 实验数量与充分性
实验设计非常全面且具有说服力：
*   **性能对比：** 在 7 个数学竞赛基准上进行了测试，结果显示 POISE 与 DAPO 性能相当甚至略优。
*   **消融实验：** 详细分析了不同输入特征（隐藏状态 vs 熵）、不同层索引、不同池化窗口以及探针架构（线性 vs MLP）对预测准确性的影响。
*   **稳定性分析：** 监控了训练过程中的梯度范数（Gradient Norm），证明 POISE 的梯度更稳定。
*   **跨领域验证：** 在 5 个不同领域的数据集上对比了 POISE 探针与全量 Critic 模型的预测相关性，证明了方法的普适性。

### 6. 主要结论与发现
*   **内部状态包含价值信号：** 策略模型的隐藏状态确实编码了关于答案正确性的高度相关信息，线性探针即可提取这些信号。
*   **计算效率更高：** POISE 避免了 GRPO 为了检测“零优势”提示词而进行的额外采样，显著缩短了训练时间。
*   **训练更稳定：** 由于每个 Batch 可以包含更多独特的 Prompt（只需 2 个采样而非 8 个），梯度方差更小，学习曲线更平滑。
*   **性能对等：** 轻量级探针的价值预测能力接近甚至在某些任务上超过了专门训练的 LLM 规模 Critic。

### 7. 优点与亮点
*   **极低开销：** 几乎不增加额外的显存和计算负担，复用了前向传播的中间产物。
*   **优雅的无偏设计：** 巧妙地利用交叉采样解决了轨迹相关特征带来的梯度偏差问题。
*   **高 Prompt 多样性：** 在相同计算预算下，能够处理更多样化的训练数据，这对提升模型泛化能力至关重要。

### 8. 不足与局限
*   **序列级 vs Token 级：** 目前 POISE 主要在序列级别（Sequence-level）进行价值估计，尚未实现更精细的 Token 级别信用分配（Credit Assignment）。
*   **训练时长限制：** 实验主要在固定计算预算下进行，尚未观察在极长训练周期下内部状态信号是否会发生退化或漂移。
*   **应用范围：** 虽然验证了多个领域，但主要集中在具有明确“可验证奖励”（Verifiable Rewards）的任务上，对于主观性较强的任务（如创意写作）效果尚不明确。
