## 摘要
基于大语言模型（LLM）的智能体越来越多地被部署用于处理流式任务，但它们通常仍是单次问题解决者，无法从过去的交互中学习。从经验中提取的可重用技能为自我进化提供了天然基础，而高质量的技能管理（skill curation）则是其中的关键瓶颈。现有方法要么依赖手动技能管理，要么规定启发式技能操作，或者针对短时程技能操作进行训练。然而，它们仍然难以从间接且延迟的反馈中学习复杂的长期管理策略。为了应对这一挑战，我们提出了 SkillOS，这是一种经验驱动的强化学习（RL）训练方案，用于在自我进化智能体中学习技能管理。SkillOS 将一个负责检索和应用技能的冻结智能体执行器与一个可训练的技能管理器配对，后者根据积累的经验更新外部技能库（SkillRepo）。为了提供管理的学习信号，我们设计了复合奖励，并在基于技能相关任务依赖关系的组合任务流上进行训练，其中早期的轨迹用于更新 SkillRepo，而随后的相关任务则用于评估这些更新。在多轮智能体任务和单轮推理任务中，SkillOS 在有效性和效率方面始终优于无记忆和强记忆基线，且学习到的技能管理器能够跨不同的执行器骨干网络和任务领域进行泛化。进一步的分析表明，学习到的管理器能产生更有针对性的技能使用，而 SkillRepo 中的技能随着时间的推移演变成结构更丰富的 Markdown 文件，编码了更高层次的元技能。

## Abstract
LLM-based agents are increasingly deployed to handle streaming tasks, yet they often remain one-off problem solvers that fail to learn from past interactions. Reusable skills distilled from experience provide a natural substrate for self-evolution, where high-quality skill curation serves as the key bottleneck. Existing approaches either rely on manual skill curation, prescribe heuristic skill operations, or train for short-horizon skill operations. However, they still struggle to learn complex long-term curation policies from indirect and delayed feedback. To tackle this challenge, we propose SkillOS, an experience-driven RL training recipe for learning skill curation in self-evolving agents. SkillOS pairs a frozen agent executor that retrieves and applies skills with a trainable skill curator that updates an external SkillRepo from accumulated experience. To provide learning signals for curation, we design composite rewards and train on grouped task streams based on skill-relevant task dependencies, where earlier trajectories update the SkillRepo, and later related tasks evaluate these updates. Across multi-turn agentic tasks and single-turn reasoning tasks, SkillOS consistently outperforms memory-free and strong memory-based baselines in both effectiveness and efficiency, with the learned skill curator generalizing across different executor backbones and task domains. Further analyses show that the learned curator produces more targeted skill use, while the skills in SkillRepo evolve into more richly structured Markdown files that encode higher-level meta-skills over time.

*   **手动管理：** 成本高、难以扩展。

*   **短视优化：** 现有强化学习（RL）方法多关注短期适应，难以处理技能更新、删除等复杂的长期管理决策。

#### 2. 方法论：核心思想与技术细节
论文提出了 **SkillOS**，一个模块化的自我进化框架，其核心思想是将“执行”与“管理”分离：
*   **模块化设计：**
    *   **冻结的执行器（Agent Executor）：** 负责检索技能并执行任务。
    *   **可训练的管理器（Skill Curator）：** 观察执行轨迹，通过函数调用（Insert/Update/Delete）维护外部技能库（SkillRepo）。
*   **关键技术细节：**
    *   **分组任务流训练（Grouped Task Streams）：** 将具有技能依赖关系的任务编组。管理器在组内早期任务中更新技能库，其效果由后续相关任务的成功率来评估，从而将延迟反馈转化为学习信号。
    *   **复合奖励函数：** 包含四个维度：
        1.  **任务结果奖励（$r_{task}$）：** 后续任务的成功率。
        2.  **函数调用奖励（$r_{fc}$）：** 操作格式的合法性。
        3.  **内容质量奖励（$r_{cnt}$）：** 由外部模型（如Qwen3-32B）评估技能的抽象性、重用性和准确性。
        4.  **压缩奖励（$r_{comp}$）：** 鼓励简洁，防止直接复制原始轨迹。
    *   **优化算法：** 使用 **GRPO**（Grouped Reward Policy Optimization）进行策略优化，提高训练稳定性和样本效率。

*   **评估指标：** 成功率（SR）、准确率（Acc）、交互步数（Steps，衡量效率）。

实验设计非常充分且具有说服力：

#### 6. 主要结论与发现
*   **性能卓越：** SkillOS 在所有基准测试中均优于无记忆和强记忆基线，成功率提升显著（如 ALFWorld 相对提升达 9.8%）。
*   **效率提升：** 相比基线，SkillOS 完成任务所需的交互步数更少（减少约 6%），说明学习到的技能能提供更直接的路径。
*   **小模型逆袭：** 经过 RL 训练的 8B 管理器在技能管理任务上超过了未经针对性训练的顶级模型（Gemini-2.5-Pro）。
*   **元技能涌现：** 随着训练进行，技能库不仅积累了具体操作，还演化出了如“失败恢复”、“系统性搜索”等高阶元技能。

#### 7. 优点
*   **解耦设计：** 执行器与管理器分离，使得系统非常灵活，无需重新训练昂贵的执行器即可实现进化。
*   **长时程学习：** 通过任务分组巧妙解决了技能管理中反馈延迟的问题。
*   **可解释性：** 技能以 Markdown 格式存储，人类可读、可编辑、可审计。
*   **泛化能力强：** 训练出的管理策略具有跨领域和跨模型的迁移能力。

#### 8. 不足与局限
*   **检索机制简单：** 目前仅使用 BM25 关键词检索，对于语义复杂的技能匹配可能存在瓶颈。
*   **技能表示单一：** 每个技能被简化为单个 Markdown 文件，暂不支持更复杂的脚本或分层嵌套结构。
*   **执行器冻结：** 虽然解耦是优点，但也意味着管理器必须单方面适应执行器的“脾气”，无法实现双向协同进化。
*   **推理任务增益较小：** 相比具身任务，在单轮推理任务上的提升幅度相对较小，反映出不同任务类型对技能重用的需求差异。
