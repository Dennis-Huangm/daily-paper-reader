## Abstract
Command line interface (CLI) agents are emerging as a practical paradigm for agent-computer interaction over evolving filesystems, executable command line programs, and online execution feedback. Recent work has used reinforcement learning (RL) to learn these interaction abilities from verifiable task feedback, yet few methods exploit the native structured attributes of CLI actions as learning signals. Beyond this underused action structure, CLI learning also couples two bottlenecks for coding agents. First, the agent must identify task-relevant evidence in a large codebase from partial observations. Second, sparse terminal rewards must be assigned to the actions that shape a long multi-turn trajectory. We study these bottlenecks through shell-driven information extraction and file editing tasks. For selective observation, we introduce $σ$-Reveal, an inference-time mechanism that selects token-budgeted context for the same CLI. For credit assignment, we propose Action Advantage Assignment ($\mathrm{A}^3$), a native agentic RL method that preserves the algorithmic complexity of standard agentic RL. $\mathrm{A}^3$ constructs turn-level advantages from episode-level relative feedback, abstract syntax tree (AST) based action sub-chain residuals, and tree-level trajectory margins. To further evaluate this problem setting, we construct ShellOps, a verifiable dataset suite covering CLI tasks in repository environments.

### 1. 核心问题与整体含义
该研究聚焦于**命令行界面（CLI）智能体**在真实计算机环境（如文件系统、代码库）中交互的学习难题。研究动机源于两个核心瓶颈：
*   **选择性观测（Selective Observation）：** 在包含成千上万个文件的大规模工作区中，智能体难以从有限的初始观测中识别出与任务相关的证据。
*   **稀疏信用分配（Sparse Credit Assignment）：** CLI 任务通常涉及长轨迹操作，而奖励往往只在轨迹末端给出（稀疏奖励），难以确定中间哪些具体的 Shell 命令对最终成功做出了贡献。

### 2. 核心方法论
论文提出了一个名为 **$A^3$** 的强化学习框架，并辅以 **$\sigma$-Reveal** 上下文机制：

*   **$\sigma$-Reveal（选择性观测机制）：** 在推理阶段，根据 Token 预算自动筛选初始工作区视图。它通过计算文件节点的“相关性分数”（结合名称匹配、目录深度先验和文件扩展名先验）来构建一个子树，确保智能体在行动前能看到最关键的文件上下文。
*   **$A^3$ (Action Advantage Assignment，动作优势分配)：** 这是一个三通道的优势函数融合方法，用于精细化信用分配：
    1.  **回合级骨干（Episode Backbone）：** 测量当前轨迹相对于同一提示词下其他兄弟轨迹的整体表现。
    2.  **动作子链残差（Turn-Level Action Sub-Chain Residual）：** 利用 **AST（抽象语法树）** 对 Shell 动作进行结构化签名，计算动作间的相似度。通过对比执行了“结构相似动作”的轨迹表现，提取出动作级别的贡献残差。
    3.  **树级优势（Tree Advantage）：** 将交互历史抽象为树状结构，计算不同动作分支之间的边际收益（Margin），并利用折扣因子沿轨迹回传。
*   **结构化动作度量：** 论文不直接比较 Shell 命令的文本，而是使用 Tree-sitter 将其解析为 AST 签名，通过归一化编辑距离来衡量动作意图的相似性，这比纯文本匹配更具鲁棒性。

### 3. 实验设计
*   **数据集：** 构建了 **ShellOps**（1624个任务）和 **ShellOps-Pro**（150个更难的 OOD 任务）。此外，还整合了 AgentBench (OS/DB)、DataBench、EHRCon 和 TableBench 等 6 个基准流。
*   **任务类型：** 涵盖查找（Lookup）、聚合（Aggregate）、编辑（Edit）和混合（Mixed）四类。
*   **对比方法：**
    *   **推理基准：** ReACT, LATS, rStar。
    *   **强化学习基准：** GSPO, GiGPO, HGPO, RetroAgent。
    *   **前沿模型（作为参考）：** Kimi-K2.6, GLM-5.1, Qwen3-235B。
*   **评估指标：** 精确匹配（Exact Match）、Pass@k、LLM Judge 评分、文件差异召回率（Diff Recall）。

### 4. 资源与算力
*   **硬件：** 使用了 **4 台 NVIDIA H200 加速器**。
*   **软件/框架：** 策略模型为 **Qwen3-14B**，使用 **SGLang** 进行训练和推理。
*   **训练细节：** 学习率 $5 \times 10^{-7}$，训练/验证 Batch Size 为 16，最大上下文长度 32,768。环境步数上限为 6 步，沙箱执行超时设为 10 秒。

### 5. 实验数量与充分性
*   **实验规模：** 论文在 6 个不同的基准数据集上进行了广泛测试，并在 ShellOps-Pro 上进行了长时界（Horizon）的扩展性实验。
*   **消融实验：** 针对 $A^3$ 的三个通道（回合、动作、树）分别进行了剔除实验，并研究了动作窗口粒度（$\ell_{max}$）的影响。
*   **公平性与客观性：** 实验在相同的模型（Qwen3-14B）和数据预算下对比了多种 GRPO 家族的变体，并引入了第三方 LLM Judge 和自动化脚本进行双重验证，实验设计较为严谨、客观。

### 6. 主要结论与发现
*   **性能领先：** $A^3$ 结合 $\sigma$-Reveal 在所有 Qwen3-14B 级别的智能体中表现最强，尤其在 ShellOps 混合任务上，精确匹配率从基线的 11.3% 提升至 24.6%。
*   **长时界优势：** 在 ShellOps-Pro 的长轨迹任务中，$A^3$ 的表现甚至能触及参数量大得多的 Qwen3-235B 模型的水平。
*   **训练稳定性：** 相比于 HGPO 或 GiGPO 等方法，$A^3$ 在训练过程中表现出更稳定的 KL 散度和更高的策略熵，避免了早期崩溃。
*   **效率：** AST 相似度计算的开销极低（平均每步约 20ms），远小于 LLM 的推理耗时。

### 7. 优点与亮点
*   **原生结构化信号：** 巧妙地利用了 Shell 语言的 AST 结构作为学习信号，而非将其视为纯文本，这抓住了 CLI 交互的本质。
*   **无需辅助模型：** 与需要额外 Critic 模型或 LLM Judge 进行信用分配的方法相比，$A^3$ 更加轻量且计算高效。
*   **可验证性：** 提出的 ShellOps 数据集强调“可验证的结果”（文件状态或标准输出），为 CLI 智能体提供了更可靠的评估基准。

### 8. 不足与局限
*   **意图与副作用的偏差：** AST 相似性衡量的是“动作意图”，但相同的命令在不同文件状态下可能产生完全不同的副作用，该方法对环境状态的感知仍有提升空间。
*   **$\sigma$-Reveal 的局限：** 该机制依赖于初始文件树的静态属性，如果任务所需的证据隐藏在深层且命名无规律的文件内容中，该机制可能失效。
*   **应用范围：** 目前仅在 Shell/文件系统环境下验证，对于 GUI、Web 或网络协议等非结构化动作空间的泛化能力尚待证明。
