## 摘要
我们引入了递归智能体优化（Recursive Agent Optimization, RAO），这是一种用于训练递归智能体的强化学习方法。递归智能体能够递归地生成自身的新实例，并将子任务委派给这些实例。递归智能体实现了一种推理时扩展算法，使其能够自然地扩展到更长的上下文，并通过分治法泛化到更难的问题。RAO 提供了一种训练模型以充分利用此类递归推理的方法，教会智能体何时以及如何进行委派和通信。我们发现，以这种方式训练的递归智能体具有更高的训练效率，能够处理超出模型上下文窗口的任务，泛化到比训练任务困难得多的任务，并且与单智能体系统相比，可以缩短实际运行时间。

## Abstract
We introduce Recursive Agent Optimization (RAO), a reinforcement learning approach for training recursive agents: agents that can spawn and delegate sub-tasks to new instantiations of themselves recursively. Recursive agents implement an inference-time scaling algorithm that naturally allows agents to scale to longer contexts and generalize to more difficult problems via divide-and-conquer. RAO provides a method to train models to best take advantage of such recursive inference, teaching agents when and how to delegate and communicate. We find that recursive agents trained in this way enjoy better training efficiency, can scale to tasks that go beyond the model's context window, generalize to tasks much harder than the ones the agent was trained on, and can enjoy reduced wall-clock time compared to single-agent systems.

### 2. 方法论：RAO 核心思想与技术细节
*   **核心思想**：训练一个单一的策略 $\pi_\theta$，使其在递归生成的执行树的每个节点上实例化。这意味着同一个模型既要学会直接解决任务，也要学会作为“管理者”生成并协调子智能体。
*   **关键技术细节**：
    *   **动作空间扩展**：引入异步函数 `launch_subagent(goal, ...)`，允许智能体在 Python REPL 环境中派生新实例。支持顺序委派（有依赖）和并行委派（利用 `asyncio.gather`）。
    *   **局部节点奖励（Local Reward）**：每个节点（智能体实例）的奖励由两部分组成：$R = \text{自身任务成功信号} + \lambda \cdot \text{子智能体平均成功率}$。这种设计提供了密集的信用分配（Credit Assignment），鼓励有效的委派。
    *   **策略优化目标**：在递归树的所有节点上联合优化。为了防止深度节点过多导致梯度偏差，引入了**深度级别逆频率加权（Depth-level Inverse-frequency Weighting）**，平衡不同深度轨迹对学习的影响。
    *   **基准线设计**：使用留一法（Leave-one-out）基准线来计算优势函数（Advantage），确保梯度估计的无偏性。

*   **泛化性测试**：在“中等”难度任务上训练，在“困难”难度（递归深度达 10 层）上评估，验证了分治策略的泛化能力。

### 6. 主要结论与发现
*   **突破上下文限制**：递归智能体能通过将长文本拆分给子智能体，解决超出其原生上下文窗口的任务。
*   **训练效率提升**：递归结构提供了一种“隐式课程学习”，使模型在相同训练步数下比单智能体学得更快。
*   **更强的泛化能力**：通过递归委派，模型能解决比训练时复杂得多的任务（测试深度远超训练深度）。
*   **运行耗时优化**：在可并行任务中，递归智能体通过并发执行子任务，实际运行速度比单智能体快达 2.5 倍。

### 7. 优点与亮点
*   **动态执行树**：不同于固定层级的多智能体系统，RAO 支持动态生成的、任意深度的递归树。
*   **端到端训练**：首次实现了递归深度大于 1 的端到端强化学习训练，解决了以往递归模型难以训练的难题。
*   **推理时缩放**：为 LLM 智能体提供了一种通过增加计算深度（递归）来换取更高成功率的有效路径。

### 8. 不足与局限
*   **顺序任务瓶颈**：在 DeepDive 等强顺序依赖任务中，递归虽然提高了成功率，但由于无法并行，实际运行时间显著增加（比单智能体慢 18 倍）。
*   **领域局限性**：目前的实验是在特定领域内分别训练的，尚未实现跨领域的通用递归策略。
*   **采样成本**：在强化学习循环中进行完整的递归采样成本较高，未来需要更高效的代理采样程序。
