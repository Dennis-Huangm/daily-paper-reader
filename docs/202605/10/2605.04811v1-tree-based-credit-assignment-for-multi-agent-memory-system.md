## 摘要
记忆系统被广泛用于增强大语言模型（LLMs）处理长程任务的能力，通常被组织为包含记忆构建、摘要和检索智能体的多智能体流水线。为了增强该系统，现有的基于强化学习（RL）的方法要么对所有智能体统一应用最终的下游任务奖励（如问答准确率），这种方式较为粗糙且模糊；要么为不同子任务上的智能体设计特定任务的奖励，这需要昂贵的标注（如关键证据）且难以可靠地定义。为了解决这些局限性，我们提出了面向多智能体记忆系统的基于树的信用分配（TreeMem），它在无需特定任务标注的情况下，从最终奖励中推导出特定于智能体的信用。具体而言，TreeMem 将多智能体流水线（构建者-摘要者-检索者）扩展为树状结构，其中每个智能体的输出都被扩展为多个后续分支。每个智能体的贡献通过对其后续分支进行蒙特卡洛平均来估计，从而捕捉中间智能体动作如何影响最终奖励。这旨在将粗糙的最终奖励转化为特定于智能体的优化信号。这些信号随后被用于同时更新所有智能体的策略，帮助异构智能体有效地实现专业化。在长程基准测试上的实验表明，TreeMem 相比强基准模型提升了记忆系统的性能，验证了树状结构信用分配在多智能体记忆系统中的有效性。

## Abstract
Memory systems are widely adopted to enhance LLMs for long-horizon tasks, and are commonly organized as multi-agent pipelines with memory building, summarizing, and retrieval agents. To empower this system, existing RL-based methods either apply final downstream task rewards (e.g., QA accuracy) for all agents uniformly, which are coarse and ambiguous, or design task-specific rewards for agents on different subtasks, which require costly annotations (e.g., key evidence) and are difficult to define reliably. To address these limitations, we propose Tree-based Credit Assignment for Multi-Agent Memory Systems (TreeMem), which derives agent-specific credit from the final reward without task-specific annotations. Specifically, TreeMem extends the multi-agent pipeline (builder--summarizer--retrieval) into a tree structure, where each agent's outputs are expanded into multiple subsequent branches. The contribution of each agent is estimated via Monte Carlo averaging over its subsequent branches, capturing how intermediate agent actions may influence the final reward. This converts the coarse final reward into agent-specific optimization signals. These signals are then used to update all agent policies simultaneously, helping heterogeneous agents specialize effectively. Experiments on long-horizon benchmarks show that TreeMem improves memory system performance over strong baselines, validating the effectiveness of tree-structured credit assignment for the multi-agent memory system.

### 1. 核心问题与整体含义（研究动机和背景）
在处理长文本或长程（Long-horizon）任务时，大语言模型（LLM）通常依赖由**构建（Builder）**、**摘要（Summarizer）**和**检索（Retrieval）**智能体组成的多智能体记忆系统。
*   **研究动机**：现有的强化学习（RL）优化方法存在两个痛点：
    1.  **奖励信号模糊**：直接使用最终任务结果（如问答准确率）作为所有智能体的统一奖励，无法区分中间环节（如构建或摘要）的好坏。
    2.  **标注成本高且不可靠**：为每个智能体设计特定任务奖励（如证据覆盖率）需要大量人工标注，且容易导致“奖励作弊”（Reward Hacking），即智能体优化了指标却损害了最终表现。
*   **核心问题**：如何在无需额外人工标注的情况下，将最终的全局奖励公平且精准地分配给多智能体系统中的各个异构智能体。

### 2. 方法论：TreeMem 框架
TreeMem 的核心思想是将线性的智能体流水线扩展为**树状结构**，通过采样多个分支来估算中间动作的贡献。
*   **树状采样（Tree-structured Rollout）**：
    *   在训练阶段，对于同一个输入，构建者采样 $G$ 个动作，摘要者在每个构建动作下采样 $J$ 个分支，检索者在每个摘要下采样 $K$ 个响应。
    *   这形成了一个包含 $G \times J \times K$ 条完整轨迹的树。
*   **信用分配（Credit Assignment）**：
    *   **向上传播**：利用蒙特卡洛平均法，将叶子节点的最终奖励向上回传。
    *   **计算逻辑**：检索者的信用即为最终奖励；摘要者的信用是其下方所有检索分支奖励的平均值；构建者的信用则是所有后续摘要和检索分支的平均值（并加入长度惩罚以抑制冗余）。
*   **策略优化**：
    *   采用类似 **GRPO**（Group Relative Policy Optimization）的算法。
    *   从树中采样代表性轨迹组成小组，计算每个智能体相对于组内平均水平的优势（Advantage），从而同时更新所有异构智能体的策略。

### 6. 主要结论与发现
*   **性能领先**：TreeMem 在所有历史长度下均显著优于现有方法，相比最强基准在 PersonaMem 上平均提升了约 5.5% - 7.5%。

*   **效率优势**：尽管训练时有分支采样，但由于收敛更快且生成的记忆更紧凑（Token 效率更高），整体训练和推理开销具有竞争力。

### 7. 优点（亮点）
*   **无需标注**：巧妙地利用树结构从最终结果中“挖掘”中间信号，极大地降低了数据准备成本。
*   **端到端协同**：解决了多智能体系统中“谁该为失败负责”的经典信用分配难题，实现了异构智能体的联合进化。
*   **鲁棒性强**：对超参数（如分支数量）不敏感，在不同长度和模型底座上表现稳定。

### 8. 不足与局限
*   **训练开销**：虽然论文提到通过采样缓解了压力，但树状扩展在训练阶段的计算量（FLOPs）和显存占用仍高于单路径 RL 方法。
*   **采样偏差**：蒙特卡洛估算的准确性高度依赖于采样分支的数量（$J, K$），在极端复杂的任务中，可能需要更多的分支才能获得稳定的梯度。
*   **应用限制**：目前主要针对“构建-摘要-检索”这种固定的流水线结构，对于更动态、拓扑结构可变的多智能体系统，其适用性有待进一步探索。
