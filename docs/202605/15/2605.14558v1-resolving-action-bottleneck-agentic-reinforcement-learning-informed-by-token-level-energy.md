## 摘要
智能体强化学习利用多轮轨迹训练大语言模型，这些轨迹交织了长推理链与短促的面向环境的动作。常见的策略梯度方法（如 PPO 和 GRPO）对轨迹中的每个 token 一视同仁，导致了均匀的信用分配。在本文中，我们批判性地证明了这种均匀的信用分配在很大程度上错配了 token 级的训练信号。从基于能量的建模视角出发，我们展示了 token 级的训练信号（通过其与从给定提示词采样的不同 rollout 的奖励方差之间的相关性来量化）急剧集中在动作 token 而非推理 token 上，尽管动作 token 仅占轨迹的一小部分。我们将这一现象称为“动作瓶颈”（Action Bottleneck）。受此启发，我们提出了一种极其简单的 token 重加权方法 ActFocus，该方法降低了推理 token 的梯度权重，并结合了一种额外的基于能量的再分配机制，进一步增加了具有更高不确定性的动作 token 的权重。在四种环境和不同模型规模下，ActFocus 的表现始终优于 PPO 和 GRPO，在不增加任何额外运行时间或内存开销的情况下，最终步的增益分别高达 65.2 和 63.7 个百分点。

## Abstract
Agentic reinforcement learning trains large language models using multi-turn trajectories that interleave long reasoning traces with short environment-facing actions. Common policy-gradient methods, such as PPO and GRPO, treat each token in a trajectory equally, leading to uniform credit assignment. In this paper, we critically demonstrate that such uniform credit assignment largely misallocates token-level training signals. From an energy-based modeling perspective, we show that token-level training signals, quantified by their correlations with reward variance of different rollouts sampled from a given prompt, concentrate sharply on action tokens rather than reasoning tokens, even though action tokens account for only a small fraction of the trajectory. We refer to this phenomenon as the Action Bottleneck. Motivated by this observation, we propose an embarrassingly simple token reweighting approach, ActFocus, that downweights gradients on reasoning tokens, along with an additional energy-based redistribution mechanism that further increases the weights on action tokens with higher uncertainty. Across four environments and different model sizes, ActFocus consistently outperforms PPO and GRPO, yielding final-step gains of up to 65.2 and 63.7 percentage points, respectively, without any additional runtime or memory cost.

### 1. 核心问题与整体含义（研究动机和背景）
在智能体强化学习（Agentic RL）中，大语言模型（LLM）生成的轨迹通常包含长篇幅的**推理过程（Reasoning）**和极短的**环境动作（Action）**。
*   **核心矛盾**：现有的策略梯度算法（如 PPO、GRPO）通常采用**均匀信用分配（Uniform Credit Assignment）**，即对轨迹中的每一个 token 赋予相同的权重。
*   **动作瓶颈（Action Bottleneck）**：作者发现，尽管推理 token 占据了轨迹的绝大部分（如 96%），但真正决定环境反馈（奖励）的关键信号却高度集中在极少数的动作 token 上。这种信号错配导致训练效率低下、梯度被噪声稀释，且容易出现训练不稳定的现象。

### 2. 方法论：ActFocus
作者提出了一种名为 **ActFocus** 的 token 级重加权机制，核心思想是“将梯度注意力集中在关键动作上”。

*   **核心思想**：
    1.  **降低推理权重**：通过显式的标签（如 `<think>`）识别推理 token，并降低其梯度权重。
    2.  **基于能量的动作增强**：利用冻结的参考模型（Reference Model）计算动作 token 的“自由能量”（Free Energy），能量越高代表模型对该动作越不确定，从而赋予更高的权重。
*   **关键技术细节**：
    *   **能量计算**：使用参考模型在每个位置生成的 logit，通过公式 $E_t = -\log \sum \exp(\text{logits})$ 计算 token 级能量。
    *   **权重公式**：
        *   对于推理 token：$w_t = \alpha$（通常 $\alpha < 1$）。
        *   对于动作 token：$w_t = 1 + \beta \cdot \text{sigmoid}(\text{normalized } E_t)$。
    *   **目标函数**：将上述权重 $w_t$ 引入 PPO 或 GRPO 的代理损失函数中，通过加权求和代替简单的平均。

### 6. 主要结论与发现
*   **显著提升**：ActFocus 在所有测试配置中均优于基准方法。在 Sudoku 0.5B 任务上，PPO 的成功率从 16.2% 提升至 81.4%（+65.2%）。

*   **响应效率**：ActFocus 训练出的模型倾向于生成更短、更高效的推理轨迹，而不是通过冗长的废话来换取性能。
*   **能量信号的有效性**：实验证明，冻结参考模型的能量信号比动态变化的策略熵更能稳定地指示关键训练位置。

### 7. 优点
*   **简单高效**：方法论极其简洁（“embarrassingly simple”），易于在现有 RL 流程中实现。
*   **零额外开销**：不需要额外的评论家网络（Critic）或复杂的蒙特卡洛采样，计算开销与标准方法持平。
*   **理论支撑**：从能量建模的角度解释了信用分配问题，为智能体训练提供了新的视角。

### 8. 不足与局限
*   **超参数依赖**：$\alpha$ 和 $\beta$ 的最优值在不同任务间存在差异（例如，纯逻辑任务和需要持续推理的任务对 $\alpha$ 的需求不同），可能需要少量调优。
*   **格式依赖**：该方法依赖于模型能够生成显式的推理/动作边界标签（如 `<think>`/`<answer>`），对于不遵循此格式的模型需要额外处理。
*   **环境覆盖**：虽然涵盖了四个环境，但主要集中在离散动作空间，尚未在极其复杂的连续动作或超长程开放域任务中验证。
