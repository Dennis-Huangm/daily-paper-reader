## 摘要
利用大语言模型（LLMs）丰富的世界知识来增强强化学习（RL）智能体，是通往通用智能的一条充满前景的路径。然而，一种根本性的“先验-动力学不匹配”阻碍了现有方法：静态的 LLM 知识无法直接适应长时程任务中复杂的转移动力学。将 LLM 先验作为固定策略使用会限制探索的多样性，因为先验对特定环境的动力学是盲目的；而端到端微调则面临优化不稳定和信用分配问题。为了弥补这一差距，我们提出了 PriorZero，这是一个统一的框架，通过解耦的展开-训练设计，将源自 LLM 的概念先验集成到基于世界模型的规划中。在展开过程中，一种新颖的根节点先验注入机制仅在蒙特卡洛树搜索（MCTS）的根节点引入 LLM 先验，使搜索集中在语义上有前景的动作上，同时保留世界模型的深度前瞻能力。在训练过程中，PriorZero 将世界模型学习与 LLM 适配解耦：世界模型在交互数据上不断优化，以共同提升其动力学、策略和价值预测；随后利用其价值估计，通过交替优化为稳定的 LLM 微调提供细粒度的信用分配信号。在包括 Jericho 中的文本冒险游戏和 BabyAI 中的指令遵循网格世界任务在内的多种基准测试上的实验表明，PriorZero 一致地提高了探索效率和渐近性能，为 LLM 赋能的决策制定建立了一个极具前景的框架。我们的代码可在 https://github.com/opendilab/LightZero 获取。

## Abstract
Leveraging the rich world knowledge of Large Language Models (LLMs) to enhance Reinforcement Learning (RL) agents offers a promising path toward general intelligence. However, a fundamental prior-dynamics mismatch hinders existing approaches: static LLM knowledge cannot directly adapt to the complex transition dynamics of long-horizon tasks. Using LLM priors as fixed policies limits exploration diversity, as the prior is blind to environment-specific dynamics; while end-to-end fine-tuning suffers from optimization instability and credit assignment issues. To bridge this gap, we propose PriorZero, a unified framework that integrates LLM-derived conceptual priors into world-model-based planning through a decoupled rollout-training design. During rollout, a novel root-prior injection mechanism incorporates LLM priors exclusively at the root node of Monte Carlo Tree Search (MCTS), focusing search on semantically promising actions while preserving the world model's deep lookahead capability. During training, PriorZero decouples world-model learning from LLM adaptation: the world model is continuously refined on interaction data to jointly improve its dynamics, policy, and value predictions, its value estimates are then leveraged to provide fine-grained credit assignment signals for stable LLM fine-tuning via alternating optimization. Experiments across diverse benchmarks, including text-based adventure games in Jericho and instruction-following gridworld tasks in BabyAI, demonstrate that PriorZero consistently improves both exploration efficiency and asymptotic performance, establishing a promising framework for LLM-empowered decision-making. Our code is available at https://github.com/opendilab/LightZero.

#### 1. 核心问题与整体含义（研究动机和背景）
论文探讨了如何将大语言模型（LLM）丰富的世界知识有效地转化为强化学习（RL）智能体的决策能力。
*   **研究动机**：在长时程、稀疏奖励的任务中，纯强化学习的试错成本极高。LLM 虽有常识，但存在**“先验-动力学不匹配”**（Prior-Dynamics Mismatch）问题：LLM 的静态知识无法直接感知特定环境的物理/逻辑规则。
*   **现有瓶颈**：直接将 LLM 当作策略（太短视）、端到端微调 LLM（信用分配难、不稳定）、或让 LLM 预测状态转移（粒度不匹配）均存在显著缺陷。
*   **核心目标**：建立一个能够让 LLM 提供语义引导，同时让世界模型（World Model）负责环境建模与深度规划的统一框架。

#### 2. 方法论：核心思想与关键技术
PriorZero 提出了一个**解耦的“展开-训练”架构**，主要包含两个核心机制：
*   **根节点先验注入 (Root-Prior Injection)**：
    *   在蒙特卡洛树搜索（MCTS）中，仅在**根节点**（即当前真实状态）融合 LLM 的语义先验 $\pi_{LLM}$ 和世界模型的策略 $\pi_{WM}$。
    *   公式表达为：$P_{root} = (1-\alpha)\pi_{WM} + \alpha\pi_{LLM}$。
    *   **意义**：LLM 引导搜索方向，避免无效探索；而非根节点（想象状态）完全依赖世界模型，保证了动力学模拟的纯净性。
*   **交替强化微调 (Alternating Reinforcement Fine-Tuning)**：
    *   **解耦优化**：世界模型和 LLM 采用交替更新策略（如 10:1 的步数比例）。
    *   **细粒度信用分配**：利用世界模型训练出的价值函数（Value Function）计算 $n$ 步自举 TD 优势信号（Advantage），作为 LLM 微调的奖励信号。
    *   **PPO 优化**：LLM 通过带思维链（CoT）的 PPO 算法进行更新，使其语义先验逐渐向环境真实的奖励逻辑对齐。

#### 3. 实验设计
*   **实验场景**：
    1.  **Jericho**：复杂的文字冒险游戏（如 *Zork1*, *Detective*），特点是动作空间巨大、奖励极其稀疏、需要逻辑推理。
    2.  **BabyAI**：网格世界指令遵循任务，要求智能体根据自然语言指令完成多步骤物体操作。
*   **Benchmark 与对比方法**：
    *   **P1 (Naive Policy)**：直接 Prompt LLM 输出动作。
    *   **P2 (Naive RLFT)**：端到端强化学习微调 LLM。
    *   **P3 (Dynamics Model)**：用 LLM 作为世界模型的骨干网络。
    *   **P4 (Text Encoder)**：将 LLM 作为冻结的特征提取器。
    *   **UniZero**：不带 LLM 先验的最强世界模型基准。

*   **BabyAI 实验**：多任务运行使用 4 张 H200，训练 100k 步，耗时约 **48 小时**。
*   **模型规模**：主要使用 Qwen2.5-3B-Instruct，消融实验中扩展到了 7B 版本。

#### 5. 实验数量与充分性
*   **实验规模**：涵盖了 4 个代表性 Jericho 游戏和 18 个 BabyAI 关卡，实验覆盖了从简单推理到极长时程规划的不同维度。
*   **消融实验**：非常充分，分别验证了**交替训练策略、CoT 权重 ($w_{cot}$)、LLM 模型规模、以及 MCTS 规划**对最终性能的影响。
*   **客观性**：所有主实验均采用 3 个随机种子并标注了阴影区域（标准差），对比实验在相同的环境步数预算下进行，确保了公平性。

#### 6. 主要结论与发现
*   **性能提升**：PriorZero 在所有基准测试中均显著优于纯世界模型（UniZero）和各类 LLM 迁移范式。
*   **探索效率**：LLM 先验在训练初期能显著降低 MCTS 根节点的熵，使智能体更快发现高奖励路径。
*   **相互促进**：世界模型为 LLM 提供了低方差的训练信号，而微调后的 LLM 反过来提供了更精准的搜索引导，形成了正向闭环。
*   **CoT 的必要性**：在 RL 过程中，保留 CoT 过程并给予适当的损失权重对训练稳定性至关重要，直接输出动作容易导致数值崩溃（NaN）。

#### 7. 优点
*   **架构优雅**：通过“根节点注入”巧妙解决了 LLM 无法处理非文本潜空间状态的问题。
*   **稳定性强**：利用世界模型的价值估计代替原始环境奖励，解决了 LLM 在稀疏奖励下难以收敛的顽疾。
*   **通用性**：在纯文本环境（Jericho）和具身模拟环境（BabyAI）中均表现出色，证明了框架的泛化潜力。

#### 8. 不足与局限
*   **计算开销**：尽管比端到端微调更高效，但 MCTS 过程中频繁调用 LLM（即使仅在根节点）和交替训练仍需消耗大量算力。
*   **动作空间限制**：目前主要针对离散动作空间（文字或高层语义动作），在连续控制任务中的表现尚未验证。
*   **依赖世界模型质量**：如果世界模型在初期无法建立起起码的价值估计，LLM 的微调可能会受到错误信号的干扰（虽然论文通过预热阶段缓解了此问题）。
