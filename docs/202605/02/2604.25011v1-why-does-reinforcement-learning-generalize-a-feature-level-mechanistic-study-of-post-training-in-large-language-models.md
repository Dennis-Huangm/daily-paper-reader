## 摘要
基于强化学习（RL）的训练后处理通常能提升大语言模型（LLMs）在训练领域之外的推理性能，而监督微调（SFT）则经常导致通用能力的遗忘。然而，这种差异背后的机制尚不清楚。为了填补这一空白，我们提出了一种特征级机理分析方法，通过受控实验设置来探究 RL 的泛化性，其中 RL 和 SFT 微调模型是在相同数据上基于同一基础模型训练而成的。利用我们的可解释性框架，我们将不同模型的内部激活对齐到共享特征空间中，并分析特征在训练后阶段的演变过程。我们发现，SFT 会迅速引入许多高度专门化的特征，并在训练早期趋于稳定；而 RL 引起的特征变化则更为克制且持续演变，在很大程度上保留了基础模型的表示。针对 RL 成功但基础模型失败的样本，我们识别出一组紧凑且与任务无关的特征，这些特征直接介导了跨不同任务的泛化。特征级干预证实了它们的因果作用：禁用这些特征会显著降低 RL 模型的泛化性能，而放大这些特征则能提升基础模型的性能。代码可在 https://github.com/danshi777/RL-generalization 获取。

## Abstract
Reinforcement learning (RL)-based post-training often improves the reasoning performance of large language models (LLMs) beyond the training domain, while supervised fine-tuning (SFT) frequently leads to general capabilities forgetting. However, the mechanisms underlying this contrast remain unclear. To bridge this gap, we present a feature-level mechanistic analysis methodology to probe RL generalization using a controlled experimental setup, where RL- and SFT-tuned models are trained from the same base model on identical data. Leveraging our interpretability framework, we align internal activations across models within a shared feature space and analyze how features evolve during post-training. We find that SFT rapidly introduces many highly specialized features that stabilize early in training, whereas RL induces more restrained and continually evolving feature changes that largely preserve base models' representations. Focusing on samples where RL succeeds but the base model fails, we identify a compact, task-agnostic set of features that directly mediate generalization across diverse tasks. Feature-level interventions confirm their causal role: disabling these features significantly degrades RL models' generalization performance, while amplifying them improves base models' performance. *   **核心问题**：为什么基于 RL 的训练后处理能显著提升模型在训练域之外的泛化能力，而 SFT 往往会导致通用能力的遗忘？
*   **研究背景**：尽管经验观察表明 RL 在数学和逻辑推理任务中表现出强大的跨领域迁移能力，但其内部机制（即弱反馈信号如何产生广泛的泛化）仍是一个黑盒。

*   **三模型对齐与归因**：
    *   **三模型稀疏交叉编码器**：同时对齐 Base、SFT 和 RL 三个模型，确保特征在同一基准下可比。

*   **泛化控制特征识别**：
    *   定义“泛化关键样本”：Base 模型失败但 RL 模型成功的样本。
    *   计算**泛化得分（Generalization Score）**：测量 RL 与 Base 模型在这些样本上的激活差异，识别出跨任务一致激活的紧凑特征集。
*   **因果干预**：通过“置零（Zeroing）”和“放大（Amplifying）”特定特征，验证其对模型行为的因果影响。

### 6. 主要结论与发现
*   **特征演化差异**：SFT 会迅速引入大量高度专门化的新特征，并很快在训练早期稳定，这导致了对原始能力的挤压（遗忘）；而 RL 的特征变化更为克制、缓慢且持续演化，很大程度上保留了基座模型的表征结构。
*   **泛化机制**：RL 并不是简单地学习任务特定知识，而是激活并增强了一组**任务无关（Task-agnostic）**的通用特征。
*   **因果证据**：在 RL 模型中禁用这些“泛化特征”会导致性能大幅下降（最高超过 40%）；而在 Base 模型中人为放大这些特征，能使其在未见过的任务上表现出显著的性能提升。

### 7. 优点
*   **深度机理分析**：不仅停留在行为观察，而是深入到神经元特征级别解释了 RL 的优越性。
*   **创新的工具**：提出的三模型交叉编码器和 MAS 分数是研究模型差异的有力工具。
*   **因果闭环**：通过干预实验（不仅是相关性分析）证实了泛化特征的实际作用。

### 8. 不足与局限
*   **特征捕获限制**：稀疏交叉编码器虽然强大，但可能无法捕获所有功能相关的内部结构，存在一定的表征偏差。
*   **训练指导性不足**：目前的研究主要在于“解释”，虽然发现了泛化特征，但尚未直接提出如何通过设计新的训练目标来显式诱导这些特征。
*   **计算开销**：训练高维度的稀疏交叉编码器（如 32k 特征）需要大量的计算资源，限制了其在大规模模型上的快速迭代。
