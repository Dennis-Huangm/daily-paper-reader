## 摘要
遵循顺序“推理-行动”（reason-then-act）范式的大语言模型（LLM）智能体在许多复杂任务中取得了卓越的性能。然而，由于这些方法每步仅与单个环境交互，因此面临探索受限和环境理解不完整的问题。在本文中，我们首先引入了一种新颖的范式，使智能体能够同时与多个环境交互并共享跨轨迹经验。基于这一范式，我们进一步提出了 DPEPO，这是一种鼓励智能体进行多样化并行探索的强化学习（RL）算法。DPEPO 包含两个阶段：初始的有监督微调（SFT）赋予智能体基础的并行推理和动作生成能力，随后是采用分层奖励方案的强化学习阶段。我们设计了一个并行轨迹级成功奖励和两个步级奖励：多样化动作奖励（Diverse Action Reward）和多样化状态转移奖励（Diverse State Transition Reward），旨在主动惩罚行为冗余并促进广泛探索。在 ALFWorld 和 ScienceWorld 上的广泛实验表明，DPEPO 达到了最先进（SOTA）的成功率，同时保持了与强顺序基线模型相当的效率。（代码可在 https://github.com/LePanda026/Code-for-DPEPO 获取）

## Abstract
Large language model (LLM) agents that follow the sequential "reason-then-act" paradigm have achieved superior performance in many complex tasks.However, these methods suffer from limited exploration and incomplete environmental understanding, as they interact with only a single environment per step. In this paper, we first introduce a novel paradigm that enables an agent to interact with multiple environments simultaneously and share cross-trajectory experiences. Building upon this paradigm, we further propose DPEPO, a reinforcement learning (RL) algorithm that encourages the agent to perform diverse parallel exploration. There are two stages in DPEPO: initial supervised fine-tuning (SFT) imparts basic parallel reasoning and action generation, followed by reinforcement learning stage with a hierarchical reward scheme. We design a parallel trajectory-level success reward and two step-level rewards: Diverse Action Reward and Diverse State Transition Reward, which actively penalize behavioral redundancy and promote broad exploration. Extensive experiments on ALFWorld and ScienceWorld show that DPEPO achieves state-of-the-art (SOTA) success rates, while maintaining comparable efficiency to strong sequential baselines. ### 1. 核心问题与整体含义（研究动机和背景）
传统的 LLM 智能体通常遵循 **ReAct**（推理-行动）范式，即每一步只选择一个动作并观察一个反馈。这种“线性”交互方式存在两大缺陷：
*   **探索受限**：智能体只能从狭窄的视角理解环境，容易陷入局部最优或因信息不足导致决策失败。
*   **效率低下**：虽然可以通过多次独立采样（Multi-sampling）来增加探索，但不同轨迹间缺乏经验共享，且动作往往趋同（缺乏多样性），导致计算资源浪费。
**研究动机**：提出一种并行探索范式，让智能体能同时与多个环境交互，构建对环境的全面认知。

### 2. 方法论：核心思想与关键技术
论文提出了 **DPEPO（多样化并行探索策略优化）** 框架，核心流程分为两个阶段：

*   **阶段一：有监督微调（SFT）冷启动**
    *   通过人工标注和模型合成（如 DeepSeek-V3）生成包含并行探索行为的轨迹数据。
    *   训练智能体掌握基础的并行推理格式（使用 `<parallel>` 和 `<env_i>` 标签）。

*   **阶段二：强化学习（RL）优化**
    *   **并行环境交互**：智能体在每一步动态选择多个环境（子集）执行并行动作。
    *   **层次化奖励机制**：
        1.  **并行轨迹级成功奖励 ($R_{traj}$)**：只要并行轨迹中任一路径成功，即给予奖励。
        2.  **多样化动作奖励 ($R_{action}$)**：惩罚在单个环境内（深度）或跨环境间（宽度）的重复动作。
        3.  **多样化状态转移奖励 ($R_{transition}$)**：惩罚重复的“状态-动作”转移对，强制智能体探索未知的状态空间。
    *   **策略优化**：采用类似 **GRPO** 的组相对优势计算，无需 Critic 模型，通过组内轨迹的相对表现来估计优势函数，并结合步级（Step-level）奖励进行细粒度信用分配。

### 6. 主要结论与发现

*   **Token 优势**：随着并行环境数增加，DPEPO 的 Token 增长速度远低于简单的多次采样策略。

### 7. 优点（亮点）
*   **范式创新**：打破了 ReAct 的线性限制，提出了“并行探索、经验共享”的新模式。
*   **奖励设计精巧**：通过惩罚“冗余”而非仅仅奖励“成功”，有效解决了强化学习在稀疏奖励环境下的探索难题。
*   **训练高效**：去除了 Critic 模型，利用组相对优势和并行采样，大幅缩短了训练周期。

### 8. 不足与局限
*   **环境依赖性**：该方法依赖于能够被并行实例化的模拟器。在无法轻易创建多个并行副本的现实物理环境（如单体机器人）中，应用难度较大。
*   **偏见风险**：论文提到并行探索可能让智能体接触并学习到环境中的潜在偏见，需加强安全性评估。
*   **上下文压力**：虽然设计了 Prompt 压缩方案，但并行环境的信息堆叠仍会对 LLM 的长文本处理能力提出更高要求。
