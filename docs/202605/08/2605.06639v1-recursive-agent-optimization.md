## 摘要
我们引入了递归智能体优化（Recursive Agent Optimization, RAO），这是一种用于训练递归智能体的强化学习方法。递归智能体可以递归地生成自身的新实例并向其委派子任务。递归智能体实现了一种推理时扩展算法，使其能够通过分而治之的方式自然地扩展到更长的上下文，并泛化到更难的问题。RAO 提供了一种训练模型以充分利用此类递归推理的方法，教会智能体何时以及如何进行委派和通信。我们发现，以这种方式训练的递归智能体具有更高的训练效率，能够处理超出模型上下文窗口的任务，泛化到比训练任务困难得多的任务，并且与单智能体系统相比，可以减少实际运行时间。

## Abstract
We introduce Recursive Agent Optimization (RAO), a reinforcement learning approach for training recursive agents: agents that can spawn and delegate sub-tasks to new instantiations of themselves recursively. Recursive agents implement an inference-time scaling algorithm that naturally allows agents to scale to longer contexts and generalize to more difficult problems via divide-and-conquer. RAO provides a method to train models to best take advantage of such recursive inference, teaching agents when and how to delegate and communicate. We find that recursive agents trained in this way enjoy better training efficiency, can scale to tasks that go beyond the model's context window, generalize to tasks much harder than the ones the agent was trained on, and can enjoy reduced wall-clock time compared to single-agent systems.

### 2. 方法论
*   **核心思想**：将递归执行建模为一个动态生成的执行树，树中的每个节点都是同一个策略网络 $\pi_\theta$ 的实例。通过端到端的强化学习，同时优化根智能体和所有子智能体的决策。
*   **关键技术细节**：
    *   **动作空间扩展**：引入异步函数 `launch_subagent(goal, ...)`，允许智能体生成子智能体。支持并行执行（通过 Python 的 `asyncio`）和串行执行。
    *   **局部节点奖励（Local Reward）**：每个节点 $X$ 的奖励由两部分组成：
        $$R(X, \tau_X) = \tilde{s}(X, \tau_X) + \lambda \cdot \text{mean}(\tilde{s}(\text{children}))$$
        其中 $\tilde{s}$ 是任务成功信号，$\lambda$ 是委派奖励系数。这鼓励智能体不仅要解决自己的任务，还要有效地委派子任务。
    *   **策略优化**：使用基于优势（Advantage）的强化学习。为了解决递归树中深层节点远多于根节点的问题，引入了**深度级别逆频率加权（Depth-level inverse-frequency weighting）**，防止优化过程被深层轨迹主导。
    *   **留一法基准（Leave-one-out Baseline）**：在计算优势函数时，使用同一根任务下不同采样轨迹的平均奖励作为基准，以降低方差且保持无偏。

### 7. 优点
*   **端到端训练**：不同于以往只在推理时套用模板，RAO 真正教会了模型如何“思考”委派逻辑。
*   **动态性**：支持动态生成的执行树，而非固定的层级结构，适应性更强。
*   **异步支持**：原生支持异步编程模式，充分利用了现代计算环境的并发能力。

### 8. 不足与局限
*   **推理成本**：在某些顺序依赖的任务（如 DeepDive）中，递归智能体虽然成功率更高，但由于步骤更多，token 消耗和延迟显著增加（比单智能体慢 18 倍）。
*   **评估依赖**：在缺乏自动校验器的任务中，高度依赖 LLM Judge（如 GPT-5-mini）来评估子任务的成功，可能引入评估偏差。
*   **领域局限**：目前实验主要在特定领域内训练，尚未实现跨领域的通用递归策略迁移。
*   **采样开销**：完整的递归树采样在强化学习循环中成本极高，未来需要更高效的代理采样程序。
