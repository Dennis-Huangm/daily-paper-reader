## 摘要
技能库使大语言模型智能体能够重用过去交互中的经验，但大多数现有技能库将技能存储为孤立的条目，并仅通过语义相似性进行检索。这给组合性任务带来了两个关键挑战。首先，智能体不仅必须识别相关技能，还必须识别它们如何相互依赖和构建。其次，这也使得技能库的维护变得困难，因为系统缺乏决定何时合并、拆分或删除技能的结构化线索。我们提出了 SKILLGRAPH，这是一个将可重用技能表示为有向图中节点的框架，其中类型化边编码了先验、增强和共现关系。给定一个新任务，SKILLGRAPH 不仅检索单个技能，还检索一个有序的技能子图，该子图可以指导多步决策。该图根据智能体轨迹和强化学习反馈不断更新，从而使技能库和智能体策略能够共同改进。在 ALFWorld、WebShop 和七个搜索增强问答任务上的实验表明，SKILLGRAPH 在与记忆增强强化学习方法的对比中实现了最先进的性能，在需要组合多种技能的复杂任务上增益尤为显著。

## Abstract
Skill libraries enable large language model agents to reuse experience from past interactions, but most existing libraries store skills as isolated entries and retrieve them only by semantic similarity. This leads to two key challenges for compositional tasks. Firstly, an agent must identify not only relevant skills but also how they depend on and build upon each other. Secondly, it also makes library maintenance difficult, since the system lacks structural cues for deciding when skills should be merged, split, or removed. We propose SKILLGRAPH, a framework that represents reusable skills as nodes in a directed graph, with typed edges encoding prerequisite, enhancement, and co-occurrence relations. Given a new task, SKILLGRAPH retrieves not just individual skills, but an ordered skill subgraph that can guide multi-step decision making. The graph is continuously updated from agent trajectories and reinforcement learning feedback, allowing both the skill library and the agent policy to improve together. Experiments on ALFWorld, WebShop, and seven search-augmented QA tasks show that SKILLGRAPH achieves state-of-the-art performance against memory-augmented RL methods, with especially large gains on complex tasks that require composing multiple skills.

### 1. 核心问题与整体含义
**研究动机：** 
现有的大语言模型（LLM）智能体通常使用“扁平化”的技能库来存储经验，即技能之间是孤立的，仅靠语义相似度检索。这导致了两个主要问题：
1. **缺乏组合能力：** 复杂任务（如“加热并放置物体”）需要技能按特定顺序执行，扁平检索无法提供技能间的依赖关系。
2. **维护困难：** 缺乏结构化信息，系统难以判断何时该合并冗余技能、拆分宽泛技能或删除过时技能。

**核心含义：** 
论文提出了 **SKILLGRAPH** 框架，将技能组织为**有向图**，通过类型化边（先验、增强、共现）描述技能关系，并让技能图与智能体策略在强化学习（RL）过程中共同演化，实现“更丰富的轨迹 -> 更好的图 -> 更好的检索 -> 更强的策略”的闭环。

### 2. 方法论
SKILLGRAPH 包含三个关键阶段，并集成在强化学习循环中：

*   **图构建（Graph Construction）：**
    *   从成功/失败轨迹中蒸馏出“通用技能”和“任务特定技能”。
    *   定义三种边：**Prerequisite**（A是B的前提）、**Enhances**（通用技能A增强特定技能B）、**Co-occurs**（A与B常同时出现）。
    *   根据依赖关系计算节点的**拓扑层级（Level）**。
*   **图感知检索（Graph-Aware Retrieval）：**
    *   **种子选择：** 选取与任务相关的初始技能。
    *   **图扩展：** 通过后向 BFS 寻找前提技能，通过前向 Beam Search 寻找后续增强技能。
    *   **拓扑排序：** 将检索到的技能按依赖顺序排列，作为 Prompt 引导智能体。
*   **图演化（Graph Evolution）：**
    *   **节点级适配：** 根据成功率和使用频率进行插入（Insert）、合并（Merge）、拆分（Split）和弃用（Deprecate）。
    *   **边级适配：** 强化成功路径上的边权重，发现新的共现关系，并对弱边进行衰减和剪枝。
    *   **渐进式解锁：** 只有当低层级（基础）技能掌握后，才解锁高层级（复杂）技能。
*   **策略优化：** 使用 **GRPO**（Group Relative Policy Optimization）算法，利用技能图提供的结构化引导进行大规模强化学习训练。

### 6. 主要结论与发现
*   **性能领先：** SKILLGRAPH 在所有基准测试中均达到 SOTA。在 ALFWorld 上，7B 模型配合技能图的表现大幅超过了 GPT-4o 和 Gemini-2.5-Pro。
*   **复杂任务增益大：** 在需要严格执行顺序的任务（如 ALFWorld 的 Clean/Heat 任务）中，图感知检索带来的有序引导至关重要。
*   **效率提升：** 相比扁平检索，图检索能提供更精准、更短的技能序列，减少了 Prompt 长度，降低了推理成本。
*   **演化有效性：** 动态演化机制能自动过滤低质量技能并发现技能间的深层关联，使智能体能从简单任务向复杂任务迁移知识。

### 7. 优点
*   **结构化创新：** 首次将技能库从“列表”提升为“图”，解决了技能依赖和组合的根本问题。
*   **闭环演化：** 技能图与策略同步进化，具备自我修复和自我增强的能力。
*   **课程学习：** 通过拓扑层级的渐进式解锁，为 RL 训练提供了天然的课程学习机制，加速了收敛。
*   **泛化性强：** 实验证明在特定领域训练的技能图可以有效迁移到未见过的同类任务中。

### 8. 不足与局限
*   **教师模型依赖：** 技能的蒸馏、合并、拆分等操作高度依赖高性能教师模型（如 OpenAI o3），这增加了训练阶段的 API 成本。
*   **推理延迟：** 虽然 Prompt 变短了，但检索阶段涉及图遍历和多次扩展操作，可能增加系统复杂度和初始检索延迟。
*   **跨环境迁移：** 目前的技能图主要在单一或相似环境内演化，如何在完全不同的环境间（如从家居操作到网页导航）共享技能图仍有待研究。
*   **安全风险：** 自动蒸馏的技能可能包含教师模型的偏见或幻觉，虽然有弃用机制，但在安全敏感领域仍需人工审核。
