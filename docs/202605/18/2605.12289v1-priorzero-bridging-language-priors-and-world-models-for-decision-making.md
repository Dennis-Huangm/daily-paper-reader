## 摘要
利用大语言模型（LLMs）丰富的世界知识来增强强化学习（RL）智能体，是通往通用智能的一条充满前景的路径。然而，一种根本性的先验-动力学不匹配阻碍了现有方法：静态的 LLM 知识无法直接适应长时程任务中复杂的转移动力学。将 LLM 先验作为固定策略使用会限制探索的多样性，因为先验对特定环境的动力学是盲目的；而端到端微调则面临优化不稳定和信用分配问题。为了弥补这一差距，我们提出了 PriorZero，这是一个统一的框架，通过解耦的展开-训练设计，将源自 LLM 的概念先验集成到基于世界模型的规划中。在展开阶段，一种新颖的根节点先验注入机制仅在蒙特卡洛树搜索（MCTS）的根节点引入 LLM 先验，使搜索集中在语义上有前景的动作上，同时保留世界模型的深度前瞻能力。在训练阶段，PriorZero 将世界模型学习与 LLM 适配解耦：世界模型在交互数据上不断细化，以共同改进其动力学、策略和价值预测，随后利用其价值估计，通过交替优化为稳定的 LLM 微调提供细粒度的信用分配信号。在包括 Jericho 中的文本冒险游戏和 BabyAI 中的指令遵循网格世界任务在内的多种基准测试上的实验表明，PriorZero 持续提高了探索效率和渐近性能，为 LLM 赋能的决策制定建立了一个极具前景的框架。我们的代码可在 https://github.com/opendilab/LightZero 获取。

## Abstract
Leveraging the rich world knowledge of Large Language Models (LLMs) to enhance Reinforcement Learning (RL) agents offers a promising path toward general intelligence. However, a fundamental prior-dynamics mismatch hinders existing approaches: static LLM knowledge cannot directly adapt to the complex transition dynamics of long-horizon tasks. Using LLM priors as fixed policies limits exploration diversity, as the prior is blind to environment-specific dynamics; while end-to-end fine-tuning suffers from optimization instability and credit assignment issues. To bridge this gap, we propose PriorZero, a unified framework that integrates LLM-derived conceptual priors into world-model-based planning through a decoupled rollout-training design. During rollout, a novel root-prior injection mechanism incorporates LLM priors exclusively at the root node of Monte Carlo Tree Search (MCTS), focusing search on semantically promising actions while preserving the world model's deep lookahead capability. During training, PriorZero decouples world-model learning from LLM adaptation: the world model is continuously refined on interaction data to jointly improve its dynamics, policy, and value predictions, its value estimates are then leveraged to provide fine-grained credit assignment signals for stable LLM fine-tuning via alternating optimization. Experiments across diverse benchmarks, including text-based adventure games in Jericho and instruction-following gridworld tasks in BabyAI, demonstrate that PriorZero consistently improves both exploration efficiency and asymptotic performance, establishing a promising framework for LLM-empowered decision-making. Our code is available at https://github.com/opendilab/LightZero.

#### 1. 核心问题与研究动机
论文探讨了如何有效地将大语言模型（LLM）丰富的世界知识转化为强化学习（RL）智能体的决策能力。
*   **核心矛盾：** 现有的“先验-动力学不匹配”（Prior-Dynamics Mismatch）。LLM 擅长语义推理（静态知识），但难以直接处理特定环境的转移动力学、长期信用分配和复杂的规划任务。
*   **现有范式的缺陷：** 
    *   直接作为策略（Naive Policy）会导致决策短视；
    *   端到端微调（RLFT）在稀疏奖励下优化极不稳定；
    *   作为动力学模型（Dynamics Model）存在 Token 级别与状态-动作级别之间的粒度不匹配。
*   **研究目标：** 提出一个能够解耦 LLM 语义先验与环境动力学建模的统一框架，实现两者的协同进化。

#### 2. 方法论：PriorZero 框架
PriorZero 采用了**解耦的展开-训练（Decoupled Rollout-Training）**设计：
*   **根节点先验注入（Root-Prior Injection）：**
    *   在蒙特卡洛树搜索（MCTS）过程中，LLM 的语义先验仅注入到**根节点**。
    *   **公式逻辑：** 根节点策略 $P_{root} = (1-\alpha)\pi_{WM} + \alpha\pi_{LLM}$，而非根节点则完全依赖世界模型（WM）的预测。
    *   **作用：** 利用 LLM 引导搜索方向，同时避免 LLM 干扰世界模型在深层潜在空间中的动力学模拟。
*   **交替强化微调（Alternating Reinforcement Fine-Tuning）：**
    *   **解耦优化：** 训练过程在世界模型更新和 LLM 适配之间交替进行（比例约为 10:1）。
    *   **信用分配信号：** 利用世界模型训练出的价值估计（Value Estimates）来构建低方差的 $n$ 步自助法（Bootstrapped）优势信号（Advantage），通过 PPO 算法稳定地微调 LLM。
*   **结构化先验提取：** 采用“先分析再决策”的思维链（CoT）提示词模板，减少 LLM 的合理化偏差。

#### 3. 实验设计
*   **实验场景：**
    *   **Jericho：** 文本冒险游戏基准（如 *Detective*, *Zork1* 等），侧重长程规划和稀疏奖励。
    *   **BabyAI：** 指令遵循的网格世界任务（18个不同等级的任务），侧重多任务泛化和空间语义理解。
*   **对比基准（Baselines）：**
    *   **UniZero：** 最先进的基于潜在世界模型的规划算法（不含 LLM）。
    *   **P1-P4 范式：** 包括纯 LLM 策略、端到端 RLFT、LLM 作为动力学模型、LLM 作为固定文本编码器。

#### 4. 资源与算力
*   **硬件：** 使用 NVIDIA **H200** GPU。
*   **算力消耗：**
    *   **Jericho：** 每个单任务运行使用 4 张 H200，训练 50k 步约需 **35 小时**。
    *   **BabyAI：** 每个多任务运行使用 4 张 H200，训练 100k 步约需 **48 小时**。
*   **模型规模：** 主要使用 Qwen2.5-3B-Instruct，部分实验扩展至 7B 版本。

#### 5. 实验数量与充分性
*   **实验规模：** 涵盖了 4 个 Jericho 游戏和 18 个 BabyAI 任务等级。
*   **消融实验：** 非常充分，分别验证了交替训练策略、CoT 权重（$w_{cot}$）、LLM 模型规模（3B vs 7B）以及 MCTS 规划组件的必要性。
*   **客观性：** 主要实验结果基于 3 个随机种子，并提供了误差带（Shaded regions）。对于明显失败的变体（如关闭 MCTS），作者在文中说明仅使用单种子以节省算力，这在学术规范内是合理的。

#### 6. 主要结论与发现
*   **性能提升：** PriorZero 在所有基准测试中均显著优于纯世界模型（UniZero）和其他 LLM 迁移范式。
*   **探索效率：** LLM 先验能有效降低 MCTS 根节点的熵，使搜索集中在语义合理的动作上，从而打破“奖励循环”或“逻辑死循环”。
*   **稳定性：** 通过世界模型提供的价值信号微调 LLM，比直接从环境奖励微调更稳定，解决了长程任务中的信用分配难题。
*   **扩展性：** 随着 LLM 规模从 3B 增加到 7B，复杂任务（如 *Zork1*）的性能有进一步提升。

#### 7. 优点与亮点
*   **架构优雅：** 巧妙地通过“根节点注入”解决了 LLM 无法直接处理潜在空间动力学的问题。
*   **闭环进化：** 建立了一个互惠循环——LLM 引导世界模型探索高质量轨迹，世界模型反过来为 LLM 提供精准的微调反馈。
*   **实用性强：** 兼容现有的 MCTS 框架（如 LightZero），且在处理稀疏奖励任务上表现卓越。

#### 8. 不足与局限
*   **动作空间限制：** 目前主要针对离散动作空间（文本指令或网格动作），尚未在连续控制任务中验证。
*   **计算开销：** 尽管比端到端微调更高效，但同时运行 LLM 和世界模型仍需较高的显存和计算资源。
*   **依赖性：** LLM 的微调质量高度依赖于世界模型价值估计的准确性，若世界模型在初期训练崩溃，LLM 可能会学到错误的先验。
