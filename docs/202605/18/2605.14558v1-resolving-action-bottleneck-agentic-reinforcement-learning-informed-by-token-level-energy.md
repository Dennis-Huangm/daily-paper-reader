## 摘要
智能体强化学习利用多轮轨迹训练大语言模型，这些轨迹交织了长推理链与短环境交互动作。常见的策略梯度方法（如 PPO 和 GRPO）对轨迹中的每个 token 一视同仁，导致了均匀的信用分配。在本文中，我们批判性地证明了这种均匀的信用分配在很大程度上错配了 token 级的训练信号。从基于能量的模型视角出发，我们展示了 token 级的训练信号（通过其与给定提示词下不同采样轨迹的奖励方差之间的相关性来量化）急剧集中在动作 token 而非推理 token 上，尽管动作 token 仅占轨迹的一小部分。我们将这一现象称为“动作瓶颈”。受此启发，我们提出了一种极其简单的 token 重加权方法 ActFocus，该方法降低了推理 token 的梯度权重，并结合了一种额外的基于能量的再分配机制，进一步增加了具有更高不确定性的动作 token 的权重。在四种环境和不同模型规模下，ActFocus 的表现始终优于 PPO 和 GRPO，在不增加任何额外运行时间或内存成本的情况下，最终步的增益分别高达 65.2 和 63.7 个百分点。

## Abstract
Agentic reinforcement learning trains large language models using multi-turn trajectories that interleave long reasoning traces with short environment-facing actions. Common policy-gradient methods, such as PPO and GRPO, treat each token in a trajectory equally, leading to uniform credit assignment. In this paper, we critically demonstrate that such uniform credit assignment largely misallocates token-level training signals. From an energy-based modeling perspective, we show that token-level training signals, quantified by their correlations with reward variance of different rollouts sampled from a given prompt, concentrate sharply on action tokens rather than reasoning tokens, even though action tokens account for only a small fraction of the trajectory. We refer to this phenomenon as the Action Bottleneck. Motivated by this observation, we propose an embarrassingly simple token reweighting approach, ActFocus, that downweights gradients on reasoning tokens, along with an additional energy-based redistribution mechanism that further increases the weights on action tokens with higher uncertainty. Across four environments and different model sizes, ActFocus consistently outperforms PPO and GRPO, yielding final-step gains of up to 65.2 and 63.7 percentage points, respectively, without any additional runtime or memory cost.

#### 1. 核心问题与整体含义（研究动机和背景）
在智能体强化学习（Agentic RL）中，大语言模型（LLM）生成的轨迹通常包含长篇幅的**推理 Token**（如 `<think>` 块）和极短的**动作 Token**（如环境交互指令）。
*   **研究动机**：现有的策略梯度方法（如 PPO 和 GRPO）通常采用**均匀信用分配**，即对轨迹中的每个 Token 赋予相同的权重。
*   **核心问题**：作者发现这种做法会导致“**动作瓶颈（Action Bottleneck）**”现象。实验证明，尽管动作 Token 仅占轨迹的极小比例（通常不足 10%），但它们与奖励方差（即训练信号的丰富程度）高度相关。均匀分配梯度会使推理 Token 稀释掉关键动作 Token 的学习信号，导致训练效率低下且不稳定。

#### 2. 方法论：ActFocus
作者提出了一种名为 **ActFocus** 的 Token 重加权机制，旨在将梯度质量重新导向关键的动作 Token。

*   **核心思想**：利用推理/动作的结构边界进行粗粒度重加权，并利用“能量”指标进行细粒度重加权。
*   **关键技术细节**：
    1.  **推理降权**：对推理 Token 赋予较小的权重系数 $\alpha$（如 0.1），减少其对梯度更新的干扰。
    2.  **动作增强与能量重分配**：对动作 Token 赋予基础权重，并根据其**冻结参考模型能量（Frozen-Reference Token Energy）**进行动态调整。
    3.  **能量定义**：能量 $E_t$ 定义为参考模型在当前位置预测分布的负对数配分函数。高能量代表模型对该 Token 的预测不确定性较高，通常包含更多学习信息。
*   **权重公式**：
    *   若 $t \in \text{推理 Token}$，$w_t = \alpha$。
    *   若 $t \in \text{动作 Token}$，$w_t = 1 + \beta \cdot \text{sigmoid}(\text{归一化能量})$。
*   **算法流程**：在计算 PPO 或 GRPO 的代理损失函数时，将原本均匀的均值计算替换为基于 $w_t$ 的加权和，从而在不改变优势函数（Advantage）计算的前提下改变梯度流向。

*   **实验规模**：涵盖了 4 种不同性质的环境、3 种模型规模、2 种主流 RL 算法（PPO/GRPO）。
*   **消融实验**：
    *   针对超参数 $\alpha$（推理保留程度）和 $\beta$（能量调节强度）进行了详细扫参。

*   **充分性评价**：实验设计较为全面，跨越了符号推理到真实网页交互，验证了方法在不同能力水平模型上的普适性，结果具有较强的说服力和客观性。

#### 6. 主要结论与发现
*   **性能飞跃**：ActFocus 在所有配置下均优于均匀分配方法。在 Sudoku 0.5B 任务中，PPO 的成功率从 16.2% 提升至 81.4%（+65.2%）。
*   **稳定性提升**：在 GRPO 训练中，ActFocus 显著缓解了“先升后降”的性能崩塌现象，使训练过程更加平滑。
*   **效率优化**：ActFocus 倾向于生成更短、更高效的推理轨迹，证明了性能提升并非通过单纯增加推理 Token 数量（Verbalization）实现的。
*   **信号集中性**：验证了动作 Token 的能量与奖励方差之间存在显著正相关（$\rho = +0.537$），而推理 Token 的相关性接近于零。

#### 7. 优点
*   **简单高效**：实现极其简单（仅需修改损失函数的权重），且不引入额外的模型参数或推理开销。
*   **理论支撑**：从能量模型视角解释了信用分配的不均，并提供了量化的诊断工具。
*   **通用性强**：兼容 PPO 和 GRPO，适用于多种智能体任务。

#### 8. 不足与局限
*   **超参数敏感性**：$\alpha$ 和 $\beta$ 的最优值在不同任务间存在差异（如 WebShop 需要保留更多推理权重），可能需要针对新环境进行少量调优。
*   **结构依赖**：该方法依赖于明确的推理/动作边界（如 `<think>` 标签），对于没有显式思维链（CoT）的轨迹可能难以直接应用。
*   **实验覆盖**：虽然涵盖了 WebShop，但尚未在更复杂、超长时程的真实世界智能体任务（如操作系统操控）中进行验证。
