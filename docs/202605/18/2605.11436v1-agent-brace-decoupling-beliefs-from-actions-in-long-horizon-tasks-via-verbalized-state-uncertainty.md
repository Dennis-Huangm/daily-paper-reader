## 摘要
大语言模型（LLMs）越来越多地被部署在部分可观测环境下的长程任务中，它们必须在多步操作中推断并追踪复杂的环境状态。这带来了两个挑战：部分可观测性要求维持对未观测世界属性的不确定性，而漫长的交互历史导致上下文无限制增长，稀释了与任务相关的信息。针对这两个挑战的一个原则性解决方案是信念状态（belief state）：即给定过去观测和动作后环境状态的后验分布，无论回合长度如何，它都能紧凑地编码历史信息以供决策。然而，在 LLM 智能体中，文本的开放性使得如何表示这种分布变得不明确。因此，我们引入了 Agent-BRACE：通过抽象和置信度估计实现的智能体信念状态表示，这是一种将 LLM 智能体解耦为信念状态模型和策略模型的方法，两者通过强化学习进行联合优化。信念状态模型生成信念分布的结构化近似：一组关于环境的原子级自然语言陈述，每条陈述都标注了从“确定”到“未知”的序数言语化确定性标签。策略模型基于这种紧凑、结构化的近似信念而非完整历史进行条件化，学习在显式不确定性下选择动作。在长程、部分可观测的具身语言环境中，Agent-BRACE 实现了 +14.5% (Qwen2.5-3B-Instruct) 和 +5.3% (Qwen3-4B-Instruct) 的平均绝对提升，优于强强化学习基线，同时保持了与回合长度无关的近乎恒定的上下文窗口。进一步的分析表明，随着证据的积累，学习到的信念在回合过程中变得越来越校准。

## Abstract
Large language models (LLMs) are increasingly deployed on long-horizon tasks in partially observable environments, where they must act while inferring and tracking a complex environment state over many steps. This leads to two challenges: partial observability requires maintaining uncertainty over unobserved world attributes, and long interaction history causes context to grow without bound, diluting task-relevant information. A principled solution to both challenges is a belief state: a posterior distribution over environment states given past observations and actions, which compactly encodes history for decision making regardless of episode length. In LLM agents, however, the open-ended nature of text makes it unclear how to represent such a distribution. Therefore, we introduce Agent-BRACE: Agent Belief state Representation via Abstraction and Confidence Estimation, a method that decouples an LLM agent into a belief state model and a policy model, jointly optimized via reinforcement learning. The belief state model produces a structured approximation of the belief distribution: a set of atomic natural language claims about the environment, each annotated with an ordinal verbalized certainty label ranging from certain to unknown. The policy model conditions on this compact, structured approximate belief rather than the full history, learning to select actions under explicit uncertainty. Across long-horizon, partially observable embodied language environments, Agent-BRACE achieves an average absolute improvement of +14.5% (Qwen2.5-3B-Instruct) and +5.3% (Qwen3-4B-Instruct), outperforming strong RL baselines while maintaining a near-constant context window independent of episode length. Further analysis shows that the learned belief becomes increasingly calibrated over the course of an episode as evidence accumulates.

    1.  **上下文膨胀**：交互历史随步数线性增长，导致计算成本增加并稀释关键任务信号。
    2.  **不确定性缺失**：现有的历史压缩方法（如摘要）通常会将信念分布坍缩为单一的估计值，丢失了在部分可观测环境下至关重要的“不确定性”信息。
*   **研究动机**：借鉴传统控制理论中的“信念状态（Belief State）”概念，将其引入 LLM 智能体，通过自然语言和显式置信度标签来表示对环境状态的后验分布，从而实现历史信息的紧凑编码和不确定性的保留。

### 2. 方法论
*   **核心思想**：将智能体解耦为**信念状态模型 ($f_\phi$)**和**策略模型 ($\pi_\theta$)**，并进行联合强化学习（RL）优化。
*   **关键技术细节**：
    *   **信念表示**：信念状态不再是自由文本摘要，而是一组原子化的自然语言断言。每条断言都附带一个**言语化概率词汇（WEP）**标签（如：*confirmed, probable, possible, unknown* 等 7 个等级）。
    *   **解耦架构**：
        *   **信念模型**：输入当前目标、前一刻信念和新观测，输出更新后的带置信度标签的信念状态。
        *   **策略模型**：仅根据当前目标、最新的信念状态和当前观测选择动作，不再依赖冗长的原始历史。
    *   **联合训练流程**：
        1.  **SFT 阶段**：利用教师模型（如 GPT-5.4-mini）生成的轨迹对信念模型进行监督微调，使其掌握结构化格式。
        2.  **PPO 阶段**：使用近端策略优化算法联合训练两个模型。
*   **奖励设计**：
    *   **策略奖励**：环境给出的二元成功奖励（$R_{env}$）。
    *   **信念奖励 ($R_{belief}$)**：由五个部分组成：状态追踪（逻辑一致性）、状态正确性（事实对齐）、多样性（鼓励使用不同置信度标签）、格式规范性以及折扣后的任务成功奖励。

*   **数据集/场景**：
    *   **TextWorld**：包括三个子任务：Quest（任务搜索）、Treasure（迷宫寻宝）、Cooking（烹饪）。

### 5. 实验数量与充分性
*   **实验规模**：在三个 TextWorld 环境和 ALFWorld 上进行了广泛测试，每个任务包含 1000 个训练游戏和 200 个测试游戏。
*   **消融实验**：非常充分。涵盖了 WEP 标签粒度、信念奖励组件、联合训练必要性、以及在无任务特定监督（无 SFT）情况下的表现。
*   **客观性**：通过三次独立运行取平均值和标准差，并对比了上下文长度与成功率的曲线，证明了其在长程任务中的稳定性。

### 6. 主要结论与发现
*   **性能卓越**：Agent-BRACE 在 Qwen2.5-3B 上比最强 RL 基线平均提升了 **14.5%** 的绝对准确率。
*   **上下文效率**：在 100 步的长程任务中，Agent-BRACE 保持了**近乎恒定**的上下文窗口，而传统方法随步数线性增长并最终崩溃。

### 7. 优点
*   **可解释性强**：通过自然语言断言和显式置信度标签，人类可以直观地看到智能体“相信什么”以及“有多确定”。
*   **架构优雅**：成功将控制理论中的信念状态概念与 LLM 的文本处理能力结合，解决了长程任务的上下文瓶颈。
*   **鲁棒性**：实验证明即使在缺乏领域特定监督的情况下，通过联合 RL 也能学习到有效的状态追踪能力。

*   **应用范围**：主要在文本基和简单的具身模拟环境中验证，在更复杂的现实世界多模态任务中的表现尚待观察。
