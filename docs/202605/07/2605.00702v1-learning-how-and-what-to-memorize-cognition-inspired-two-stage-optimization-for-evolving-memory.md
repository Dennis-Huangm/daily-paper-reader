## 摘要
大语言模型（LLM）智能体需要长期用户记忆来实现一致的个性化，但有限的上下文窗口阻碍了在长期交互中追踪演化的偏好。现有的记忆系统主要依赖于静态的手工更新规则；虽然基于强化学习（RL）的智能体可以学习记忆更新，但稀疏的结果奖励提供了微弱的监督，导致长程优化不稳定。借鉴记忆图式理论以及前额叶区域与海马体区域之间的功能划分，我们提出了 MemCoE，这是一个受认知启发的两阶段优化框架，用于学习记忆应如何组织以及更新哪些信息。在第一阶段，我们提出了记忆指南归纳（Memory Guideline Induction），通过将对比反馈解释为文本梯度来优化全局指南；在第二阶段，指南对齐的记忆策略优化（Guideline-Aligned Memory Policy Optimization）利用归纳出的指南来定义结构化的过程奖励，并进行多轮强化学习以学习遵循指南的记忆演化策略。我们在三个个性化记忆基准上进行了评估，涵盖了显式/隐式偏好以及不同的规模和噪声，并观察到相比强基线模型在鲁棒性、可迁移性和效率方面均有持续提升。

## Abstract
Large language model (LLM) agents require long-term user memory for consistent personalization, but limited context windows hinder tracking evolving preferences over long interactions. Existing memory systems mainly rely on static, hand-crafted update rules; although reinforcement learning (RL)-based agents learn memory updates, sparse outcome rewards provide weak supervision, resulting in unstable long-horizon optimization. Drawing on memory schema theory and the functional division between prefrontal regions and hippocampus regions, we introduce MemCoE, a cognition-inspired two-stage optimization framework that learns how memory should be organized and what information to update. In the first stage, we propose Memory Guideline Induction to optimize a global guideline via contrastive feedback interpreted as textual gradients; in the second stage, Guideline-Aligned Memory Policy Optimization uses the induced guideline to define structured process rewards and performs multi-turn RL to learn a guideline-following memory evolution policy. We evaluate on three personalization memory benchmarks, covering explicit/implicit preference and different sizes and noise, and observe consistent improvements over strong baselines with favorable robustness, transferability, and efficiency.

#### 1. 核心问题与整体含义（研究动机和背景）
大语言模型（LLM）智能体在处理长期个性化对话时面临核心挑战：**有限的上下文窗口**无法容纳海量的历史交互，而用户偏好又是**动态演化**的。
*   **现有方案缺陷**：目前的记忆系统要么依赖于**静态的手工规则**（难以适应复杂多变的行为），要么使用**强化学习（RL）**进行端到端更新。然而，RL 方案通常仅依赖最终结果的稀疏奖励（Sparse Rewards），导致在长程优化中训练不稳定、动作空间过大且难以收敛。
*   **研究动机**：受认知心理学中“记忆图式理论（Memory Schema Theory）”启发，人类大脑通过前额叶（负责组织模式/图式）和海马体（负责填充具体细节）的分工协作来管理记忆。论文旨在构建一个类似的双阶段框架，解耦“如何组织记忆”与“记忆什么内容”。

#### 2. 方法论：MemCoE 框架
MemCoE（Cognition-Inspired Two-Stage Optimization）分为两个关键阶段：

*   **第一阶段：记忆准则诱导（Memory Guideline Induction, MGI）**
    *   **核心思想**：学习“如何记忆”。将记忆更新指令（Prompt）视为可优化的全局文本参数。
    *   **技术细节**：
        1.  **对比反馈作为文本梯度**：通过对比正确轨迹（Positive）与错误轨迹（Negative），利用 LLM 生成自然语言形式的“对比反思”，将其作为“文本梯度”。
        2.  **批次梯度聚合**：在 mini-batch 层面汇总多个实例的反馈，通过聚合算子消除噪声，诱导出领域通用的、稳健的记忆组织准则（Guideline）。
*   **第二阶段：准则对齐的记忆策略优化（Guideline-Aligned Memory Policy Optimization, GMPO）**
    *   **核心思想**：学习“记忆什么”。在固定第一阶段准则的基础上，优化具体的记忆更新策略。
    *   **技术细节**：
        1.  **准则对齐奖励（Guideline-aligned Rewards）**：利用第一阶段生成的准则定义“过程奖励”，评估记忆更新是否符合预设的结构和逻辑，解决奖励稀疏问题。
        2.  **策略优化**：采用 **GRPO（Group Relative Policy Optimization）** 算法，在多轮对话轨迹上进行强化学习，使模型学会根据当前上下文选择性地保留、更新或遗忘信息。

#### 6. 主要结论与发现
*   **性能领先**：MemCoE 在所有基准测试中均显著优于现有最强基线（如 MemAgent），在 PersonaMem 128K 任务上提升尤为明显。
*   **记忆演化规律**：随着对话增长，记忆库的大小呈**亚线性增长**，表明模型学会了合并稳定信息并剔除冗余内容。
*   **准则价值**：高质量的记忆准则（MGI 产出）比手工编写或简单 LLM 改写的 Prompt 能带来约 10% 的性能提升。

#### 7. 优点
*   **认知启发**：将心理学理论转化为工程实现，解耦组织架构与具体内容，逻辑清晰。

*   **强迁移性**：诱导出的“记忆准则”是自然语言形式，具有跨模型的通用性，降低了部署成本。

#### 8. 不足与局限
*   **评分器依赖**：第二阶段的过程奖励依赖于 LLM 作为评分者（Scorer），评分者的偏见或不稳定性可能影响策略优化。

*   **多目标平衡**：目前主要针对准确率优化，尚未显式平衡记忆的“稳定性”与“可塑性”（Stability vs. Plasticity）等多个潜在冲突目标。
