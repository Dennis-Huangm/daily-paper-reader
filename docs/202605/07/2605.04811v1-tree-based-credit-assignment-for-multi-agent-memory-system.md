## 摘要
记忆系统被广泛用于增强大语言模型（LLMs）处理长程任务的能力，通常被组织为包含记忆构建、摘要和检索智能体的多智能体流水线。为了增强该系统，现有的基于强化学习（RL）的方法要么对所有智能体统一应用最终的下游任务奖励（如问答准确率），这种方式较为粗糙且模糊；要么为不同子任务上的智能体设计特定任务的奖励，这需要昂贵的标注（如关键证据）且难以可靠地定义。为了解决这些局限性，我们提出了面向多智能体记忆系统的基于树的信用分配（TreeMem），它在无需特定任务标注的情况下，从最终奖励中推导出特定于智能体的信用。具体而言，TreeMem 将多智能体流水线（构建者-摘要者-检索者）扩展为树状结构，其中每个智能体的输出都被扩展为多个后续分支。每个智能体的贡献通过对其后续分支进行蒙特卡洛平均来估计，从而捕捉中间智能体动作如何影响最终奖励。这将粗糙的最终奖励转化为特定于智能体的优化信号。这些信号随后被用于同时更新所有智能体的策略，帮助异构智能体有效地实现专业化。在长程基准测试上的实验表明，TreeMem 相比强基准模型提升了记忆系统的性能，验证了树状结构信用分配在多智能体记忆系统中的有效性。

## Abstract
Memory systems are widely adopted to enhance LLMs for long-horizon tasks, and are commonly organized as multi-agent pipelines with memory building, summarizing, and retrieval agents. To empower this system, existing RL-based methods either apply final downstream task rewards (e.g., QA accuracy) for all agents uniformly, which are coarse and ambiguous, or design task-specific rewards for agents on different subtasks, which require costly annotations (e.g., key evidence) and are difficult to define reliably. To address these limitations, we propose Tree-based Credit Assignment for Multi-Agent Memory Systems (TreeMem), which derives agent-specific credit from the final reward without task-specific annotations. Specifically, TreeMem extends the multi-agent pipeline (builder--summarizer--retrieval) into a tree structure, where each agent's outputs are expanded into multiple subsequent branches. The contribution of each agent is estimated via Monte Carlo averaging over its subsequent branches, capturing how intermediate agent actions may influence the final reward. This converts the coarse final reward into agent-specific optimization signals. These signals are then used to update all agent policies simultaneously, helping heterogeneous agents specialize effectively. Experiments on long-horizon benchmarks show that TreeMem improves memory system performance over strong baselines, validating the effectiveness of tree-structured credit assignment for the multi-agent memory system.

*   **核心痛点**：
    *   **奖励信号模糊**：现有的强化学习（RL）方法通常只使用最终的下游任务奖励（如QA准确率），这对于中间环节的智能体来说过于粗糙，难以明确哪个智能体表现好或坏。
    *   **标注成本高且不可靠**：若为每个智能体设计特定任务奖励（如证据覆盖率），则需要昂贵的人工标注，且容易引发“奖励作弊”（Reward Hacking），即智能体优化了中间指标却损害了最终表现。
*   **研究动机**：探索一种无需额外人工标注，就能从最终奖励中自动推导出每个智能体特定信用（Credit）的训练框架。

### 2. 方法论：TreeMem 核心架构
*   **核心思想**：将线性的多智能体流水线扩展为**树状结构**，通过蒙特卡洛采样（Monte Carlo Sampling）来估算中间动作对最终结果的期望贡献。
*   **关键技术细节**：
    1.  **树状展开（Tree-structured Rollout）**：
        *   **Builder** 采样 $G$ 个候选动作。
        *   对于每个 Builder 动作，**Summarizer** 采样 $J$ 个分支。
        *   对于每个 Summarizer 分支，**Retrieval** 采样 $K$ 个最终回答。
    2.  **信用分配（Credit Assignment）**：
        *   **检索智能体**：直接获得最终奖励 $R$。
        *   **摘要智能体**：其信用是其后续 $K$ 个回答分支奖励的平均值。
        *   **构建智能体**：其信用是其后续 $J \times K$ 个分支奖励的平均值，并加入长度惩罚项以减少冗余。
    3.  **策略优化**：
        *   基于 **GRPO（Group Relative Policy Optimization）** 算法。
        *   不同于标准 GRPO 对所有部分应用统一奖励，TreeMem 为每个智能体计算其在组内的相对优势（Advantage），并利用各自的特定信用信号同步更新三个智能体的策略。

    *   **PersonaMem**：主测试集，包含 32K、128K、1M 三种历史长度，涵盖 6000 个个性化问答查询。

*   **实验规模**：

    *   **消融实验**：分别移除 Builder 或 Summarizer 的树状信用信号，验证了每个组件的必要性。
    *   **超参数分析**：对分支数量 $J, K$ 和组大小 $G$ 进行了敏感性分析。
*   **充分性评价**：实验设计非常充分，不仅有最终准确率对比，还包含了收敛速度分析、Token 效率分析以及使用 GPT-4o 作为评委的智能体专业化定性评估，结果具有较强的说服力和客观性。

### 6. 主要结论与发现
*   **性能领先**：TreeMem 在所有历史长度下均显著优于现有最强基线（如 CoMAM），在 128K 长度下提升尤为明显。
*   **专业化效应**：通过树状信用分配，Builder 学会了提取更精炼的证据，Summarizer 学会了更高质量的抽象，从而实现了异构智能体的有效专业化。
*   **效率优势**：虽然训练时增加了采样分支，但由于收敛更快且生成的记忆更简洁，整体 Token 效率和训练步数表现优异；推理时无需树状展开，无额外开销。

### 7. 优点与亮点
*   **创新性信用分配**：巧妙地将强化学习中的信用分配问题与多智能体记忆流水线结合，解决了中间环节“奖励稀疏”的问题。
*   **无需人工标注**：完全依赖最终任务结果（如 QA 对错）进行反向推导，极大地降低了系统构建成本。
*   **端到端协同**：实现了构建、摘要、检索三个环节的联合优化，而非孤立训练。

### 8. 不足与局限
*   **训练计算开销**：树状采样（$G \times J \times K$）虽然在文中通过采样策略进行了优化，但在训练初期仍比单路径 RL 消耗更多的计算资源（Rollout 成本）。
*   **复杂度**：系统涉及多个智能体的协同采样与更新，实现复杂度较高，对超参数（如分支数）的设置虽有鲁棒性但仍需合理配置。
*   **任务依赖**：目前的评估主要集中在问答类任务，对于更复杂的开放式生成或多步骤推理任务的适用性尚待进一步验证。
