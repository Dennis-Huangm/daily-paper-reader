## 摘要
基于大语言模型（LLM）的智能体越来越多地被部署用于处理流式任务，但它们通常仍是单次问题解决者，无法从过去的交互中学习。从经验中提炼的可重用技能为自我进化提供了天然基础，而高质量的技能管理（skill curation）则是其中的关键瓶颈。现有方法要么依赖人工技能管理，要么规定启发式技能操作，或者针对短时域技能操作进行训练。然而，它们仍然难以从间接且延迟的反馈中学习复杂的长期管理策略。为了应对这一挑战，我们提出了 SkillOS，这是一种经验驱动的强化学习（RL）训练方案，用于学习自我进化智能体中的技能管理。SkillOS 将一个负责检索和应用技能的冻结智能体执行器与一个可训练的技能管理器配对，后者根据积累的经验更新外部技能库（SkillRepo）。为了提供管理学习信号，我们设计了复合奖励，并基于技能相关的任务依赖关系在分组任务流上进行训练，其中早期的轨迹用于更新 SkillRepo，而随后的相关任务则用于评估这些更新。在多轮智能体任务和单轮推理任务中，SkillOS 在有效性和效率方面均持续优于无记忆和强记忆基线，且学习到的技能管理器能够跨不同的执行器骨干网络和任务领域进行泛化。进一步的分析表明，学习到的管理器能产生更具针对性的技能使用，而 SkillRepo 中的技能随着时间的推移演变成结构更丰富的 Markdown 文件，并编码了更高层级的元技能。

## Abstract
LLM-based agents are increasingly deployed to handle streaming tasks, yet they often remain one-off problem solvers that fail to learn from past interactions. Reusable skills distilled from experience provide a natural substrate for self-evolution, where high-quality skill curation serves as the key bottleneck. Existing approaches either rely on manual skill curation, prescribe heuristic skill operations, or train for short-horizon skill operations. However, they still struggle to learn complex long-term curation policies from indirect and delayed feedback. To tackle this challenge, we propose SkillOS, an experience-driven RL training recipe for learning skill curation in self-evolving agents. SkillOS pairs a frozen agent executor that retrieves and applies skills with a trainable skill curator that updates an external SkillRepo from accumulated experience. To provide learning signals for curation, we design composite rewards and train on grouped task streams based on skill-relevant task dependencies, where earlier trajectories update the SkillRepo, and later related tasks evaluate these updates. Across multi-turn agentic tasks and single-turn reasoning tasks, SkillOS consistently outperforms memory-free and strong memory-based baselines in both effectiveness and efficiency, with the learned skill curator generalizing across different executor backbones and task domains. Further analyses show that the learned curator produces more targeted skill use, while the skills in SkillRepo evolve into more richly structured Markdown files that encode higher-level meta-skills over time.

当前的 LLM 智能体在处理流式任务时，往往表现为“一次性”的问题解决者，无法从过去的交互中积累经验以提升未来表现。虽然“技能（Skills）”被认为是实现智能体自我进化的核心，但如何从原始轨迹中**提炼、更新和删除**高质量技能（即技能管理，Skill Curation）仍是主要瓶颈。现有方法多依赖人工编写、固定规则（启发式）或仅针对短期任务优化，难以应对长期、复杂且具有延迟反馈的真实场景。

#### 2. 论文提出的方法论
论文提出了 **SkillOS**，一个经验驱动的强化学习训练框架，旨在训练一个专门的“技能管理员”。
*   **核心思想**：采用模块化设计，将系统分为**冻结的执行器（Agent Executor）**和**可训练的管理员（Skill Curator）**。管理员通过函数调用（插入、更新、删除）来维护一个外部的 Markdown 格式技能库（SkillRepo）。
*   **关键技术细节**：
    *   **分组任务流训练**：将具有技能依赖关系的相关任务编组。管理员在处理组内早期任务时更新技能库，其效果由后续相关任务的成功率来评估，从而提供长期的学习信号。
    *   **复合奖励函数**：为了解决反馈延迟问题，设计了四部分奖励：
        1.  **任务结果奖励**：后续相关任务的成功率。
        2.  **函数调用奖励**：操作格式是否正确。
        3.  **内容质量奖励**：由外部模型（如 Qwen3-32B）评估技能的抽象性、可重用性和准确性。
        4.  **压缩奖励**：鼓励提炼简洁技能，防止直接复制原始轨迹。
*   **算法流程**：使用 **GRPO（Grouped Reward Policy Optimization）** 算法。在每个训练步骤中，采样一个任务组，管理员根据执行轨迹生成管理决策，并根据复合奖励进行策略优化。

#### 3. 实验设计
*   **数据集 / 场景**：

#### 6. 主要结论与发现
*   **性能卓越**：SkillOS 在所有基准测试中均显著优于无记忆和现有的记忆管理方法。在 ALFWorld 上，相对最强基线提升了约 9.8% 的成功率。
*   **效率提升**：通过提炼有效的操作规程，智能体完成任务所需的交互步数减少了约 6.0%。
*   **小模型逆袭**：经过 RL 训练的 8B 管理员在特定任务上的表现甚至超过了未针对该任务优化的顶级模型（如 Gemini-2.5-Pro）。
*   **元技能涌现**：随着训练进行，技能库从简单的任务特定指令演化为包含“失败恢复”、“系统搜索”等高层级元策略的结构化文档。

#### 7. 优点
*   **模块化解耦**：管理员与执行器分离，使得技能管理能力可以跨模型迁移，无需重新训练昂贵的执行器。
*   **长期价值导向**：通过任务分组设计，成功将“技能管理”这一抽象行为与“下游任务表现”这一硬指标挂钩。
*   **格式友好**：使用 Markdown 格式，既便于 LLM 处理，也具备极高的人类可读性和可编辑性。

#### 8. 不足与局限
*   **检索机制简单**：目前仅使用 BM25 关键词检索，对于语义复杂或大规模技能库的检索效率可能受限。

*   **执行器冻结**：虽然模块化是优点，但也意味着管理员无法根据执行器的特定“偏好”进行联合优化，可能存在协同上限。
*   **算力门槛**：强化学习训练过程（尤其是多轮交互任务）对算力需求较高，且依赖高质量的任务分组标注。
