## 摘要
AI 智能体研究涵盖了广泛的领域：从从零开始学习的强化学习（RL）智能体到利用预训练知识的基础模型智能体，然而目前尚无统一的基准测试能够对这些方法进行公平比较。我们提出了 Agentick，这是一个专为序列决策智能体设计的基准测试，旨在在共同基础上评估 RL、LLM、VLM、混合型以及人类智能体，并推动对序列决策基本挑战的研究。Agentick 提供了跨越 6 个能力类别、4 个难度级别和 5 种观测模态的 37 个程序化生成任务，所有任务均通过单一的 Gymnasium 兼容接口公开。该基准测试附带了编码 API、所有任务的 oracle 参考策略、预构建的 SFT 数据集、可组合的智能体框架以及实时排行榜。一项涵盖 27 种配置和超过 90,000 个回合的评估显示，没有任何一种方法占据绝对主导地位：GPT-5 mini 以 0.309 的 oracle 归一化得分在总体上领先，而 PPO 在规划和多智能体任务中占据主导；推理框架使 LLM 的性能提升了 3-10 倍；且 ASCII 观测结果始终优于自然语言。这些发现强调了所有智能体范式仍存在巨大的改进空间。Agentick 的能力分解、多模态设计为推动通用自主智能体的发展提供了所需的实证基础设施，既可作为评估框架，也可作为在真实序列环境中对基础模型进行 RL 后训练的训练场。

## Abstract
AI agent research spans a wide spectrum: from RL agents that learn from scratch to foundation model agents that leverage pre-trained knowledge, yet no unified benchmark enables fair comparison across these approaches. We present Agentick, a benchmark for sequential decision-making agents designed to evaluate RL, LLM, VLM, hybrid, and human agents on common ground and to power research on the fundamental challenges of sequential decision-making. Agentick provides 37 procedurally generated tasks across six capability categories, four difficulty levels, and five observation modalities, all exposed through a single Gymnasium-compatible interface. The benchmark ships with a Coding API, oracle reference policies for all tasks, pre-built SFT datasets, a composable agent harness, and a live leaderboard. An evaluation spanning 27 configurations and over 90,000 episodes reveals that no single approach dominates: GPT-5 mini leads overall at 0.309 oracle-normalized score while PPO dominates planning and multi-agent tasks; the reasoning harness multiplies LLM performance by 3-10x; and ASCII observations consistently outperform natural language. These findings highlight the substantial room for improvement that remains across all agent paradigms. Agentick's capability-decomposed, multi-modal design provides the empirical infrastructure needed to drive progress toward general autonomous agents, both as an evaluation framework and as a training ground for RL post-training of foundation models in truly sequential environments.

### 1. 核心问题与整体含义（研究动机和背景）
论文的核心问题在于**缺乏一个能够公平比较不同范式智能体（Agent）的统一基准测试**。当前智能体研究分为两大阵营：
*   **强化学习（RL）智能体**：从零开始通过交互学习，擅长精细控制但采样效率低。
*   **基础模型（FM/LLM/VLM）智能体**：利用预训练知识进行零样本决策，语义理解强但缺乏长程规划和精确控制能力。
现有的基准测试通常只针对其中一类（如 Atari 针对 RL，BALROG 针对 LLM），导致无法在同一维度下评估“交互学习”与“预训练知识”的结合效果。Agentick 旨在提供一个通用的、多模态的、能力分解的评估平台。

### 2. 方法论：核心思想与关键技术
Agentick 的核心思想是构建一个**范式通用（Paradigm Universal）**且**训练优先（Training-first）**的实验床：
*   **任务设计**：包含 37 个程序化生成的网格世界任务，分为 6 大能力维度：导航（Navigation）、规划（Planning）、推理（Reasoning）、记忆（Memory）、泛化（Generalization）和多智能体协调（Multi-Agent）。
*   **五种观测模态**：为了消除架构偏见，同一环境状态同时提供：ASCII 字符阵列、自然语言描述、结构化字典、512×512 等轴测像素渲染、原始 Numpy 数组。
*   **评分机制 (ONS)**：采用 Oracle 归一化得分（Oracle-Normalized Score），公式为：
    $$ONS = \frac{\text{agent\_return} - \text{random\_baseline}}{\text{oracle\_return} - \text{random\_baseline}}$$
    该指标将表现校准在随机水平（0.0）和专家水平（1.0）之间。
*   **关键组件**：
    *   **Coding API**：提供空间查询、路径规划等高级原语，用于构建 Oracle 策略或供 LLM 生成代码。
    *   **智能体框架（Harness）**：解耦了模型后端与推理策略（如 Markovian 纯反应式 vs. Reasoner 链式思考推理）。

### 3. 实验设计
*   **数据集/场景**：37 个任务，每个任务设有 4 个难度等级（简单到专家），通过程序化生成确保每个种子（Seed）下的布局唯一。
*   **对比方法**：
    *   **前沿 LLM**：GPT-5 mini, Gemini 3.1 Flash Lite, Claude Haiku 4.5。
    *   **RL 基准**：使用 PPO 算法从像素输入进行训练（分为 2M 步和 500k 步版本）。
    *   **开源 LLM**：Qwen3 和 Qwen3.5 系列（0.8B 到 4B 参数）。
*   **评估规模**：涵盖 27 种配置，总计运行超过 90,000 个回合（Episode）。

### 4. 资源与算力
*   **RL 训练**：使用单张 **NVIDIA A100 (80GB)** GPU。每个任务训练 2M 步约需 4 小时，37 个任务总计耗时约 **150 GPU 小时**。
*   **LLM 推理**：
    *   前沿模型通过商业 API 调用（总成本约 290 美元）。
    *   开源 Qwen 模型在 **2 张 A100** 上通过 vLLM 部署，总计耗时约 **200 GPU 小时**。
*   **数据生成**：500K 回合的专家数据集在 32 核机器上约 8 小时完成。

### 5. 实验数量与充分性
*   **实验规模**：每个（任务, 难度）组合使用 25 个确定性种子进行评估（37x4x25=3700 回合/智能体），实验规模庞大且覆盖面广。
*   **客观性与公平性**：通过五种观测模态确保了 RL（像素/数组）和 LLM（文本/ASCII）都能在各自擅长的输入下竞争。引入 95% 自举置信区间（Bootstrap CI）进行统计显著性分析，实验设计严谨、客观。

### 6. 主要结论与发现
*   **无单一主导范式**：GPT-5 mini 综合得分最高（0.309），但在规划和多智能体任务中，从零训练的 PPO 显著优于所有 LLM。
*   **推理框架至关重要**：引入简单的“Reasoner”框架（要求模型在行动前进行简短 CoT）使 LLM 性能提升了 **3-10 倍**。
*   **观测模态影响**：对于 LLM 而言，**ASCII 阵列始终优于自然语言描述**，表明紧凑的 Token 表示更有利于空间推理。
*   **巨大的提升空间**：即使是最强的智能体，其 ONS 得分也仅为 0.3 左右，距离 Oracle（1.0）仍有巨大鸿沟，尤其是在逻辑推理任务上。

### 7. 优点
*   **多模态同步**：解决了不同类型智能体无法在同一任务上公平竞技的痛点。
*   **能力分解**：通过雷达图清晰展示了不同模型的优劣势（如 LLM 擅长泛化，RL 擅长规划）。
*   **训练友好**：不仅是评估工具，还提供了海量 SFT 数据集和向量化环境，可作为基础模型进行 RL 后训练（RLVR）的理想场所。
*   **程序化生成**：有效防止了智能体通过记忆特定地图布局来“刷分”。

### 8. 不足与局限
*   **环境抽象化**：任务局限于 2D 网格世界，缺乏连续控制和实时动态，可能无法完全代表现实世界的复杂性。
*   **RL 预算限制**：PPO 仅训练了 2M 步，若给予更多算力或更先进的算法，RL 的表现可能会有更大变化。
*   **多智能体局限**：目前的对手是脚本策略，而非学习型对手，限制了对复杂博弈演化行为的研究。
*   **模型覆盖**：由于预算原因，未包含最顶级的旗舰模型（如 GPT-5 Pro 或 Claude Opus），且 VLM 在像素模态下的表现尚未充分测试。
