## 摘要
我们介绍了递归智能体优化（Recursive Agent Optimization, RAO），这是一种用于训练递归智能体的强化学习方法。递归智能体能够递归地生成自身的新实例并向其委派子任务。递归智能体实现了一种推理时扩展算法，使其能够自然地扩展到更长的上下文，并通过分治法泛化到更难的问题。RAO 提供了一种训练模型以充分利用此类递归推理的方法，教导智能体何时以及如何进行委派和通信。我们发现，以这种方式训练的递归智能体具有更好的训练效率，能够扩展到超出模型上下文窗口的任务，泛化到比训练任务困难得多的任务，并且与单智能体系统相比，可以缩短实际运行时间。

## Abstract
We introduce Recursive Agent Optimization (RAO), a reinforcement learning approach for training recursive agents: agents that can spawn and delegate sub-tasks to new instantiations of themselves recursively. Recursive agents implement an inference-time scaling algorithm that naturally allows agents to scale to longer contexts and generalize to more difficult problems via divide-and-conquer. RAO provides a method to train models to best take advantage of such recursive inference, teaching agents when and how to delegate and communicate. We find that recursive agents trained in this way enjoy better training efficiency, can scale to tasks that go beyond the model's context window, generalize to tasks much harder than the ones the agent was trained on, and can enjoy reduced wall-clock time compared to single-agent systems.

*   **核心问题**：现有的 LLM 智能体在处理超长上下文、长程规划和复杂任务（如软件工程、深度研究）时，往往受限于上下文窗口大小和推理能力的瓶颈。

### 2. 方法论：核心思想与关键技术
*   **核心思想**：将递归执行视为一种可学习的策略。训练一个单一的策略 $\pi_\theta$，它在递归生成的执行树的每个节点上被实例化。模型不仅要学会解决当前任务，还要学会通过 Python 代码调用 `launch_subagent` 函数来生成并委派子任务。
*   **关键技术细节**：
    *   **递归动作空间**：基于 Python REPL 环境，扩展了异步函数 `launch_subagent(goal, ...)`，允许父智能体并行或串行启动子智能体。
    *   **局部节点奖励（Local Reward）**：每个节点（智能体实例）的奖励由两部分组成：
        $$R(X, \tau_X) = \tilde{s}(X, \tau_X) + \lambda \cdot \frac{1}{|C(X)|} \sum_{c \in C(X)} \tilde{s}(c, \tau_c)$$
        其中 $\tilde{s}$ 是任务成功信号，$\lambda$ 是委派奖励系数。这种设计提供了密集的信用分配（Credit Assignment），奖励不仅取决于自身成功，还取决于其委派的子任务是否成功。
    *   **策略优化**：使用策略梯度方法。为了解决递归树中深层节点远多于根节点导致的梯度偏差，引入了**深度级逆频率加权（Depth-level inverse-frequency weighting）**，平衡不同深度轨迹对更新的贡献。
    *   **基准线（Baseline）**：采用留一法（Leave-one-out）计算优势函数，以减少方差。

### 6. 主要结论与发现
*   **突破上下文限制**：递归智能体能解决超出其训练上下文窗口的任务（例如用 8K 窗口的模型解决需要极长上下文的任务）。
*   **更强的泛化性**：在简单/中等任务上训练的模型，通过递归能显著更好地泛化到困难任务（成功率从单智能体的 20% 提升至 88%）。
*   **训练效率高**：由于递归结构提供了天然的“课程学习”信号，递归智能体比单智能体收敛更快。
*   **运行速度优势**：在可并行化的任务中，递归智能体通过并发执行，实际运行时间比单智能体快达 2.5 倍。

### 7. 优点
*   **端到端训练**：不同于以往只在推理时套用模板，RAO 真正训练了模型“如何委派”的能力。
*   **动态性**：支持动态生成的执行树，而非固定的层级结构。
*   **推理时扩展**：为 LLM 智能体提供了一种通过增加计算量（增加递归深度）来换取更高成功率的有效路径。

### 8. 不足与局限
*   **顺序依赖任务的延迟**：对于无法并行的任务（如 DeepDive），递归会显著增加 Token 消耗和运行时间（慢 18 倍），因为每一层递归都有额外的思考和通信开销。
*   **领域局限性**：目前的实验是在特定领域内分别训练的，尚未实现跨领域的通用递归策略。
*   **训练成本**：完整的递归树采样在强化学习循环中开销巨大，论文提到未来需要研究更高效的代理采样程序。
