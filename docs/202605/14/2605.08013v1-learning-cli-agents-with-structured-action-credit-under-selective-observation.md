## 摘要
命令行界面（CLI）智能体正成为一种实用的范式，用于在不断演化的文件系统、可执行命令行程序和在线执行反馈上进行人机交互。最近的研究利用强化学习（RL）从可验证的任务反馈中学习这些交互能力，但很少有方法利用 CLI 动作的天然结构化属性作为学习信号。除了这种未被充分利用的动作结构外，CLI 学习还面临着编程智能体的两个瓶颈：首先，智能体必须从部分观测中识别大型代码库中与任务相关的证据；其次，必须将稀疏的终端奖励分配给构成漫长多轮轨迹的动作。我们通过 shell 驱动的信息提取和文件编辑任务来研究这些瓶颈。针对选择性观测，我们引入了 $\sigma$-Reveal，这是一种推理时机制，可为同一 CLI 选择受 Token 预算限制的上下文。针对信用分配，我们提出了动作优势分配（Action Advantage Assignment，$\mathrm{A}^3$），这是一种原生的智能体强化学习方法，保留了标准智能体强化学习的算法复杂度。$\mathrm{A}^3$ 从回合级相对反馈、基于抽象语法树（AST）的动作子链残差以及树级轨迹边际中构建轮次级优势。为了进一步评估这一问题设置，我们构建了 ShellOps，这是一个涵盖代码仓库环境中 CLI 任务的可验证数据集套件。

## Abstract
Command line interface (CLI) agents are emerging as a practical paradigm for agent-computer interaction over evolving filesystems, executable command line programs, and online execution feedback. Recent work has used reinforcement learning (RL) to learn these interaction abilities from verifiable task feedback, yet few methods exploit the native structured attributes of CLI actions as learning signals. Beyond this underused action structure, CLI learning also couples two bottlenecks for coding agents. First, the agent must identify task-relevant evidence in a large codebase from partial observations. Second, sparse terminal rewards must be assigned to the actions that shape a long multi-turn trajectory. We study these bottlenecks through shell-driven information extraction and file editing tasks. For selective observation, we introduce $σ$-Reveal, an inference-time mechanism that selects token-budgeted context for the same CLI. For credit assignment, we propose Action Advantage Assignment ($\mathrm{A}^3$), a native agentic RL method that preserves the algorithmic complexity of standard agentic RL. $\mathrm{A}^3$ constructs turn-level advantages from episode-level relative feedback, abstract syntax tree (AST) based action sub-chain residuals, and tree-level trajectory margins. To further evaluate this problem setting, we construct ShellOps, a verifiable dataset suite covering CLI tasks in repository environments.

*   **研究动机**：命令行界面（CLI）智能体在处理真实世界的文件系统任务时面临两个相互耦合的瓶颈：
    1.  **选择性观测（Selective Observation）**：在庞大的代码库或工作空间中，智能体只能看到局部信息，必须从海量文件中识别出与任务相关的证据。
    2.  **信用分配（Credit Assignment）**：任务奖励通常是稀疏的终端奖励（如任务是否完成），很难将这一奖励准确分配给长轨迹中的具体某一步 Shell 动作。
*   **核心目标**：利用 CLI 动作的天然结构化属性（如 Shell 语法树）作为学习信号，提升智能体在部分观测环境下的决策能力和训练效率。

### 2. 方法论
论文提出了两个核心机制：

*   **$\sigma$-Reveal（选择性观测机制）**：
    *   这是一种推理时的上下文选择算法。它根据 Token 预算，通过计算文件节点的**相关性评分**（结合名称匹配、树深度先验和文件扩展名先验）来构建初始工作空间的视图。
    *   该机制确保智能体在执行第一步动作前，能够获得最可能相关的代码或文档片段，而不会超出上下文窗口。

*   **$\mathrm{A}^3$ (Action Advantage Assignment，动作优势分配)**：
    *   这是一种原生的智能体强化学习方法，通过融合三个维度的信号来构建每一轮动作的“优势”（Advantage）：
        1.  **回合骨干（Episode Backbone）**：基于轨迹级别的相对反馈（类似 GRPO），对比同一提示词下的不同采样结果。
        2.  **轮次级动作子链残差（Turn-Level Residual）**：利用**抽象语法树（AST）**对 Shell 动作进行签名和聚类。通过比较结构相似动作的收益残差，识别出哪些具体的命令结构导致了更好的结果。
        3.  **树级轨迹边际（Tree-Level Margin）**：在抽象的状态-动作树上计算折扣优势，衡量特定动作分支相对于平均分支的增益。

### 6. 主要结论与发现
*   **性能领先**：$\mathrm{A}^3$ 在 Qwen3-14B 模型上表现显著优于其他 RL 算法，尤其在涉及文件编辑和混合任务的 ShellOps 上，准确率提升巨大（例如在混合任务上从 11.3% 提升至 24.6%）。
*   **长程能力**：在 ShellOps-Pro 的长轨迹测试中，经过 $\mathrm{A}^3$ 训练的 14B 模型在长步数下的表现甚至能触及参数量大得多的 235B 模型。
*   **训练稳定性**：相比于 GiGPO 或 HGPO，$\mathrm{A}^3$ 的 KL 散度更稳定，策略熵下降更平缓，避免了训练后期的崩溃。
*   **低开销**：基于 AST 的相似度计算极快（平均每批次小于 26ms），相比于调用 LLM 作为裁判的算法，计算成本几乎可以忽略不计。

### 7. 优点与亮点
*   **结构化洞察**：巧妙地利用了 Shell 命令的 AST 结构来解决信用分配问题，这比纯文本匹配或依赖 LLM 裁判更具解释性且更高效。
*   **端到端验证**：构建了完全可验证的 ShellOps 环境，所有任务均通过文件系统状态或标准输出进行客观评分，减少了模型评估的偏差。
*   **推理时增强**：$\sigma$-Reveal 提供了一种简单有效的处理长上下文工作空间的方法，无需重新训练模型即可提升信息提取效率。

### 8. 不足与局限
*   **语法依赖性**：目前的 AST 抽象主要针对 Bash 语法，若要迁移到 Windows PowerShell 或其他非 Shell 环境（如 GUI 交互），需要重新设计语法解析器。
*   **语义局限**：AST 相似度是动作意图的代理指标，但结构相似的命令如果参数（如文件路径）不同，效果可能完全相反，该方法在处理极细微的语义差别时可能存在盲区。
*   **观测瓶颈**：$\sigma$-Reveal 依赖于文件名等元数据，如果任务相关的证据隐藏在无意义文件名的深层内容中，该机制可能失效。
