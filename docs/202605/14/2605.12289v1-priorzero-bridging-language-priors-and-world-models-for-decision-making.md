## 摘要
利用大语言模型（LLMs）丰富的世界知识来增强强化学习（RL）智能体，是通往通用智能的一条充满前景的路径。然而，一种根本性的“先验-动力学不匹配”阻碍了现有方法：静态的 LLM 知识无法直接适应长时程任务中复杂的转移动力学。将 LLM 先验作为固定策略使用会限制探索的多样性，因为先验对特定环境的动力学是盲目的；而端到端微调则面临优化不稳定和信用分配问题。为了弥补这一差距，我们提出了 PriorZero，这是一个统一的框架，通过解耦的展开-训练设计，将源自 LLM 的概念先验集成到基于世界模型的规划中。在展开过程中，一种新颖的根节点先验注入机制仅在蒙特卡洛树搜索（MCTS）的根节点引入 LLM 先验，使搜索集中在语义上有前景的动作上，同时保留世界模型的深度前瞻能力。在训练过程中，PriorZero 将世界模型学习与 LLM 适配解耦：世界模型在交互数据上不断优化，以共同提高其动力学、策略和价值预测；随后利用其价值估计，通过交替优化为稳定的 LLM 微调提供细粒度的信用分配信号。在包括 Jericho 中的文本冒险游戏和 BabyAI 中的指令遵循网格世界任务在内的多种基准测试中，实验表明 PriorZero 持续提高了探索效率和渐近性能，为 LLM 赋能的决策制定建立了一个极具前景的框架。我们的代码可在 https://github.com/opendilab/LightZero 获取。

## Abstract
Leveraging the rich world knowledge of Large Language Models (LLMs) to enhance Reinforcement Learning (RL) agents offers a promising path toward general intelligence. However, a fundamental prior-dynamics mismatch hinders existing approaches: static LLM knowledge cannot directly adapt to the complex transition dynamics of long-horizon tasks. Using LLM priors as fixed policies limits exploration diversity, as the prior is blind to environment-specific dynamics; while end-to-end fine-tuning suffers from optimization instability and credit assignment issues. To bridge this gap, we propose PriorZero, a unified framework that integrates LLM-derived conceptual priors into world-model-based planning through a decoupled rollout-training design. During rollout, a novel root-prior injection mechanism incorporates LLM priors exclusively at the root node of Monte Carlo Tree Search (MCTS), focusing search on semantically promising actions while preserving the world model's deep lookahead capability. During training, PriorZero decouples world-model learning from LLM adaptation: the world model is continuously refined on interaction data to jointly improve its dynamics, policy, and value predictions, its value estimates are then leveraged to provide fine-grained credit assignment signals for stable LLM fine-tuning via alternating optimization. Experiments across diverse benchmarks, including text-based adventure games in Jericho and instruction-following gridworld tasks in BabyAI, demonstrate that PriorZero consistently improves both exploration efficiency and asymptotic performance, establishing a promising framework for LLM-empowered decision-making. Our code is available at https://github.com/opendilab/LightZero.

#### 1. 核心问题与整体含义（研究动机和背景）
论文探讨的核心问题是**如何有效地将大语言模型（LLM）的通用世界知识转化为强化学习（RL）智能体的决策能力**。
*   **研究动机**：在长时程、稀疏奖励的任务中，纯试错探索成本极高。LLM 拥有丰富的语义先验，但直接应用存在“先验-动力学不匹配”问题：
    *   LLM 知识是静态且声明式的，无法直接感知特定环境的转移动力学。
    *   直接作为策略（P1）会导致短视；端到端微调（P2）面临高方差信用分配难题；作为动力学模型（P3）存在 Token 级别与状态-动作级别的粒度错位。
*   **整体含义**：PriorZero 旨在通过一个解耦的框架，让 LLM 提供语义引导（先验），而让世界模型（World Model）负责具体的动力学建模和长期规划，从而实现两者的优势互补。

#### 2. 方法论：核心思想与关键技术
PriorZero 提出了一个**解耦的展开-训练（Rollout-Training）架构**：

*   **核心思想**：将 LLM 作为“语义先验源”，仅在蒙特卡洛树搜索（MCTS）的起点提供建议，而搜索的深度前瞻和价值评估由学习到的潜在世界模型完成。
*   **关键技术细节**：
    1.  **根节点先验注入（Root-Prior Injection）**：在 MCTS 过程中，LLM 的语义先验 $\pi_{LLM}$ 仅在根节点（当前真实状态）与世界模型策略 $\pi_{WM}$ 融合。非根节点（想象状态）完全依赖世界模型。这避免了 LLM 对其不理解的潜在空间状态进行错误干预。
    2.  **结构化先验提取（CoT）**：利用“先分析后决策”的思维链（Chain-of-Thought）提示词，减少 LLM 的合理化偏差。
    3.  **交替强化微调（Alternating Reinforcement Fine-Tuning）**：
        *   **解耦优化**：世界模型在交互数据上更新，以提供准确的价值估计。
        *   **低方差监督**：利用世界模型的 $n$ 步自助法（Bootstrapped）TD 优势信号（Advantage）作为奖励，通过 PPO 算法微调 LLM。这解决了稀疏奖励下的信用分配问题。
*   **算法流程**：智能体在 Rollout 阶段通过融合先验的 MCTS 收集数据；在训练阶段，先更新世界模型，待其价值估计稳定后，再利用其产生的优势信号交替微调 LLM。

#### 3. 实验设计
*   **数据集/场景**：
    *   **Jericho**：文本冒险游戏基准（包括 Detective, Acorncourt, Zork1, Omniquest），侧重长时程规划和稀疏奖励。
    *   **BabyAI**：指令遵循的网格世界任务（18个关卡），侧重多任务泛化和空间语义理解。
*   **基准（Benchmark）**：主要对比 **UniZero**（不含 LLM 先验的先进世界模型规划器）。
*   **对比范式**：
    *   **P1 (Naive Policy)**：直接 Prompt LLM 输出动作。
    *   **P2 (Naive RLFT)**：端到端强化学习微调 LLM。
    *   **P3 (Dynamics Model)**：用 LLM 作为动力学骨干网络。
    *   **P4 (Text Encoder)**：将 LLM 作为冻结的特征提取器。

#### 4. 资源与算力
*   **硬件**：使用 **NVIDIA H200 GPU**。
*   **配置**：

*   **模型规模**：使用了 **Qwen2.5-3B-Instruct** 和 **Qwen2.5-7B-Instruct** 作为 LLM 模块。

#### 5. 实验数量与充分性
*   **实验规模**：涵盖了 4 个不同特性的 Jericho 游戏和 18 个 BabyAI 关卡，实验设置较为全面。

    *   交替训练策略的必要性（对比冻结先验和非交替优化）。
    *   CoT 及其损失权重的影响。
    *   LLM 模型规模（3B vs 7B）的扩展性。
    *   MCTS 规划组件的不可或缺性。

#### 6. 主要结论与发现
*   **性能提升**：PriorZero 在所有测试环境中均显著优于纯世界模型（UniZero）和现有的 LLM 转移范式（P1-P4）。
*   **探索效率**：LLM 先验在训练早期能有效降低 MCTS 根节点的熵，使搜索集中在有意义的动作上，从而在稀疏奖励任务中实现更快的收敛。
*   **协同效应**：世界模型为 LLM 提供了稳定的微调信号，而微调后的 LLM 反过来提供了更精准的搜索引导，形成了正向循环。
*   **解决不匹配**：通过根节点注入和交替优化，成功解决了 LLM 静态知识与环境动态之间的错位。

#### 7. 优点
*   **架构优雅**：解耦设计巧妙地避开了 LLM 难以建模潜在动力学的弱点，同时发挥了其语义理解的长处。
*   **稳定性高**：利用世界模型的价值函数作为 Critic，为 LLM 提供了比原始环境奖励更低方差的梯度信号。
*   **通用性强**：在纯文本（Jericho）和具身指令（BabyAI）任务中均表现出色，证明了框架的普适性。

#### 8. 不足与局限
*   **计算开销**：尽管比端到端微调更高效，但 Rollout 过程中每个根节点都需要 LLM 推理，且训练涉及 LLM 微调，算力需求依然较高。
*   **动作空间限制**：目前主要在离散动作空间（文本或高层语义动作）中验证，在连续动作空间或极大规模动作空间下的表现尚待探索。
*   **超参数敏感性**：交替优化的频率（N_WM : N_LLM）和先验融合权重 $\alpha$ 可能需要针对不同任务进行精细调优。
