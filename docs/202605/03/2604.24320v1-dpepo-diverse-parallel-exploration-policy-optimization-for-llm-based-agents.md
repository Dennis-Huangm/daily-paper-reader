## 摘要
遵循顺序“推理-行动”范式的大语言模型（LLM）智能体在许多复杂任务中取得了卓越的性能。然而，由于这些方法每步仅与单个环境交互，因此面临探索受限和环境理解不完整的问题。在本文中，我们首先引入了一种新颖的范式，使智能体能够同时与多个环境交互并共享跨轨迹经验。基于这一范式，我们进一步提出了 DPEPO，这是一种鼓励智能体进行多样化并行探索的强化学习（RL）算法。DPEPO 包含两个阶段：初始的有监督微调（SFT）赋予基础的并行推理和动作生成能力，随后是采用分层奖励方案的强化学习阶段。我们设计了一个并行轨迹级成功奖励和两个步骤级奖励：多样化动作奖励（Diverse Action Reward）和多样化状态转移奖励（Diverse State Transition Reward），旨在主动惩罚行为冗余并促进广泛探索。在 ALFWorld 和 ScienceWorld 上的广泛实验表明，DPEPO 实现了最先进的（SOTA）成功率，同时保持了与强顺序基线相当的效率。（代码可在 https://github.com/LePanda026/Code-for-DPEPO 获取）

## Abstract
Large language model (LLM) agents that follow the sequential "reason-then-act" paradigm have achieved superior performance in many complex tasks.However, these methods suffer from limited exploration and incomplete environmental understanding, as they interact with only a single environment per step. In this paper, we first introduce a novel paradigm that enables an agent to interact with multiple environments simultaneously and share cross-trajectory experiences. Building upon this paradigm, we further propose DPEPO, a reinforcement learning (RL) algorithm that encourages the agent to perform diverse parallel exploration. There are two stages in DPEPO: initial supervised fine-tuning (SFT) imparts basic parallel reasoning and action generation, followed by reinforcement learning stage with a hierarchical reward scheme. We design a parallel trajectory-level success reward and two step-level rewards: Diverse Action Reward and Diverse State Transition Reward, which actively penalize behavioral redundancy and promote broad exploration. Extensive experiments on ALFWorld and ScienceWorld show that DPEPO achieves state-of-the-art (SOTA) success rates, while maintaining comparable efficiency to strong sequential baselines. ### 1. 核心问题与整体含义（研究动机和背景）
传统的 LLM 智能体通常遵循 **ReAct**（推理-行动）范式，这是一种线性的顺序交互方式：智能体执行一个动作，观察一个反馈，再进行下一步。
*   **核心痛点**：这种“窄而深”的线性视图限制了智能体对环境的全面理解，容易陷入局部最优或因探索不足而失败。
*   **研究动机**：虽然可以通过多次独立采样来增加探索，但存在**缺乏多样性**（动作趋同）和**效率低下**（经验不共享、Token 消耗大）的问题。
*   **整体含义**：本文提出了一种**并行探索（Parallel Exploration）**新范式，允许智能体在单步内同时与多个环境交互并共享经验，从而构建更全面的环境认知。

### 2. 方法论：核心思想与关键技术
论文提出了 **DPEPO** 框架，通过两个阶段训练智能体：
*   **阶段一：冷启动（SFT）**
    *   通过人工标注和模型合成（如 DeepSeek-V3）生成包含并行探索行为的轨迹数据。
    *   训练智能体掌握基础的并行推理格式（使用 `<think>`、`<parallel>`、`<env_i>` 等标签）。
*   **阶段二：强化学习（RL）与分层奖励**
    *   **并行轨迹级成功奖励**：只要并行环境中的任何一个达到目标状态，即给予奖励。
    *   **并行步骤级多样性奖励（核心创新）**：
        1.  **多样化动作奖励（DAR）**：同时考虑“深度”（单环境内动作重复）和“宽度”（跨环境动作重复），惩罚冗余动作。
        2.  **多样化状态转移奖励（DSTR）**：惩罚重复的“状态-动作”转移对，强制智能体收集新信息。
*   **策略优化**：采用类似 **GRPO** 的组相对优势计算，无需 Critic 模型。通过将轨迹级优势与步骤级奖励结合，提供多粒度的监督信号。

*   **评估指标**：成功率（Success Rate）、轨迹长度（Steps）、Token 消耗、推理时间。

实验设计非常充分且具有客观性：
*   **多维度对比**：涵盖了不同规模的模型（1.5B 到 7B）和不同代际的模型（Qwen2.5, Qwen3）。
*   **消融实验**：详细验证了 DAR 和 DSTR 奖励组件的有效性，并分析了冷启动阶段的贡献。

### 6. 主要结论与发现
*   **性能领先**：DPEPO 在 ALFWorld（98.2%）和 ScienceWorld（61.4%）上均刷新了 SOTA 记录。
*   **高效探索**：并行探索不仅提高了成功率，还缩短了完成任务所需的平均步数。
*   **Token 效率**：虽然单步 Token 较多，但由于总步数减少且避免了冗余尝试，DPEPO 的总 Token 消耗和推理时间优于强基线（如 DeepSeek-R1）。
*   **策略演变**：智能体学会了在任务早期进行广泛并行探索，在后期锁定目标后转为聚焦执行。

### 7. 优点
*   **范式创新**：打破了 ReAct 的线性限制，提出了更符合人类“多路尝试”逻辑的并行交互模式。
*   **奖励设计精巧**：通过 DAR 和 DSTR 有效解决了强化学习中常见的“行为坍缩”和“探索冗余”问题。
*   **训练高效**：相比传统的 PPO 或其他复杂的 RL 算法，DPEPO 样本效率极高，仅需少量样本即可达到优异效果。

### 8. 不足与局限
*   **环境依赖**：该方法假设环境可以被并行实例化（如模拟器、沙盒），在无法轻易复制状态的现实物理世界（如单一实体机器人）中应用受限。
*   **偏见风险**：并行探索可能导致智能体在带有偏见的环境中加速习得负面行为。
*   **上下文压力**：随着并行环境数量增加，Prompt 的上下文长度会迅速增长，对模型的长文本处理能力有一定要求。
