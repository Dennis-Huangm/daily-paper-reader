## 摘要
长程语言智能体必须在有限的上下文窗口下，重复与工具交互、积累证据并做出决策。现有的上下文管理方法通过截断久远的历史、将过去的轮次折叠为摘要或选择紧凑的记忆状态，使这种长程展开成为可能。然而，这些突破引入了两个耦合的局限性。首先，随着轮次增加，历史观测被逐渐移除或坍缩为压缩状态，使得策略难以重用细粒度的证据。其次，一旦原始轮次不再具备源可寻址性，基于结果的强化学习就失去了将策略更新与支持成功最终答案的证据对齐的显式路径。为此，我们提出了 ECHO，这是一个选择性轮次记忆框架，通过源索引重构共同解决历史坍缩和可追踪学习的问题。具体而言，ECHO 将每个完成的环境轮次压缩为紧凑的记忆记录，通过从这些记录中进行选择来重构受限的策略上下文，并重用所选的源索引，将正向结果信用分配给支持成功答案的证据和选择动作。在 BrowseComp-Plus 上，ECHO 达到了 43.4% 的留出准确率，优于 GRPO (28.9%) 和滚动摘要基准 SUPO (36.1%)，同时比 SUPO 使用了更少的轮次和更低的轨迹量。此外，经过训练的策略在稠密和混合专家骨干网络上，均提升了在多目标问答、代码生成和深度信息检索基准测试中的零样本泛化能力。

## Abstract
Long-horizon language agents must repeatedly interact with tools, accumulate evidence, and make decisions under bounded context windows. Existing context-management methods make such rollouts feasible by truncating distant history, folding past turns into summaries, or selecting compact memory states. However, these breakthroughs introduce two coupled limitations. First, as the number of turns grows, historical observations are progressively removed or collapsed into compressed states, making it harder for the policy to reuse fine-grained evidence. Second, once the original turns are no longer source-addressable, outcome-based RL loses an explicit path for aligning policy updates with the evidence that supported a successful final answer. To this end, we propose ECHO, a selective turn-memory framework that jointly addresses history collapse and traceable learning through source-indexed reconstruction. Specifically, ECHO compresses each completed environment turn into a compact memory record, reconstructs bounded policy contexts by selecting from these records, and reuses the selected source indices to route positive outcome credit to the evidence and selection actions that support successful answers. On BrowseComp-Plus, ECHO reaches 43.4% held-out accuracy, outperforming GRPO (28.9%) and the rolling-summary baseline SUPO (36.1%), while using fewer turns and lower trajectory volume than SUPO (Figure 1). Additionally, the trained policy improves zero-shot generalization across multi-objective QA, code generation, and deep information-seeking benchmarks on both dense and MoE backbones.

### 1. 核心问题与研究动机
在长程交互任务中，智能体需要频繁调用工具并积累证据。由于 LLM 的上下文窗口有限，现有方法通常采用截断历史或滚动摘要（如 SUPO）来压缩信息。
*   **历史坍缩（History Collapse）：** 摘要会丢失细粒度的原始证据，导致智能体难以重用关键信息。
*   **可追溯性缺失（Loss of Traceability）：** 当原始交互被压缩后，强化学习（RL）无法将最终的成功奖励准确地回溯到具体的历史步骤上，导致信用分配（Credit Assignment）变得模糊，容易引发“轮次膨胀”（生成冗余搜索）。

### 2. 方法论：ECHO 框架
ECHO 的核心思想是“**通过剪枝来行动，通过追踪来学习**”，主要包含以下关键技术：
*   **源索引轮次记忆（Source-Indexed Turn Memory）：** 智能体将每一次工具交互压缩为一个紧凑的“记忆记录”，包含源轮次索引、动作摘要和局部发现。这些记录以非坍缩的集合形式存储，保持了原始证据的可寻址性。
*   **自回归记忆选择（Autoregressive Memory Selection）：** 当上下文超出预算时，策略会主动选择对当前决策最有用的历史记录，并据此重构下一个受限的策略上下文。
*   **溯源引导的信用分配（Provenance-Guided Credit Assignment）：** 这是 ECHO 的核心创新。在学习阶段，系统不再将奖励均匀分配给所有生成的 Token，而是利用重构时的“源索引”建立信用路径。只有最终答案、被选中的历史证据轮次、记忆发现以及执行选择动作的 Token 才会获得正向信用。

### 6. 主要结论与发现
*   **性能领先：** ECHO 在 BrowseComp-Plus 上达到了 43.4% 的准确率，显著优于 GRPO (28.9%) 和 SUPO (36.1%)。
*   **效率更高：** 相比 SUPO，ECHO 在提升准确率的同时，显著减少了交互轮次和轨迹数据量，避免了摘要方法常见的“轮次激增”现象。
*   **泛化性强：** 经过 ECHO 训练的智能体在未见过的代码和深度搜索任务中表现出更好的零样本迁移能力。

### 7. 优点与亮点
*   **创新性：** 首次将上下文重构的“索引”直接用于 RL 的信用分配，实现了感知与学习的统一。
*   **解决痛点：** 有效缓解了长程任务中的信息丢失问题，通过“精准奖励”抑制了智能体的冗余行为。
*   **架构无关：** 实验证明该方法在不同规模和类型的模型（稠密 vs MoE）上均表现稳健。

### 8. 不足与局限
*   **近似溯源：** 目前的信用分配采用的是“最终轨迹近似”，即只奖励最后一步选中的轮次，可能无法完全覆盖深层嵌套的依赖链（即 A 依赖 B，B 依赖 C 的情况）。
*   **计算开销：** 引入了额外的记忆选择步骤，虽然减少了总轮次，但在单次重构时会增加一定的推理计算量。
*   **应用范围：** 目前主要集中在文本工具使用领域，尚未在 GUI 操作或多智能体协作等更复杂的场景中验证。
