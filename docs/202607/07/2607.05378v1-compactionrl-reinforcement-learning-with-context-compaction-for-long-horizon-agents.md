## 摘要
长程智能体大语言模型（LLMs）日益受到有限上下文窗口的限制，因为在任务完成之前，延长的交互轨迹可能会超过最大上下文长度。上下文压缩通过总结之前的交互状态并在压缩后的上下文中继续展开（rollout），提供了一种自然的解决方案，但将压缩整合到强化学习中仍有待探索。我们提出了 CompactionRL，这是一种利用上下文压缩训练长程智能体 LLM 的强化学习策略。我们的方法通过标记级（token-level）损失归一化和跨轨迹广义优势估计（cross-trajectory generalized advantage estimation），共同优化任务执行和摘要生成。这种设计使 LLM 智能体能够从压缩的长程轨迹中学习。我们在开源模型的基础上训练了 CompactionRL，并观察到在智能体编程任务上的持续性能提升。CompactionRL 使开源 GLM-4.5-Air 模型（106B-A30B）在 SWE-bench Verified 上达到 66.8% 的 Pass@1 分数，在 Terminal-Bench 2.0 上达到 24.5%，分别获得了 7.0 和 3.1 个百分点的绝对提升。基于 GLM-4.7-Flash（30B-A3B），CompactionRL 将 Pass@1 分数分别提高了 5.5 和 6.8 个百分点，在 SWE-bench Verified 上达到 56.0%，在 Terminal-Bench 2.0 上达到 20.2%。因此，CompactionRL 已部署在用于训练开源 GLM-5.2 模型（750B-A40B）的强化学习流水线中。

## Abstract
Long-horizon agentic LLMs are increasingly limited by finite context windows, as extended interaction trajectories can exceed the maximum context length before a task is completed. Context compaction offers a natural solution by summarizing previous interaction states and continuing the rollout under a compressed context, but incorporating compaction into reinforcement learning remains underexplored. We propose CompactionRL, a reinforcement learning strategy to train long-horizon agentic LLMs with context compaction. Our approach jointly optimizes task execution and summary generation with token-level loss normalization and cross-trajectory generalized advantage estimation. This design enables the LLM agents to learn from compacted long-horizon trajectories. We train CompactionRL on top of open models and observe consistent performance gains on agentic coding tasks. CompactionRL enables the open GLM-4.5-Air model (106B-A30B) to achieve Pass@1 scores of 66.8% on SWE-bench Verified and 24.5% on Terminal-Bench 2.0, with absolute gains of 7.0 and 3.1 points, respectively. Built upon GLM-4.7-Flash (30B-A3B), CompactionRL improves Pass@1 by 5.5 and 6.8 points, reaching 56.0% on SWE-bench Verified and 20.2% on Terminal-Bench 2.0, respectively. CompactionRL is thus deployed in the RL pipeline for training the open GLM-5.2 model (750B-A40B).

### 1. 核心问题与研究动机
*   **核心问题**：长程任务（如软件工程、复杂终端操作）生成的交互轨迹极长，往往会超过 LLM 的最大上下文窗口。
*   **研究动机**：
    *   单纯增加上下文长度（Scaling Context）成本高昂且存在利用率下降的问题。
    *   现有的上下文压缩（如摘要提取）多被视为推理时的启发式手段，而非可学习的能力。
    *   现有的强化学习流水线（如 GRPO）假设轨迹是完整的，难以处理因压缩而导致轨迹被切分成多个变长片段的情况。

### 2. 方法论：CompactionRL 框架
*   **核心思想**：将“上下文压缩”视为智能体的一种主动行为，在 RL 训练中联合优化**任务执行动作**和**摘要生成动作**，使两者共享最终的任务奖励。
*   **关键技术细节**：
    *   **触发机制**：当剩余上下文预算低于阈值 $T_{comp}$ 时，触发摘要生成。
    *   **上下文重构**：生成摘要后，清空旧历史，仅保留“系统提示词 + 摘要 + 最近 $k$ 步原始记录”继续执行。
    *   **PPO 优化器选择**：放弃了组相对优势估计（如 GRPO），回归到基于 Critic 的 PPO。因为压缩会导致一个 Rollout 产生变数量的片段，组归一化会产生权重偏差。
    *   **令牌级损失归一化（Token-level Loss Normalization）**：针对片段数量和长度的不均衡，按生成的 Token 数量而非样本数量进行损失归一化，消除长度诱导的权重偏差。
    *   **跨轨迹广义优势估计（Cross-trajectory GAE）**：为了在压缩边界保持信用分配，根据后续片段的 Token 数量对当前片段的局部 GAE 优势进行折扣修正，确保早期动作能正确感知到遥远的最终奖励。
