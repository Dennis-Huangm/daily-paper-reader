## 摘要
强化学习（RL）在大型语言模型（LLM）的后训练中变得越来越重要。以前用于 LLM 的 RL 流水线大多是同步且批次交替的，这对于长时程智能体任务来说效率低下。最近，异步 RL 作为一种更高效的替代方案出现，它在采样（rollouts）到达时即更新模型。然而，现有的异步 RL 系统通常强调吞吐量，而对训练稳定性和任务有效性的探索较少。例如，一个关键挑战是广泛使用的 GRPO 框架中的组采样（group-wise sampling）并不自然地适用于异步智能体训练。在本文中，我们提出了单采样异步优化（SAO），以解决异步 RL 中的稳定性和离策（off-policy）挑战。为了减少离策效应并提高泛化能力，我们将组采样替换为单采样，即每个提示词（prompt）仅使用一次采样。我们通过实用的价值模型训练设计进一步改进了这种单采样策略。为了提高优化稳定性，我们引入了一种严格的双侧 Token 级裁剪策略。SAO 能够稳定训练一千步，并在智能体编程和推理基准测试（如 SWE-Bench Verified、BeyondAIME 和 IMOAnswerBench）上持续优于 GRPO 及其变体。我们还证明了单采样 RL 在模拟在线学习设置中特别有效，在这种设置中，模型必须适应不断变化的环境。为此，SAO 已成功部署在智能体 RL 流水线中，用于训练开源的 GLM-5.2 模型（750B-A40B）。

## Abstract
Reinforcement learning (RL) is becoming increasingly important for post-training large language models (LLMs). Previous RL pipelines for LLMs were mostly synchronous and batch-interleaved, which is inefficient for long-horizon agentic tasks. Recently, asynchronous RL has emerged as a more efficient alternative by updating the model as rollouts arrive. However, existing asynchronous RL systems often emphasize throughput, while leaving training stability and task effectiveness largely underexplored. For example, a key challenge is that group-wise sampling in the widely-used GRPO framework does not naturally fit asynchronous agentic training. In this paper, we present Single-rollout Asynchronous Optimization (SAO) to address the stability and off-policy challenges in asynchronous RL. To reduce off-policy effects and improve generalization, we replace group-wise sampling with single-rollout sampling, that is, using one rollout per prompt. We further improve this single-rollout strategy with practical value-model training designs. To improve optimization stability, we introduce a strict double-side token-level clipping strategy. SAO is able to train stably for one thousand steps and consistently outperform GRPO and its variants on agentic coding and reasoning benchmarks, such as SWE-Bench Verified, BeyondAIME, and IMOAnswerBench. We also demonstrate that single-rollout RL is particularly effective in a simulated online learning setting, where the model must adapt to changing evolving environments. To this end, SAO is successfully deployed in the agentic RL pipeline for training the open GLM-5.2 model (750B-A40B).

### 1. 核心问题与研究动机
*   **研究背景**：传统的 LLM 强化学习（如 PPO、GRPO）多采用**同步批次交替**模式，即必须等待一整批采样（Rollouts）全部完成后才开始优化。
*   **核心痛点**：
    *   **效率瓶颈**：智能体任务的采样长度差异巨大，同步模式会导致 GPU 集群长时间等待“落后者”（Stragglers），造成资源浪费。
    *   **异步挑战**：现有的异步 RL 虽然提升了吞吐量，但存在“策略滞后”（Policy Lag）导致的离策（Off-policy）偏差，严重影响训练稳定性。
    *   **框架不匹配**：目前流行的 GRPO 依赖组采样（Group-wise sampling）来估计优势函数，这在异步流程中会引入额外的等待延迟，且不符合真实在线学习（通常每条提示词仅一个反馈）的场景。

### 2. 方法论（SAO：单采样异步优化）
SAO 的核心思想是放弃组采样，采用**单采样（Single-rollout）**模式，并通过一系列技术手段确保异步训练的稳定性：
*   **双侧 Token 级重要性采样（DIS）**：
    *   直接利用采样引擎生成的 Log-probabilities 作为行为概率，避免维护历史模型副本。
    *   引入严格的**双侧裁剪与掩码策略**：不仅裁剪过大的更新，还将超出信任区域 $[1-\epsilon_l, 1+\epsilon_h]$ 的 Token 直接从梯度计算中剔除，以应对剧烈的策略漂移。
*   **价值模型（Critic）优化设计**：
    *   **快于策略的价值更新**：每进行 1 次策略更新，执行 $K=2$ 次价值模型更新，确保优势函数估计能快速跟上策略变化。
    *   **冻结注意力机制训练**：在 RL 阶段冻结价值模型的 Attention 层，仅微调 MoE 或投影层，以抑制价值模型梯度过大导致的数值不稳定。
*   **跳过观测的 Token 级 GAE（Skip-Observation GAE）**：
    *   针对智能体轨迹（动作-环境反馈交替），在计算广义优势估计（GAE）时，Bellman 目标直接跨越环境反馈 Token，连接当前动作与下一动作，避免环境噪声干扰。

### 6. 主要结论与发现
*   **性能卓越**：SAO 在所有推理和编程基准上均显著优于 GRPO 及其变体。例如在 AIME2025 上，SAO 将准确率从基准的 80.4% 提升至 97.3%。
*   **训练稳定**：SAO 解决了异步 RL 容易崩溃的问题，能够稳定支持长达千步以上的训练。
*   **在线适应**：在奖励函数动态变化的场景下，SAO 能够比“运行均值”（Running-mean）基准更快地调整策略，证明了强价值模型在单采样 RL 中的必要性。

### 7. 优点与亮点
*   **实用性极强**：直接针对工业界大规模训练中的“长尾采样”痛点，显著提升了硬件利用率。
*   **算法简化**：DIS 策略去除了对旧策略模型副本的依赖，降低了显存占用和系统复杂度。
*   **智能体适配**：Skip-Observation GAE 的设计精准捕捉了智能体任务中“模型仅对自身动作负责”的本质。

### 8. 不足与局限
*   **依赖高质量价值模型**：单采样模式对价值模型的准确性要求极高，若预训练价值模型不足，可能导致“冷启动”失败。
*   **基础设施要求**：异步架构需要复杂的分布式系统支持（如解耦的采样引擎和学习器），对中小型研究团队有一定门槛。
*   **泛化验证**：虽然在 30B 和 750B 模型上验证了效果，但对于更小规模模型或非智能体类（如短文本对话）任务的效果尚未深入探讨。
