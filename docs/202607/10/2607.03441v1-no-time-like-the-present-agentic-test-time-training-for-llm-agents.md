## 摘要
大语言模型（LLM）智能体在长回合任务中经常出现性能退化：随着轨迹的增长，它们会重新访问已探索的状态，重复失败的动作，并丢失先前有效的策略。测试时训练（TTT）提供了一种根据不断演变的任务状态调整模型权重的方法，但现有的 LLM TTT 方法大多仅针对固定输入进行一次性调整。我们研究了多轮智能体回合中的持续 TTT，其中每次更新都会改变生成后续训练文本的策略。这创建了一个自训练循环，当出现新的轨迹信息时，该循环会有所帮助，但当智能体陷入困境并反复在相似文本上进行训练时，它会放大漂移。我们发现更新文本的重复性可以区分这些情况，并引入了智能体测试时训练（aTTT），这是一种词元级重加权方法，它降低了先前更新中重复出现的 n-gram 词元的损失权重，同时保持新词元的权重。为了在实时回合中运行此类更新，我们利用 vLLM 的运行时 LoRA API 构建了一个并发服务系统，将开销限制在无 TTT 成本的 1.9 倍以内。aTTT 在 ALFWorld 上将成功率提高了多达 5.0 个百分点，在 SWE-bench Lite 上提高了 4.9 个百分点。收益主要集中在模型已经具备任务能力但在长轨迹中发生漂移的情况，这表明 aTTT 主要是保留了现有的能力，而不是教授新的能力。

## Abstract
LLM agents often degrade over long episodes: as trajectories grow, they revisit explored states, repeat failed actions, and lose strategies that previously worked. Test-time training (TTT) offers a way to adapt model weights to the evolving task state, but existing LLM TTT methods largely adapt once to a fixed input. We study continuous TTT in multi-turn agent episodes, where each update changes the policy that generates later training text. This creates a self-training loop that helps when new trajectory information appears, but can amplify drift when the agent gets stuck and repeatedly trains on similar text. We find that update-text repetition distinguishes these regimes and introduce Agentic Test-Time Training (aTTT), a token-level reweighting method that downweights the loss on tokens appearing in repeated $n$-grams from prior updates while leaving novel tokens fully weighted. To run such updates inside live episodes, we build a concurrent serving system using vLLM's runtime LoRA API, limiting overhead to 1.9$\times$ the no-TTT cost. aTTT improves success by up to 5.0 points on ALFWorld and 4.9 points on SWE-bench Lite. The gains concentrate where models already have task competence but drift over long trajectories, suggesting that aTTT mainly preserves existing competence rather than teaching new abilities.

### 1. 核心问题与整体含义（研究动机和背景）
LLM 智能体在执行长轨迹任务时常面临“漂移”问题：随着对话轮数增加，智能体容易陷入循环、重复失败动作或丢失先前有效的策略。现有的 TTT 方法（如 qTTT）通常是静态的，即针对固定输入更新一次权重后便停止。然而，智能体任务是动态的，模型自身的输出会影响后续的轨迹。这种**内生反馈循环**（Endogenous Feedback Loop）可能导致模型在陷入困境时，反复在错误的重复数据上进行训练，从而强化错误行为。

### 2. 方法论：核心思想与关键技术
论文提出了 **Agentic Test-Time Training (aTTT)**，其核心思想是在智能体运行过程中持续更新模型权重，并引入**词元级重加权机制**来抑制有害的自我强化。

*   **持续更新（Online TTT）：** 每隔 $K$ 个环境步骤，从当前轨迹中提取训练信号（如智能体自身的推理、环境观察或轨迹摘要），通过 LoRA 适配器更新模型。
*   **词元级重加权（Token-level Reweighting）：** 
    *   算法会记录该回合内所有历史更新文本的 $n$-gram 频率。
    *   对于当前更新文本中的每个词元（Token），计算其在历史中出现的最长 $n$-gram 暴露次数 $f_k(j)$。
    *   **公式：** 损失权重 $w_{k,j} = \max(w_{min}, 1 / (1 + f_k(j)))$。
    *   **效果：** 降低重复出现的文本（如陷入循环的动作）的损失权重，同时保持新信息（如新观察到的环境状态）的权重。
*   **并发服务系统：** 利用 vLLM 的运行时 LoRA API，构建了一个解耦推理与训练的系统。基础模型保持冻结并共享，每个回合拥有独立的 LoRA 槽位，支持异步更新和热插拔，将时间开销控制在基准测试的 1.9 倍。

*   **实验规模：** 在两个不同领域的基准测试上进行了评估，涵盖了从 4B 到 27B 不同规模的模型。
*   **消融实验：** 进行了更新频率（Cadence $K$）、LoRA 秩（Rank）、$n$-gram 窗口大小、随机丢弃控制实验、以及与“上下文注入（In-context）”和“解码惩罚（Decoding penalty）”的对比。

### 6. 主要结论与发现
*   **性能提升：** aTTT 在 ALFWorld 上提升了高达 5.0 个百分点，在 SWE-bench Lite 上提升了 4.9 个百分点。
*   **能力保持而非获取：** 收益主要集中在模型本身有潜力解决但因长轨迹漂移而失败的任务上。aTTT 更多是**稳定和保留**模型现有的能力，而非教会模型全新的技能。
*   **重复性是关键信号：** 失败的回合通常伴随着更新文本重复率的早期上升，aTTT 有效抑制了这种趋势。

### 7. 优点
*   **动态适应：** 解决了静态 TTT 无法应对动态交互过程的问题。
*   **精细化控制：** 词元级重加权比序列级过滤更灵活，能保留重复模板中的关键新信息（如新的物体名称）。
*   **工程可行性：** 结合 vLLM LoRA API 的并发系统证明了该方法在实际生产环境中的部署潜力。

### 8. 不足与局限
*   **信号源依赖：** 实验发现最佳的训练信号（Self, Env 或 Summary）因模型而异，目前尚无统一的最优选择。
*   **能力上限：** 如果模型本身完全不具备解决任务的能力，aTTT 无法通过测试时训练“无中生有”。
*   **应用限制：** 主要针对长轨迹任务，对于短任务或模型已经非常稳定的场景，提升有限。
