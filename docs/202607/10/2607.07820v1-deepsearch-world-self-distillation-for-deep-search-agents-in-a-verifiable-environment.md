## 摘要
训练工具使用智能体从自身经验中学习仍具挑战性，因为监督微调依赖于固定的教师蒸馏轨迹，而稀疏奖励强化学习在长程交互中提供的监督较弱。我们提出了 DeepSearch-Evolve，这是一个基于 DeepSearch-World 的 Web 智能体自蒸馏框架。DeepSearch-World 是一个具有可复现搜索和页面阅读工具的确定性且可验证的环境。DeepSearch-World 包含 42 万个基于实体级随机游走构建的多跳问答任务，并支持有助于自我进化的关键智能体认知行为，包括进度验证、落地反思和故障恢复。DeepSearch-Evolve 通过迭代执行轨迹生成、过滤、数据混合和微调来训练更强大的智能体。在没有从更强大的模型进行蒸馏的情况下，DeepSearch-World-9B 与开源智能体相比取得了具有竞争力的性能，在 BrowseComp 上达到 31.2%，在 GAIA 上达到 61.5%，在 HotpotQA 上达到 93.4%，这表明可验证环境能够实现长程 Web 智能体的可扩展自我进化。我们将发布该环境、42 万个训练池、验证集、模型和代码，以促进对自我改进深度搜索智能体的未来研究。

## Abstract
Training tool-use agents to improve from their own experience remains challenging, as supervised fine-tuning relies on fixed teacher-distilled trajectories, while sparse-reward reinforcement learning provides weak supervision for long-horizon interactions. We present DeepSearch-Evolve, a self-distillation framework for web agents built on DeepSearch-World, a deterministic and verifiable environment with reproducible search and page-reading tools. DeepSearch-World contains 420K multi-hop QA tasks constructed from entity-level random walks and supports key agentic cognitive behaviors useful for self-evolving, including progress verification, grounded reflection, and failure recovery. DeepSearch-Evolve iteratively performs trajectory generation, filtering, data mixing, and fine-tuning to train stronger agents. Without distillation from more capable models, DeepSearch-World-9B achieves competitive performance compared with open-source agents, reaching 31.2% on BrowseComp, 61.5% on GAIA, and 93.4% on HotpotQA, showing that verifiable environments enable scalable self-evolution for long-horizon web agents. We will release the environment, 420K training pool, validation set, model, and code to facilitate future research on self-improving deep search agents.

#### 1. 核心问题与整体含义（研究动机和背景）
当前训练工具调用（Tool-use）智能体面临两大瓶颈：
*   **监督微调（SFT）的局限性**：通常依赖于从更强模型（如 GPT-4）蒸馏出的固定轨迹，性能受限于教师模型且缺乏多样性。
*   **强化学习（RL）的挑战**：在长程交互任务中，最终奖励（Outcome Reward）极其稀疏，难以指导智能体在中间步骤（如查询构建、证据提取）中的决策。
*   **环境不可控性**：在线 Web 环境具有动态性，难以复现和验证中间过程。

**研究目标**：构建一个确定性、可验证的离线环境，使智能体能够通过“自我生成轨迹-验证-学习”的闭环，在不依赖闭源强模型的情况下实现自我进化。

#### 2. 方法论：核心思想与技术细节
论文提出了 **DeepSearch-World** 环境和 **DeepSearch-Evolve** 框架：

*   **DeepSearch-World（环境层）**：
    *   **离线知识库**：基于 1000 万个 Wikipedia 条目构建的确定性语料库。
    *   **任务构建**：通过实体级随机游走生成 42 万个多跳问答（Multi-hop QA）任务，并对特征进行“模糊化”处理以防止模型记忆。
    *   **确定性工具**：提供 `web_search_wiki`（基于 BM25 的检索）和 `visit_wiki`（页面阅读）工具，确保观察结果可复现。
    *   **过程验证**：环境能够实时追踪智能体是否找到了目标实体，并提供“落地反思”（Grounded Reflection）信号指导失败后的重试。

*   **DeepSearch-Evolve（训练框架）**：
    *   **脚手架教师（Scaffold Teacher）**：在生成阶段，使用包含“计划（Plan）、行动（Act）、结束（End）”三阶段的复杂提示词，显式记录工作记忆和进度。
    *   **轨迹过滤**：采用拒绝采样（仅保留答案正确的轨迹）和质量过滤（去除冗余和逻辑不一致的步骤）。
    *   **ReAct 格式转换**：将复杂的脚手架轨迹转换为标准的 `Thought-Action-Observation` 格式，将教师的计划和反思“内化”到学生的推理链中。
    *   **迭代自蒸馏**：采用异步生成与训练的循环，通过重要性采样混合不同轮次的数据，持续提升模型性能。

#### 6. 主要结论与发现
*   **性能卓越**：DeepSearch-World-9B 在不使用 GPT-4 蒸馏数据的情况下，在 GAIA (61.5%) 和 HotpotQA (93.4%) 等任务上达到了开源领先水平，显著超越了其基座模型。
*   **行为进化**：进化后的模型展现出更长的交互能力（平均轮次从 4.7 提升至 18.0）和更强的证据获取能力。

*   **泛化能力**：虽然在离线 Wikipedia 环境训练，但模型在真实 Web 搜索基准（如 BrowseComp）上依然表现出极强的迁移能力。

#### 7. 优点
*   **环境创新**：构建了一个大规模、可验证、确定性的离线 Web 模拟环境，解决了 Web 智能体训练中“不可复现”的痛点。
*   **自给自足**：证明了小参数模型（9B）可以通过在高质量环境中的自我博弈和蒸馏，达到甚至超过依赖强模型指导的智能体。
*   **过程监督**：通过将复杂的脚手架信息转化为 ReAct 轨迹，成功实现了过程级监督的有效传递。

#### 8. 不足与局限
*   **知识域限制**：目前环境仅基于 Wikipedia，虽然覆盖广，但在实时新闻、垂直行业数据或多模态 Web 交互方面的覆盖可能不足。

*   **语言偏差**：训练数据主要为英文，虽然在中文基准上有提升，但跨语言迁移的深度仍有待加强。
