## 摘要
强化学习（RL）在大语言模型（LLM）的后训练中变得日益重要。以往用于 LLM 的 RL 流水线大多采用同步和批次交替的方式，这在处理长时程智能体任务时效率较低。最近，异步 RL 作为一种更高效的替代方案出现，它在采样（rollouts）到达时即更新模型。然而，现有的异步 RL 系统往往侧重于吞吐量，而对训练稳定性和任务有效性的研究尚不充分。例如，一个关键挑战在于广泛使用的 GRPO 框架中的组采样（group-wise sampling）无法自然地适配异步智能体训练。在本文中，我们提出了单次采样异步优化（SAO），以解决异步 RL 中的稳定性和离策（off-policy）挑战。为了减轻离策效应并提高泛化能力，我们将组采样替换为单次采样，即每个提示词（prompt）仅使用一个采样序列。我们还通过实用的价值模型训练设计进一步改进了这一单次采样策略。为了提升优化稳定性，我们引入了一种严格的双侧 Token 级裁剪策略。SAO 能够稳定训练一千步，并在智能体编程和推理基准测试（如 SWE-Bench Verified、BeyondAIME 和 IMOAnswerBench）上持续优于 GRPO 及其变体。我们还证明了单次采样 RL 在模拟在线学习场景中特别有效，此时模型必须适应不断演变的环境。为此，SAO 已成功部署在用于训练开源 GLM-5.2 模型（750B-A40B）的智能体 RL 流水线中。

## Abstract
Reinforcement learning (RL) is becoming increasingly important for post-training large language models (LLMs). Previous RL pipelines for LLMs were mostly synchronous and batch-interleaved, which is inefficient for long-horizon agentic tasks. Recently, asynchronous RL has emerged as a more efficient alternative by updating the model as rollouts arrive. However, existing asynchronous RL systems often emphasize throughput, while leaving training stability and task effectiveness largely underexplored. For example, a key challenge is that group-wise sampling in the widely-used GRPO framework does not naturally fit asynchronous agentic training. In this paper, we present Single-rollout Asynchronous Optimization (SAO) to address the stability and off-policy challenges in asynchronous RL. To reduce off-policy effects and improve generalization, we replace group-wise sampling with single-rollout sampling, that is, using one rollout per prompt. We further improve this single-rollout strategy with practical value-model training designs. To improve optimization stability, we introduce a strict double-side token-level clipping strategy. SAO is able to train stably for one thousand steps and consistently outperform GRPO and its variants on agentic coding and reasoning benchmarks, such as SWE-Bench Verified, BeyondAIME, and IMOAnswerBench. We also demonstrate that single-rollout RL is particularly effective in a simulated online learning setting, where the model must adapt to changing evolving environments. To this end, SAO is successfully deployed in the agentic RL pipeline for training the open GLM-5.2 model (750B-A40B).

### 1. 核心问题与研究动机
*   **研究背景**：LLM 的后训练正从监督微调（SFT）转向强化学习。传统的 RL 流水线（如 PPO、GRPO）多为**同步批次交替**模式，即必须等待一整批采样（Rollouts）完成后才开始优化。
*   **核心痛点**：
    1.  **效率瓶颈**：智能体任务的采样长度差异巨大，同步模式会导致 GPU 集群长时间等待最慢的采样（Stragglers），造成资源浪费。
    2.  **异步不稳**：异步 RL 虽然能提高吞吐量，但会带来严重的“策略滞后”（Policy Lag），导致训练不稳定。
    3.  **框架错配**：目前流行的 GRPO 依赖组采样（Group-wise sampling）来估计优势函数，这在异步环境或单次反馈的在线学习场景中难以应用。

### 2. 方法论：单样本异步优化（SAO）
SAO 的核心思想是放弃组采样，采用**单样本采样（Single-rollout）**并配合一系列稳定性增强技术：
*   **双侧 Token 级重要性采样（DIS）**：
    *   直接利用采样引擎生成的 Log-probabilities 作为行为策略代理，避免了维护历史模型副本的开销。
    *   引入严格的**双侧裁剪与掩码策略**：不仅裁剪超出范围的比例，还将落在 $[1-\epsilon_l, 1+\epsilon_h]$ 之外的 Token 直接从梯度计算中剔除，以应对极端的策略漂移。
*   **价值模型（Critic）优化设计**：
    *   **快于策略的更新（Faster Value Update）**：Critic 的更新频率设为 Actor 的 $K$ 倍（实验中 $K=2$），确保优势函数估计能快速跟上策略变化。
    *   **冻结注意力机制（Frozen-Attention）**：在 RL 阶段仅训练价值模型的 MoE/MLP 层，冻结注意力层，以减少 Critic 训练的梯度波动。
*   **跳过观察的 Token 级 GAE（Skip-Observation GAE）**：
    *   针对智能体轨迹中包含环境反馈（Observation）的特点，修改 Bellman 目标，使当前动作的价值直接链接到下一个动作的起始，避免环境噪声通过非模型生成的 Token 传播。

    *   **数学推理**：AIME2025、BeyondAIME、HMMT Nov 2025、IMOAnswerBench（采用 Python 工具调用设置）。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了从 30B 到 750B 规模的模型，并在 5 个主流硬核基准测试上进行了验证。
*   **消融实验**：非常充分。作者对比了有无快速价值更新、有无冻结注意力、Token 级 vs 步级（Step-level）GAE、以及不同裁剪策略的效果。
*   **客观性**：通过 16 次重复运行取均值来降低推理任务的随机性，并设计了专门的在线学习模拟实验，证明了单样本策略在非平稳环境下的独特优势。

### 6. 主要结论与发现
*   **性能卓越**：SAO 在所有推理和编程基准上均优于 GRPO 及其变体。例如在 AIME2025 上，SAO 将准确率从基准的 80.4% 提升至 97.3%。
*   **训练稳定**：SAO 能够稳定训练超过 1000 步而不崩溃，而标准 GRPO 在异步设置下往往在 160 步左右出现性能坍塌。
*   **在线适应性**：在环境奖励函数发生突变时，SAO 的价值模型能比“运行均值（Running-mean）”基准更快地调整策略，展现出极强的在线学习潜力。

### 7. 优点与亮点
*   **架构创新**：成功将单样本 RL（通常被认为方差过大）通过精巧的 Critic 设计应用在大模型上，解决了异步训练的结构性矛盾。
*   **实用性强**：针对智能体任务中的“环境反馈”设计了专门的 GAE 估计器，具有很强的工程落地价值。
*   **稳定性高**：双侧裁剪和冻结注意力策略为大规模异步 RL 提供了可靠的保障。

### 8. 不足与局限
*   **基础设施依赖**：SAO 依赖于能够实时保存和传输 Token 级 Log-probabilities 的高性能异步推理/训练架构，部署门槛较高。
*   **任务局限**：实验主要集中在具有明确奖励（数学、编程）的任务上，对于奖励极其稀疏或主观性极强的通用对话任务，其表现尚待验证。
*   **超参数敏感性**：虽然提出了稳定性策略，但 $K$ 值、裁剪阈值等超参数在不同规模模型上的通用性仍需更多探索。
