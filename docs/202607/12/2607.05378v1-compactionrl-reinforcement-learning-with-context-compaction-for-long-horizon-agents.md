## 摘要
长程智能大语言模型（LLM）日益受到有限上下文窗口的限制，因为在任务完成之前，延长的交互轨迹可能会超过最大上下文长度。上下文压缩通过总结之前的交互状态并在压缩后的上下文中继续执行，提供了一种自然的解决方案，但将压缩整合到强化学习中仍有待探索。我们提出了 CompactionRL，这是一种利用上下文压缩训练长程智能 LLM 的强化学习策略。我们的方法通过词元级损失归一化和跨轨迹广义优势估计，联合优化任务执行和摘要生成。这一设计使 LLM 智能体能够从压缩后的长程轨迹中学习。我们在开源模型的基础上训练了 CompactionRL，并在智能编程任务上观察到了持续的性能提升。CompactionRL 使开源 GLM-4.5-Air 模型（106B-A30B）在 SWE-bench Verified 上实现了 66.8% 的 Pass@1 分数，在 Terminal-Bench 2.0 上实现了 24.5%，分别获得了 7.0 和 3.1 个百分点的绝对提升。基于 GLM-4.7-Flash (30B-A3B)，CompactionRL 将 Pass@1 分数分别提高了 5.5 和 6.8 个百分点，在 SWE-bench Verified 和 Terminal-Bench 2.0 上分别达到 56.0% 和 20.2%。因此，CompactionRL 已被部署到用于训练开源 GLM-5.2 模型（750B-A40B）的强化学习流水线中。

## Abstract
Long-horizon agentic LLMs are increasingly limited by finite context windows, as extended interaction trajectories can exceed the maximum context length before a task is completed. Context compaction offers a natural solution by summarizing previous interaction states and continuing the rollout under a compressed context, but incorporating compaction into reinforcement learning remains underexplored. We propose CompactionRL, a reinforcement learning strategy to train long-horizon agentic LLMs with context compaction. Our approach jointly optimizes task execution and summary generation with token-level loss normalization and cross-trajectory generalized advantage estimation. This design enables the LLM agents to learn from compacted long-horizon trajectories. We train CompactionRL on top of open models and observe consistent performance gains on agentic coding tasks. CompactionRL enables the open GLM-4.5-Air model (106B-A30B) to achieve Pass@1 scores of 66.8% on SWE-bench Verified and 24.5% on Terminal-Bench 2.0, with absolute gains of 7.0 and 3.1 points, respectively. Built upon GLM-4.7-Flash (30B-A3B), CompactionRL improves Pass@1 by 5.5 and 6.8 points, reaching 56.0% on SWE-bench Verified and 20.2% on Terminal-Bench 2.0, respectively. CompactionRL is thus deployed in the RL pipeline for training the open GLM-5.2 model (750B-A40B).

长程智能体（Long-horizon agents）在处理复杂任务（如软件工程、终端操作）时，交互轨迹往往会迅速超出大语言模型（LLM）有限的上下文窗口。虽然增加窗口长度是一种手段，但其计算成本高昂且存在长文本利用率下降的问题。
**核心问题**：现有的上下文压缩（Context Compaction）多被视为推理时的启发式操作，而非训练过程的一部分。在强化学习（RL）中，压缩后的摘要决定了后续所有动作的信息来源，因此“如何压缩”与“如何执行”同等重要。现有的 RL 框架（如 GRPO）难以处理因压缩导致的轨迹分段、长度不一及信用分配（Credit Assignment）失效等问题。

### 2. 方法论：核心思想与关键技术
CompactionRL 提出将上下文压缩整合进 PPO 强化学习框架中，使模型学会“边执行边总结”。

*   **核心思想**：将摘要生成视为一种特殊的动作，与任务执行动作共享最终的任务奖励（Reward），通过联合优化确保摘要保留了对后续任务至关重要的信息。
*   **关键技术细节**：
    *   **可训练的上下文压缩**：当剩余上下文低于阈值 $T_{comp}$ 时，触发策略生成摘要 $S_t$。随后重构上下文，保留系统提示词、摘要及最近的 $k$ 步交互，释放空间供后续 Rollout。
    *   **词元级损失归一化（Token-level Loss Normalization）**：由于压缩会导致轨迹被切分为多个长度不一的片段（执行片段和摘要片段），传统的序列级平均会导致样本权重失衡。该方法通过对所有生成的 Token 进行统一归一化，消除了片段数量和长度带来的偏差。
    *   **跨轨迹广义优势估计（Cross-trajectory GAE）**：在分段优化时，为了防止早期片段过度获取奖励，引入了位置修正。通过后续片段的 Token 数量对当前片段的优势值进行折扣修正，确保时间信用分配在跨越压缩边界时依然准确。

*   **算法修正精准**：针对分段轨迹提出的 Token 级归一化和 GAE 修正，解决了长程 RL 训练中的数学一致性问题。
